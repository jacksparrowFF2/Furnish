# DXF 布局交接

「保存／导出 → 导出 DXF 布局图」输出 UTF-8 文本 DXF 2007（AC1021），`$INSUNITS=4` 为 mm，坐标按 CAD +Y 向上转换。输出有效方案的 WALLS、OPENINGS、ROOMS、FURNITURE、LABELS、MEASURES、NOTES 图层，门窗洞口独立表示，房间保留多轮廓，家具为旋转后的占地外包。镜像矩形外包不改变其占地。

保留已保存测量线的真实端点及毫米长度；文字清理换行与控制字符。读取当前方案的墙体、门窗编辑和拆改，不依赖正在显示的主题、比例或临时预览。纯规则位于 `src/io/dxf-export.js`，无 DOM、网络和构建依赖。

DIMENSIONS 层共用 `drawing-core.js` 的自动结构分段／总尺寸和可选洞口宽度，尺寸线、界线、斜刻线和毫米文字分别输出；NORTH 层仅在真北已设置时绘制方向。看图旋转不改变 DXF 坐标，真北按原始图纸基准表达。标注为可编辑线／多段线及文字，不是原生关联 DIMENSION，接收方改几何后需重新标注。

用途为可编辑布局交接，缺少构造节点、立面、材料铺排及专业 CAD 标注样式；门窗外包与完整墙轮廓可能同层叠加，接收方须结合 OPENINGS 层核对，不作为经过审核的施工图。房间文字采用轮廓均值位置，凹形房间文字位置可能需要在 CAD 中调整。

`tests/test-layout-dxf.cjs` 验证 12 套内置户型、单位、旋转／镜像占地、Unicode 标签、测量及不变输入，并用现有 DXF 解析器读取导出文件。实际浏览器下载另作验收；未验证所有第三方 CAD 的字体、样式与版本兼容。
