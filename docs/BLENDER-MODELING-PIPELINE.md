# 模型整链路验收

2026-10-31。在TG10K60W试点基础上覆盖后引入的家具、家电、安装设备、窗饰／隔断和定制柜体配置。默认路线保持：固定产品使用Blender资产，既有参数化模型保留其构造；本工具不把柜体或早期已交付的参数化产品强制改为静态网格。

## 清单与命令

`scripts/lib/model-profiles.cjs` 是**验证清单**，不接管应用的产品规则。以首次拆分的目录 `a03d325` 的52种通用类型为原有基线，纳入后新增目录类型，以及后来明确重做的通用洗衣机、三种大屏电视、穿衣镜、单双开窗帘与柜体模板。当前为92个型号／结构配置：14组Blender资产、78组参数化配置，包含新加入的Y00Y06045／Y00Y06058转角书柜、叠放方凳，以及左右完整洗衣区、L／U形厨房。型号数量不等于产品type数量，多个模板可共用同一类型。

```powershell
# 沿用项目 Playwright 配置，可使用已安装的 Edge。
$env:FURNISH_BROWSER_CHANNEL = 'msedge'
node scripts/verify/verify-model-pipeline.cjs --list
node scripts/verify/verify-model-pipeline.cjs all gpu
node scripts/verify/verify-model-pipeline.cjs y52y09 gpu
node scripts/verify/verify-model-pipeline.cjs fridge,corner-bookcase,table_folding_1100 gpu
```

设备可选`auto`／`gpu`／`cpu`，报告区分请求与实际设备。显式`FURNISH_BLENDER`优先，其次Scoop `apps/blender/current/blender.exe`，商店入口为备选，不固定版本目录。不自动更换Blender版本重试。

运行目录为`output/model-pipeline/all-<随机后缀>/`或`selection-<随机后缀>/`。批次只有一个私有工作副本；各配置拥有独立运行目录、阶段日志、报告和导出产物。失败配置不标为通过，继续检查其余配置，批次最终返回失败。此前失败或中断的目录保留。

```powershell
# 只在程序、应用／验证代码、设备及输入校验一致时续跑。
node scripts/verify/verify-model-pipeline.cjs all gpu --resume=output/model-pipeline/all-XXXXXX
```

续跑校验源码指纹、实际Blender二进制、设备和逐配置定义；通过项仅在定义不变时保留，失败项写入新的尝试目录。商店别名无法读取实际二进制时不允许自动续跑。共享专项测试只有代码和当前运行资产哈希一致才复用结果；每配置的空间检查、应用、导出、回读、三张渲染及下载工程重开仍单独执行。

## 两条路线

| 路线 | 必须实际执行 | 不适用项 |
|---|---|---|
| Blender资产 | 新目录后台作者预检／建模 → 保存BLEND／GLB → 独立进程严格发布 → 私有副本标准路径装配 → 生产导出／Blender回读 → 三机位正式API渲染／下载工程重开 | 无 |
| 既有参数化模型 | 原生产构造与结构专项 → 数值实体／尺寸／状态检查 → 双入口正式生产GLB → Blender逐部件回读 → 三机位正式API渲染／下载工程重开 | 作者与离线发布记为`not-applicable`，不伪装成完成Blender重建 |

源仓库的14组正式JS／GLB／BLEND及真实方案在批次前后校验SHA256，验证器只在私有副本发布新资产。首个合法资产的创建和新产品注册仍按原建模流程完成；这里是已注册模型的整链路复验，不是任意模型导入器。

## 按结构适配

- **固定外形、安装设备**：尺寸／安装基准与生产构造同源。顶装浴霸、面板灯和筒灯增加底面机位；分水器、电箱、水槽、花洒等继续采用各自安装和几何专项，不套用洗衣机外包框。
- **具名板件**：Y52Y09保留柜体生产身份，核对12块实际导入的曲边BufferGeometry、六格、板厚、净距与穿板；不能要求它改用其它资产的`explicit:`身份。L形转角书柜核对14件源资产、五层／交替端板及L形空缺。
- **活动件**：冰箱左右门／上下抽屉、烟机上翻面板、洗衣机圆门和边几抽屉使用各自字段、轴向、刚性拟合和完整扫掠专项。洗碗机双片折叠继续验证两个可信端态，不把插值称为真实连杆轨迹。
- **叠放**：方凳导入5件单把资产，另测四把20件的生产装配，数量／增高／总高及安装高沿共享产品规则；不将模型数量范围解释为实物安全叠放上限。
- **参数化产品与柜体**：折叠餐桌、茶吧机、窗饰、口袋／联动门及柜体开合分别取自己的状态；定制板厚、空腔、门抽和结构仍由原核心派生。电视沿原16:9与历史`h`契约，验证缩放时宽高关联，不要求独立拉伸屏高。
- **组合与身份**：完整洗衣区保留主柜、附属洗衣机及关联数据，导出和回读覆盖所有成员，以`家具ID+板件键`识别。左右洗衣区、L／U形厨房及高低柜分别核对。厨房抽屉通过核心接口开启，不能只写一个构造器未读取的字段。重复形状的口袋墙板采用物理侧／面／门扇身份，不能靠当前坐标、遍历序号或放宽重复身份检查通过。

每项均执行`test-model-profile-spatial.cjs`：当前／另一合法状态、0°与37°镜像、生产实体、外部间隔、包络包含、真实部件穿入、高度分离和项目往返；另运行清单里的结构专项。`FurnishSnapping.directional()`与`FurnishGeometry.bodyParts()`继续提供公共能力，不新增按型号放行的碰撞豁免。方向测距沿现有保守轮廓／高度裁剪语义，不把包络内边距当作柜内净空。

## 作者预检与实际生产证据

所有14组资产作者在保存／导出前消费具名部件与rig契约，检查米制比例、有限坐标、非空网格、身份唯一性、当前发布器声明的材质槽与面索引、静／动归属、世界轴心、轴向和嵌套层级。错误包含对象名；检查不自动修补未知工程。多材质产品须另行声明适配，不能套用当前发布器的单材质限制。独立发布器仍检查尺寸、几何、材质与来源哈希。

`verify-asset-contract.py`重开新源工程逐例注入空材质、错误面索引、错误身份、单位、非有限顶点、未知部件；有运动rig时另测错误轴向、轴心与脱离随动。每例重新加载，故障工程不保存。

浏览器用静态只读服务和断网`file://`验证尺寸编辑、撤销重做、刷新、窄屏、无外部请求／脚本异常及正式生产导出。GLB证据读取真正的层级世界矩阵、部件身份／边界及Alpha；显示竖向包络须位于数值实体高度内，检查公差2mm用于目录取整与浮点误差，不是安装预留。Blender独立回读逐部件对照世界边界及Alpha；之后重开API下载的BLEND，复核同一几何、相机、Cycles和分辨率。

缓存复用的推拉门可能在保存开关后继续播放动画。导出前将实际GLB各部件的世界包络与当前目标数值实体逐片对照，等待达到端态，记录`settledPoses`；偏离、空集合、成员或数量不符均不通过，限时失败，不强改网格或读三维私有闭包。整体包络相同和Blender回读一致，都不能代替目标姿态正确。`test-model-endpoints.cjs`含总包络不变但门片位置错误的负例。

## 三机位与视觉验收

`model-studio-v2`以标称和操作状态的**实际生产顶点联合包络**构造固定方向的正面、斜视及开合／背面／底面机位，36°、方形512px，完整操作部件入镜。固定白色主光2000lux，AgX、曝光0，复用正式基础渲染API的世界光；不修改真实户型、用户机位、全局灯光或精修工程。

隔离场景保留明确坐标基准，将锚定墙放到镜头范围外，并排除隐藏建筑件，避免测试墙或隐藏吊顶遮挡大型模型。图像用于检查轮廓、分区、部件与开合，须目视核对；自动通过不等于照片级还原批准。基础对照图不是1601精修效果图，Alpha近似不等于物理折射，跨Blender／GPU版本不做严格像素相等承诺。

## 本轮发现与边界

生产／数值对照发现五类百叶／升降帘的局部实体漏加安装高。产品规则现在声明`solidModel.base:'mountHeight'`，共享记录器在世界变换时加一次；显示原位置保持。缓存读取声明，相关空间确认追加定向语义，价格／配色及其它型号不失效。三高度×三姿态×旋转镜像的真实Three包络与数值实体对照、穿入／高度分离和重复恢复已设回归。

双侧双扇与单侧三扇口袋门的重复生产身份由物理侧／面／门扇键修正，原空间几何不变；严格重复身份检查保留。单双开布帘将轨道杆与杆头纳入原保存外高，帘布不变；软帘保留原有碰撞处理。五类升降帘只检查各姿态实体，已有洗碗机双片折叠门仍按可信端态验证，这些均不代表连续机构的任意组合全过程已验证。

台上盆龙头手柄从外高中心下移半厚4.5mm，使整体外高纳入既有数值包络，不扩大碰撞规则或改变保存尺寸。多个盆高／台面标高的真实包络回归见`test-laundry-resize-vessel.cjs`。

本入口覆盖清单中的型号与结构配置，不等于穷举全部尺寸／柜体参数组合、全部GPU或全屋性能基准；真实五金、实物限位、施工和承重仍按各型号资料边界判断。历史单款记录保留于[2026-10-30](validation/model-pipeline-20261030/README.md)；本轮完整批次记录按实际结果归档。
