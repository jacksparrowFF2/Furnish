# 2kg 紫白猫粮袋

用户图1的2kg通用自立袋标注为260×400+120mm。本模型采用宽260、深120、高400mm的展开布局包络；不是图2麦富迪商品的厂家实测外包或容量认证。图2仅作为紫白配色与印刷外观参考，两张原图保存在[资料目录](../assets/models/cat-food-2kg/references/)。

独立类型 `cat_food_myfoodie_2kg`，家具库「猫粮袋 · 2kg紫白参考」。正面局部+Z，底部离地沿原mountHeight、新建0；机身高与离地独立。默认操作预留0仅表示未建模开袋动作。尺寸编辑是布局缩放，不代表更换真实包装规格。

Blender闭合软袋壳、鼓起正背面、收拢封口、两条贴面凸起拉链及紫色侧面。正面图案由用户照片做分段边缘透视校正，印刷保持照片中的细节及光影；看不清小字不重新编造。反面没有照片，采用无文字紫白示意；侧面不复刻未完整展示的营养表。褶皱、封边宽度和膜材粗糙度是视觉估算，未模拟膜厚、软袋变形、剩余粮量或开袋状态。

`storageSupplyRevision=2`复用现有v57能力选择（含pose3D时沿既有v58）。没有新持久字段、保存或撤销通道。产品规则、目录、静态生产构造器和现有数值实体共用；离线标签仅为本型号启用768²内嵌RGBA与UV，原静态无贴图发布器范围不变。通用二维矩形占地及逐部件保守包络供测距／碰撞，不提供袋内空腔。
