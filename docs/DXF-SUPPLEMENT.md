# DXF 图层补导入与水气竖管

FurnishDXFOutline.append() 复用首次轮廓导入的 sourceUnits 与 sourceTransform（x0、y1、pad、scale），禁止重算原点和范围。投影保持原草稿坐标，build 按当前标定转换为 mm。源墙轮廓不一致、缺少坐标基准、梁不闭合或超出画布均原子拒绝。中心线导入旧项目暂不支持。本入口不能删除或更新已导入图层，墙层变化仍走完整结构导入。

梁保留来源和未知高度，重复追加保留已录入高度；新梁仍需在项目工作台录入梁底／梁顶。水气点位保留原图圆半径 radius；pipeDiameter 是独立展示管径，缺失为用户指定的 100 mm。sourceAt 保留编辑前来源位置用于去重，移动点位后重复追加不覆盖位置或管径。新字段随原项目与命名方案保存，旧数据无需迁移。
