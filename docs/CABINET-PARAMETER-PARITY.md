# 柜型参数与生产模型复核（2026-11-07）

本次沿共享组件逐一检查全部21个模板的编辑、保存与生产板件，再检查厨房地柜／吊柜模块和洗衣附属柜。保留原方案，不把功能不同的柜型强制转换为普通木箱。

## 当前入口和适用范围

| 参数 | 普通柜、衣柜、书柜、电视柜等 | 置物台／分层餐边柜 | 厨房／洗衣柜 |
| --- | --- | --- | --- |
| 背板厚度 | 整柜“背板与净深”，0–50mm、小数、0无背板 | 相同入口，作用于实际分段背板 | 整柜默认、模块覆盖、末端与附属柜；附属柜可进入相同详细编辑 |
| 净深 | 按背板内面与闭合面板计算 | 开放区、上下柜深度、展示区及设备空位分别计算 | 派生模块调用同一核心截面；不把空设备位封上背板 |
| 柜门方向／角度／铰链限制 | 选门后编辑当前门扇，门组与默认值在高级选项 | 上下柜、展示门分别控制，保留原门组语义及逐扇限位 | 普通模块选门编辑；保留结构和附属柜进入同一柜体详细编辑 |
| 面板外观、颜色、把手 | 柜门和抽屉属性均可访问共享外观控件 | 相同控件，默认长条／圆钮／无把手与模型一致 | 普通门柜／抽屉模块补同一控件；保留结构沿内部编辑。恢复默认不写假覆盖 |
| 线性抽屉拉出程度 | 选抽屉后0–100%，按分列独立 | 相同百分比控制，层高仍共用该层 | 地柜与吊柜补0–100%；生产抽盒按同一行程计算 |
| 抽屉结构 | 保留原层数、分列及高度范围 | 餐边柜只有一排浅抽，已有一排时禁用“添加抽屉”；冰箱位无抽屉并说明原因 | 保留总分层高和五金配方；碗篮固定三层、关闭外抽联动关闭内抽 |

净深是结构计算结果，不能输入一个与实体板件矛盾的独立数值。无门区不扣门厚；预览隐藏门不改变闭门容量基准。洞洞板独立板件不虚构柜腔。固定成品Y52Y09的背板只读，界面显示产品构造说明。

玻璃饰面用于柜门，抽面仍按板面颜色绘制，控件注明范围。逐扇不等宽继续沿已有厨房多扇侧开门能力；不扩展到固定展示门框或其它受限配方。上盖抽屉／洞洞板检修盖沿专用机构，不把角度开盖伪装成线性抽屉。

## 本次修复

1. 分层餐边柜删除独立把手设置后，原UI显示默认长条，但生产构造因缺失字段而不生成把手。现在读同一默认，缺失与显式长条实体一致；受影响配置的空间上下文增加 `default-bar-v1`，原圆钮版本保持。
2. 普通柜内嵌抽面原来忽略隔间设置的面板颜色，现在全盖／半盖／内嵌使用同一面板颜色。
3. 抽屉检查器原来只能改高度与开合，面板外观藏在门属性里。现在移动同一组外观控件到当前抽屉高级选项，不复制字段或保存通道；柜门、抽面仍共用隔间外观。
4. 厨房普通模块原来没有外观入口，抽屉只有全开／全关。新增模块可选 `finish`／`handle`／`doorColor` 与 `drawerExtensions`（各层0–1），通过 `kitchenModuleConfig` 传给共享生产组件。普通抽屉与碗篮均按实际百分比移动，完整开启预留仍按最大行程核对。

开合按钮与普通柜一致：关闭后重新打开沿用上次非零比例，比例为0时恢复全行程；旧缺失比例仍为全行程。改层数拟合百分比数组，改抽屉样式清除旧开合数组，改为非抽屉角色清除百分比；转为保留结构时，外观存于子柜，清除模块外观覆盖；设备空位清除不适用外观。采购规格不计当前拉出程度。
