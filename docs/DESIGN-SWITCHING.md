# 同户型设计方案与历史记录

2026-10-30

常驻栏位于主工具栏与工作区之间，2D／3D 共用。仅列当前户型的设计方案；窄屏横向滚动按钮，显示当前选中项。新方案复制当前工作内容并立即进入该方案，首次创建前也为原当前布置保留独立方案。管理提供名称／备注、复制和删除。

方案与历史统一从常驻栏「管理」进入。顶部保存状态可点击查看保存详情、位置与历史备份；独立「导出」只提供文件输出。「更多 → 数据恢复」包括自动快照和本机恢复副本；JSON导入与编辑户型在「更多 → 项目与户型」中，「更多 → 重置与清理」保留原重置与清空流程。原三页签弹层和文件菜单中的管理／历史保存入口已取消。

## 保存与恢复

- `designs[].editable: true` 表示可编辑设计方案；缺失或 false 为历史记录。已有命名方案全部按历史保留，不根据名称推断角色，不改写真实项目。
- 可选工作区 `activeDesigns[planId]` 保存当前设计 ID。`store.work[planId]` 仍是当前工作槽；原 `save()` 调用核心 `saveActiveDesign`，仅当内容变化时深复制到该方案并更新时间。缓存、IndexedDB、正式文件及保存失败提示沿原实现。
- 新建、复制采用既有 `manageDesign` 校验。新建和保留原布置先走 `fixWork`，避免初次恢复补三维默认值导致项目导入产生重复版本。新增字段不进入模型／碰撞／空间确认输入。
- 切换先恢复及校验目标、保护原始结构，保存原方案和恢复点，然后设置绑定、清除选择及撤销重做栈、刷新生产画布／3D。切换本身不进入编辑撤销栈；当前方案内的编辑及历史恢复可撤销重做，不能跨方案撤销。恢复点仍沿原每户型最多 8 条的链路。
- 历史记录不出现在切换栏，也不被自动保存覆盖。可恢复到当前方案（恢复前保留恢复点，可撤销），或复制为可编辑设计方案。复制后可在常驻栏选择。自动恢复点继续按户型保留，不新增历史数据库。
- 删除当前设计时保留当前画布并解除绑定；下次切到其他设计前保留这份当前布置。新增方案和历史仍共用原每户型 100 条上限，达到上限时拒绝操作并保留数据。

## 数据边界

`editable` 是原 designs 记录的可选元数据，项目 pack/unpack、复制户型和导入合并保留。相同内容但不同角色不相互去重。工作区校验拒绝非法标记、跨户型／缺失／历史方案绑定。可选字段兼容旧存档，不提高几何格式版本；旧程序不会提供本轮独立编辑语义，避免同时用旧页面编辑同一文件。

项目导入及分享导入解除目标户型的当前绑定，载入为当前布置，防止覆盖某个现有设计；其余可编辑方案继续保留。整工作区恢复保留 activeDesigns。切换户型前保存，返回后沿原 work 槽及对应绑定继续编辑。无新的加载脚本、构建工具或自动保存／撤销通道。
