# 材料采购规格与价格依据

## 数据契约

可选 `work.pricing.materialSpecs[materialId]` 保存单片 `length`、`width`（mm），可选 `pack`（每箱整数片数）、`waste`（0–100%，缺失沿用全局）和 `unit`（`m2`／`piece`／`pack`，缺失为 `m2`）。规格缺失保持原面积法，不为旧项目补尺寸。按片／箱计价必须录入 `pricing.materials[id]` 的对应单位单价；按箱还必须填写 `pack`。

规则和校验共用 `FurnishProject.pricing()`、`materialQuantity()`、`estimate()`。当前预算、方案比较、报价 CSV 和成果报告均读取同一估算。改全局预算参数保留单独材料规格；显式恢复材料面积法同时恢复其平方米参考价。

净面积 A、损耗 w、单片面积 S 的所需片数为 `ceil(A × (1 + w / 100) / S)`，已录入每箱片数时再向上取整箱数。平方米单价也按整箱实购面积计价；按片单价使用整箱内实际片数。没有箱规格则只向上取整片数。浮点容差只抵消数值运算误差，不向下舍弃实际缺料。

示例：20 m²、10% 损耗、600 × 600 mm、4 片／箱 → 62 片 → 16 箱 → 实购 64 片、23.04 m²。这是面积法采购估算，不包含铺排、裁切、余料复用、包装外的运输破损或厂商订货限制。

## 价格依据

家具显式 `price`（含 0）为已确认单价；已有参考金额为参考价，没有参考或实际价格为未填写。材料显式 `pricing.materials[id]`、显式涂料 `paintPrice` 及录入的工程单价计为已确认。缺失字段继续读取历史参考值，粗估总价保留；另显示已确认金额及参考价／未填写项，允许按依据筛选和定位。

只编辑材料规格不会补写 `paintPrice`，避免把未确认的历史默认涂料价格误标成已确认。采购进度和价格依据分别表达，已下单不替代单价录入。

## 兼容与验收

字段沿用 `pricing` 的项目、工作槽、命名方案、恢复点和撤销快照，不另建保存通道。导入校验拒绝非法规格、缺失对应片／箱单价；恢复不补字段，重复恢复无漂移。材料字段不进入家具几何缓存或空间确认输入；复制／替换家具不影响材料采购参数。

回归：`tests/test-material-purchasing.cjs` 验证旧面积法、零损耗／零单价、取整边界、箱数、计价单位、非法输入、命名项目往返和重复恢复。浏览器验证实际录入、预览、应用、撤销／重做、刷新、默认涂料价仍为参考价及 390 px 表单。
