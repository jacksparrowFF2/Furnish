# 材料采购规格与价格依据

## 数据契约

可选 `work.pricing.materialSpecs[materialId]` 保存单片 `length`、`width`（mm），可选 `pack`（每箱整数片数）、`waste`（0–100%，缺失沿用全局）和 `unit`（`m2`／`piece`／`pack`，缺失为 `m2`）。规格缺失保持原面积法，不为旧项目补尺寸。按片／箱计价必须录入 `pricing.materials[id]` 的对应单位单价；按箱还必须填写 `pack`。

规则和校验共用 `FurnishProject.pricing()`、`materialQuantity()`、`estimate()`。当前预算、方案比较、报价 CSV 和成果报告均读取同一估算。改全局预算参数保留单独材料规格；显式恢复材料面积法同时恢复其平方米参考价。

净面积 A、损耗 w、单片面积 S 的所需片数为 `ceil(A × (1 + w / 100) / S)`，已录入每箱片数时再向上取整箱数。平方米单价也按整箱实购面积计价；按片单价使用整箱内实际片数。没有箱规格则只向上取整片数。浮点容差只抵消数值运算误差，不向下舍弃实际缺料。

材料预览增加按房间净面积、含损耗面积和参考片数，并显示合并采购的面积余量和整箱多出片数。`FurnishProject.materialBreakdown()` 共用全屋估算；各房间片数用于分区核对，采购仍按同材料全屋合并取整，不累加各房间独立整箱数。可导出已保存房间用量 CSV；未应用的表单预览不混入导出。成果报告同步包含分区用量。面积余量不等于已裁切的可复用余料。

示例：20 m²、10% 损耗、600 × 600 mm、4 片／箱 → 62 片 → 16 箱 → 实购 64 片、23.04 m²。这是面积法采购估算，不包含铺排、裁切、余料复用、包装外的运输破损或厂商订货限制。

## 价格依据

家具显式 `price`（含 0）为已确认单价；已有参考金额为参考价，没有参考或实际价格为未填写。材料显式 `pricing.materials[id]`、显式涂料 `paintPrice` 及录入的工程单价计为已确认。缺失字段继续读取历史参考值，粗估总价保留；另显示已确认金额及参考价／未填写项，允许按依据筛选和定位。

只编辑材料规格不会补写 `paintPrice`，避免把未确认的历史默认涂料价格误标成已确认。采购进度和价格依据分别表达，已下单不替代单价录入。

## 兼容与验收

字段沿用 `pricing` 的项目、工作槽、命名方案、恢复点和撤销快照，不另建保存通道。导入校验拒绝非法规格、缺失对应片／箱单价；恢复不补字段，重复恢复无漂移。材料字段不进入家具几何缓存或空间确认输入；复制／替换家具不影响材料采购参数。

回归：`tests/test-material-purchasing.cjs` 验证旧面积法、零损耗／零单价、取整边界、箱数、计价单位、非法输入、命名项目往返和重复恢复。浏览器验证实际录入、预览、应用、撤销／重做、刷新、默认涂料价仍为参考价及 390 px 表单。
## 本地订单、到货和实付

`work.purchaseOrders` 为可选订单数组，新工作默认缺失、按空台账使用；旧恢复不补写字段。订单包含 `id`、`number`、`date`、`vendor`、`note`、`shipping`、`discount`、`paid` 和 `lines`。日期为有效 YYYY-MM-DD 或空；最多 200 单、每单 200 行、合计 2000 行。付款为累计实付，不通过采购状态推定。

每行包含 `kind`（furniture/material/other）、`target`（家具实例编号／材料编号）、下单时 `name` 和规范键顺序的完整 `signature`、`unit`、`quantity`、`received`（累计到货）和 `unitPrice`。家具单位为件、材料为当前 m²／片／箱、其他费用为项。除 m² 外数量为整数，到货不得超订；单价须显式录入，0 元有效。价格、运费、优惠、实付精度为分；每行金额先四舍五入到分再累加订单总额。优惠不能使总额为负，实付不超订单总额。退货、退款、多币种和付款流水尚未建模。

`purchasing-core.js` 共用校验、需求、规格快照和汇总。家具复制的新实例不会继承旧订单关联；移动、显示旋转及价格不改变商品快照，柜门／抽屉的临时开闭通过生产 specification 排除。替换商品、尺寸、品牌、型号或材料计量规格变化要求重新关联。删除对象或不匹配的历史行保留金额、提示待核对，但不抵扣当前需求。订单编辑选择新的当前项目是显式重新关联，保留历史选项则不改原快照。复制整个自定义项目保留内部实例编号与订单关联。

每行当前需求与有效订单合并比较，显示已下单、累计到货、待到货、还需下单及超订。地面材料数量使用同材料全屋合并采购量；涂料／施工可以其他费用行记录，暂不推算剩余数量。金额显示全屋预算参考、订单总额、累计实付、订单待付款和预算减实付，后者不是最终结余。

`purchasing-tools.js` 经 `mutate()` 保存、编辑、删除，沿用工作槽、撤销、恢复点、命名方案及完整项目。删除可撤销。采购编辑不进入空间确认或三维几何签名。台账 CSV 的订单总额和付款只在每单首行出现，避免按行重复累加；成果 HTML 同步附上进度及订单摘要。
