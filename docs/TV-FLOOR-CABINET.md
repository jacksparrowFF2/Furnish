# 落地电视柜 · 上盖抽屉藏线

用户提供的三张图片为外观依据；用户进一步确认中间部分像抽屉向前拉出，而不是上下翻盖。模型采用顶板、前板与托盘一起水平抽拉，关闭时齐平；后侧敞开，中央顶板后侧有走线留缝与梯形缺口。未建模墙上插座，需在房间中单独配置。

从家具库「柜体」添加「落地电视柜 · 上盖抽屉藏线」，或在已有电视柜「柜体详细设计」中选择此模板。每个分区的「顶板结构」可切换固定顶板与上盖抽屉；可设置后侧留缝，点击顶板、抽屉前板或表单按钮收回／拉出。保存沿用柜体撤销、自动保存、复制及项目导入流程。

| 参数 | 起始值 | 依据 |
|---|---|---|
| 宽 × 深 × 高 | 3000 × 400 × 240 mm | 可调草模假设，图片未提供可靠尺寸 |
| 板厚 | 18 mm | 项目柜体默认值 |
| 底座 | 0 mm | 图片显示贴地，精确结构未知 |
| 分区 | 5 | 外观近似，可调；中央为上盖抽屉，两侧四格为普通抽屉，台面固定 |
| 中央后侧留缝 | 30 mm | 用户图片标注 3 公分，其余分区默认 0 |
| 缺口宽／深 | 最多 120／15 mm | 外观估算，随小分区限制 |
| 抽拉行程 | 柜深的 70% | 项目既有抽屉规则，未指定滑轨型号 |
| 默认颜色 | 木色结构与顶板、白色抽屉前板 | 按用户要求与所有柜体模板统一；无精确木纹／厂家材质 |
| 价格 | 未知 | 未提供，不设置估算单价 |

局部正面为 +Z，底部为地面 0，关闭外包按 w/d/h 计；抽拉预留独立计算。上盖抽屉不与同分区的柜门、固定层板或普通抽屉混用。后侧留缝 0–100 mm，并受柜深与板厚约束。开合不改变采购规格，旧柜体缺少这些字段时保持原有结构。

生产模型预览：`output/tv-floor/preview.html`，由 `node scripts/preview-tv-floor.cjs` 生成。测试 `tests/test-tv-floor.cjs` 覆盖水平位移、保持高度、贴地与关闭外包、实际开口射线、导出导入、缩放、非法配置、旋转镜像后的抽拉空间及采购分组。空间检查沿用抽屉开启占地与前方 800 mm 操作净距；这是平面检查，不核验插座位置、滑轨安装或实际承重。

抽屉侧板与底板的前端对齐前板内表面，普通抽屉后端对齐后板内表面；所有部件随同一抽屉组移动。`tests/test-cabinet-drawer-joints.cjs` 检查 12／18／30 mm 板厚下的连接面，并覆盖普通抽屉关闭、半开、全开与中央上盖抽屉开合，防止拉开后前板与托盘脱节。
