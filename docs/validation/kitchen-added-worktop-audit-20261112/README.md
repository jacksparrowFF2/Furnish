## 发现

1. **新增独立柜箱没有被厨房台面覆盖。** `kitchen-core.slabs/outline` 仍只派生原各排模块及末端延伸，没有读取 `kitchen.assembly` 的新增柜箱。新增箱本身在生产网格和保存数据中存在，但箱顶及前沿出挑处均没有实际石材。48组一字／L／U形、左右转角、0／37／90／270度和镜像全部复现。见[核心与生产射线结果](core-results.json)。
2. **厨房不能执行按柜箱轮廓重生成。** 结构树的台面编辑入口只在 `isLaundry` 时显示；共享 `generateWorktop/setWorktop/validateWorktop` 同样限定洗衣柜。直接对普通厨房调用生成会报“请选择已解锁洗衣区”，不是生成成功。三种厨房在HTTP、断网file、同一打包桌面EXE的隔离副本全部复现，见[界面结果](ui-results.json)。

因此，“重复生成不会累加”在普通厨房暂无可执行入口，**此项不能判通过**。反复 `Kitchen.configure` 五次并读取生产几何是稳定的，但始终忽略新增箱，并不能替代真实生成验收。
