## 正式生产复核

- 作者预检、六种预检负例、独立发布、实际实体量测、间隙、碰撞、旋转镜像及项目往返通过。
- HTTP 和断网 `file://` 下的生产网格加载、撤销重做、刷新和 GLB 逐件回读通过。生产三机位与可下载工程重开均保留 10 个稳定部件。灯光专项通过背向光、0% 和 20% 预览及共享光度换算。见 [验证摘要](verification.json)。
- macOS 桌面快捷方式指向的打包程序在隔离工作目录中核对了家具库、¥61.20、底部离地编辑及撤销重做、预览亮度、保存重开和三维。
- 整屋复验发现米家夜灯与 G12 复用了同名照明定义，造成 G12 面板被错误分派。米家构造器现在按独立型号族识别，照明定义采用本型号字段。普通斜五孔与 G12 小夜灯的分派负例及 G12 全部 37 种生产款式专项通过。
- 本次执行夜灯增量检查。窄屏与项目全量检查未执行。实物测量、充电插头净空和实测墙面配光未执行。用户目视确认待反馈。
