## 识别特征与假设

- 卷纸：实际外径和高度按用户值，9卷各为独立具名闭合环网格；中心孔直径24mm为视觉估算。3×3×3排列是装箱示意，无纸箱或层间包装间隙。
- 抽纸：单包外包按用户值，六包分两排三列，包体、上封边、抽取口分层；圆角、绿色包装、抽取口均为示意，没有品牌小字或认证信息。
- 湿巾：用户外包尺寸闭合，软包／封边／框／闭盖四部件；盖子尺寸、开向和配色为视觉估算，不提供开盖运动能力。
