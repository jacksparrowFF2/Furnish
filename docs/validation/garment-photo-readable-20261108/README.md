# 衣物照片发黑修正（2026-11-08）

用户报告正反都呈黑色。最初把原因归为背面不充分：隔离正式桌面读出三款body为白底材质、map存在、UV存在；旧版正面仍明显偏暗，背面固定UV仅显示一块纯色。没有在用户当前窗口内读取私有网格，也不宣称已直接复现其正面全黑的全部环境条件。

v5两大面复用同一张正面商品参考图，侧边素色；只对衣片使用照片emissiveMap强度1，保留照片原有明暗，不修改全局灯光或其它产品。背面是双面参考卡，不是实物背照，不能据此判断背部结构。这个近似服务于用户授权的衣柜照片厚片布局，不是物理布料材质。未知真实背面、厚度等仍沿型号文档。

通过：

- 三款Blender 5.2.3 LTS作者构建及独立GLB发布检查，源保存为v5，旧v4保留。
- `geometry.json`按原版逐值对照尺寸、位置、法线与稳定身份，JSON数值语义下完全不变（正负零等价）；纹理RGBA字节完全相同。只变材质与背面UV，不升级空间几何版本。
- `test-garment-photos`：双面UV覆盖、仅衣片照片亮度补偿、挂钩不受影响、源哈希、厚度／离地／旋转镜像、间隔碰撞与项目恢复。
- `test-garment-photos-desktop`：同一打包EXE，冻结正式文件副本，正反面截图，六个生产部件，撤销重做、厚度与离地、保存刷新、390px窄屏及脚本错误检查；副本源哈希不变。见desktop.json。
- 三款新源GLB及桌面生产导出经独立Blender导入，确认衣片基色和发光通道引用同一照片、强度1与UV均存在；见readback.json。实际导出包含建筑和其它家具，只按照片材质限定三款，不将其它对象算为衣物。
- 语法检查与模型索引一致性检查。
