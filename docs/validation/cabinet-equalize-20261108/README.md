# 分格、柜箱与固定层板均分

2026-11-08，基于已汇总的衣物／阵列成果继续实现。此前只有属性区底部的活动层板均分。新入口常驻画布工具栏下方，无需展开显示选项或滚动右侧属性：左右分格、柜箱等宽、活动层板、固定层板四个按钮及柜箱范围选择。

## 尺寸与范围契约

- **左右分格**：当前柜箱内竖隔板按顺序整体重排，内部净宽相等。公式为`(柜箱外宽−两侧板厚−全部竖隔板厚)／隔间数`，不是将隔板中心距离简单等分。柜箱外宽、板厚、深高及隔板ID保持，隔间仍沿原稳定ID绑定门、层板、挂衣杆和抽屉；子组件随新净宽重建。
- **柜箱等宽**：按箱体外宽均分，不含外挂收口板，保留所选箱体宽度总和、各自板厚／深高／连接／拼缝／收口。默认“当前横排”是通过左右连接相连的柜箱；“整组柜箱”包含上下柜。上下错位与不同排数量可能改变整组外包宽度，面板操作前显示目标箱宽及整组外宽前后值，不宣称任何组合都保持总外包尺寸。没有新增自由位移或覆盖原连接树。
- **活动层板**：保留原当前隔间入口，其他类型层板及抽屉等作为结构边界。按钮移至常驻栏，属性区不再重复出现同名入口。
- **固定层板**：当前隔间的结构横板及开放区上下边界一起参与，活动层板及其他非参与组件保持。以各可用结构区为单位，扣除目标板实际厚度后使净高相等；开放区边界变化沿原from／to联动净高、灯带和侧／背开口。不是将边界板改成活动板。

层板均分读取闭合生产板件。挂衣杆按真实截面切分本次编辑的可用区域，不把它加入普通储物尺寸的“承托板”列表；抽盒沿原实际占高区域划界。单个结构区不足40mm最小净高、待均分板与非参与结构重叠、缩窄后并列抽屉不足100mm等情况整次拒绝，原数据和历史保持。宽度或高度的均分不承诺消除原有布局问题，也不替代完整开启核对与五金／承重验算。

每次按钮操作为一条草稿历史，应用柜体后沿原mutate记录一条应用历史。范围选择只影响工具状态。零效果操作不给柜箱增加新字段，重复均分不漂移。没有新增持久字段、格式版本、加载脚本、保存通道或自动方案转换；原空间配置已包含隔板位置、板位置及箱宽，缓存和核对记录沿该链失效。

## 生产与数据验证

- `test-cabinet-equalize.cjs`：五类操作×旋转／镜像／离地共60组，核对真实Three侧板／竖板／板面之间的尺寸，120块水平板的净高，选定柜箱宽度总和与非目标参数保持。覆盖不同板厚／深高、上下组合、收口及拼缝；杆件边界、等于40mm与略低于阈值、并列抽屉装不下的原子拒绝。门段／门扇／抽出参数保持，生产身份稳定，项目当前／命名／整柜复用及三次恢复无漂移，重复操作幂等。
- `--equalize-only`：四类入口首屏可见且独立于折叠显示选项，活动均分不再藏于右侧；检查左右净宽、横排／整组外宽、固定板与开放边界净高、活动板保持、杆件分区、单步撤销／重做及失败不产生历史。新净宽下实际预览门扇由35°关闭至0°（实体深18mm）、再打开至90°（实体深等于新门板宽），逐扇恢复35°后保存。刷新后逐字段相等，并将所有板件从正式场景GLB逐ID／部件键匹配到目标几何，容差0.04mm。另检查390px无横向溢出及四按钮可发现。
- Node增量：builder、builder-editing、builder-upgrade、builder-multidoor、builder-open-zones、drawer-position、horizontal-editing、component-edit、component-parity及相关脚本语法／差异检查。没有跨加载／恢复机制变更，未运行全项目check；参数化编辑不适用Blender资产重建。

测试以正式文件固定快照在独立工作目录、缓存与端口执行，同版打包EXE不操作正式窗口；源快照哈希保持。用户原方案及草稿未通过本轮测试修改。
