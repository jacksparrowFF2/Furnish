## 可复用流程与本次修复

- `asset_pbr.py`分型号／具名部件接收常量物理扩展：TG保留受限透射／IOR／体积；冰箱只对white、screen，油烟机只对black、glass开放clearcoat。油烟机黑玻璃不冒充透明窗，滤网／裸钢不套涂层。其他profile不放宽，纹理和任意节点仍不在发布范围。
- 冰箱、油烟机真实构造器接入共用`createMaterial`，全局材质缓存、生产GLB与Blender实际回读一致。兼容PBR常量随资产传递；程序微表面保存在精修工程，未烘焙为网页纹理。
- 修正棚拍负反射卡误被地面材质覆盖；A/B保持同一生产几何、机位、灯光与曝光。基准模板只迁移上一版的具名材质绑定，不迁移旧几何或旧灯光。洗衣机材质A/B共同使用修复后的玻璃，因此另列上一版原始图说明几何伪影，不把它冒充同光材质A/B。
- 发现旧空间确认仅在`washerGeometryVersion===2`时加标记。现按实际型号／实例／几何版本派生；TG几何版本升4，缓存与旧确认失效。非空间编辑、通用洗衣机及无TG的项目保持原确认语义。未改变原尺寸、吸附、测距与碰撞算法或制造安装要求。
- 光学玻璃中心不能用一圈重合顶点及零面积面直接平滑。检查拓扑与法线，再调整粗糙度／灯光；真实旧v3负例和新v4通过见[法线回归](optical-normals.json)。诊断中曾临时隔离射线，最终交付未对旋钮或其他部件使用这些隔离设置。
