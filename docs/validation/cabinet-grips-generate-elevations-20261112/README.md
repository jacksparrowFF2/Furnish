# 柜箱外边手柄、布局台面与分边视图

2026-11-12。合并用户连续补充的四项要求：2D外边手柄跟随新增柜箱；单柜箱不重复显示组；台面按柜箱组成轮廓重新生成，重复点击不累加；L型两正视／回型三正视合理利用预览区。

## 行为与边界

- 用户明确选择：拖动新增外边，只调整该外边对应的新增柜箱，原柜与台面保持独立。共享核心以实际组合外包和新增柜箱位置确定唯一外边归属；2D在该柜箱实际外边显示专用手柄，移除同方向旧宿主手柄及误导性的双轴角点。拖动按抓取起点的世界位移，转换为柜箱自身宽／深，固定其对侧；新建独立Snapping入口复用已有栅格／墙家具吸附求解器。沿原画布commit、撤销、重做和保存，不触发拖完后整件推离墙体。尺寸超限沿原组件规则拒绝，不部分写入。多个新增模块同时定义同一外边时不猜测归属；转到明细编辑，不做整组等比缩放。
- 单一柜箱模块：移除重复的模块标题行，直接用同一柜箱叶节点承接选择，部件在下方缩进；多个柜箱的模块仍保留组层级。原吊柜、开放柜的安装位置字段在合并后仍可编辑，稳定ID和草稿选择沿原通道。
- “按柜箱轮廓生成台面”：从原默认台面区域重新开始，合并顶部恰好到台面底部的柜箱投影；高度比较容差0.01mm，原吊柜／错高柜箱不加入，允许不同深度及转向。保留原台面覆盖的设备／模块跨度及默认轮廓，新增柜箱贡献自身轮廓；不从上一次手动延伸结果继续追加。投影不相连时明确拒绝，不用包络或凸包填补空地。原管道缺角、设备孔仍在生产台面阶段处理。重复生成结构相同则不新增历史；尺寸／位置变更后显式重新生成。旧手动追加功能保留在折叠的“手动追加延伸”，按钮改名“增加侧向延伸”，与重新生成分开。旧自定义顶点不自动覆盖，只有点击生成才重算。
- L型沿原elevationRuns取两边、U／回型取三边；各面按当前预览区高度均分，窄屏保留独立横向滚动和最小可用高度，不空出大块底部区域。子视图继承原整组柜箱编号，第二／第三边不再从柜箱1重新编号。选择与编辑仍映射回原全局模块索引。

没有新增持久字段、格式版本、加载脚本或保存通道。位置、宽深及台面outline继续原数据；不自动移动旧实例或迁移台面。生成规则是模型布局轮廓，不代替石材加工、支撑或施工许可。
