## 正式生产复核

- 在 macOS 实际打包桌面应用的隔离工作区验收面板库选款、标准厚度 11 mm、底高编辑、撤销重做、正式保存和刷新。MCP 换款与批量新增也读回了产品身份和厚度，显式厚度可覆盖标准值。
- 独立模型管线覆盖作者负例、尺寸／空间／状态、HTTP 和离线 `file://` 生产导出、Blender 回读和下载工程重开。三个生产机位由 Cycles 在 Metal GPU 上渲染，已目视检查[正面](production-front.jpg)、[斜视](production-oblique.jpg)和[背面](production-back.jpg)。
- 生产正面仍能辨认双键、窄缝与指示窗，斜视保留后壳分层。生产背面按外轮廓简化。模型为中立静态姿态，按键端态和实物配对不在本次范围内。
- [增量验证结果](verification.json)记录阶段结果、设备和源码指纹。未执行全仓回归及窄屏验收，外观为执行者对照复核。

## 两种无线配色与 G12 系列配色

按[京东深空灰同款](../../../assets/models/panel-xiaomi-wireless/references/jd-grey.jpg)核对微亮按键边、较深侧壳和浅色指示窗。两种无线配色共用锁定的 86 × 86 × 11 mm 网格和部件身份。无线灰色只覆盖该产品具名外观材质。公牛 G12 采用原网格可着色区域，背板和指示件沿用原材质。

以 macOS 打包桌面与独立工作区验证家具属性、插座布置、撤销重做和首次保存后刷新。实测更换两类配色后的生产 GLB 保留部件身份、顶点数和世界边界，按键材质变化，G12 背板材质保持。用 Blender 5.3.0 从两份生产 GLB 取对应的 12 个面板部件，在同一相机和曝光下渲染并目视对照，左为 G12 双开，右为小米无线双开。[深色](panel-colors-dark.jpg) · [白色](panel-colors-light.jpg)

增量回归包括公牛及两类小米面板、空间确认、布线、项目往返、档案索引、离线资产加载。未执行全仓或窄屏验收。
