# 柜体预览板底高度标注

选中可编辑层板、台面或结构底层板时，在原上下净高旁增加“板底距柜底”。基准为整柜底部（预览局部 Y=0），终点为所选生产板件下表面，包含底座高度，不包含整柜安装离地高度。采用实际生产网格世界边界，避免再次叠加底座或模块变换；没有新增持久字段、空间语义或保存通道。

标注随选中项和草稿模型更新，关闭尺寸时隐藏；短于屏幕可读尺线的高度保留数值。文字参与原有遮挡避让，并优先于普通尺寸放置。适用范围为现有可选层板和结构板；未新增普通固定底板的独立选中入口。
