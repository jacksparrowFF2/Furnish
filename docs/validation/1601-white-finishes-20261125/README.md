# 1601 客餐厅白色饰面受光

2026-11-25。起点为 `a649e1ed`。采用 macOS 正式桌面程序和 1601 的隔离副本。日景为保存的 09:30，夜景为 21:00 开主灯，沿用流畅观察和应用原曝光。每组由同一相机取景。

- 客餐厅涂装墙面从室内侧读取既有窗光场，再按窗洞的竖向角度及墙面朝向衰减漫反射。保留原基色、墙角过渡和低光泽。
- 哑光柜门与白岩板共用按生产窗洞尺寸、距离及表面粗糙度估计的柔光形状。柜门在掠射时会收到窗洞的一部分，反光更宽、更淡。岩板把更大比例的窗光留在靠近反射方向的区域。
- 茶几由生产岩板和导入竹托盘的网格边界派生短程接触影。移开、抬高或隐藏托盘时撤去接触影。阴影是实时显示近似，扫掠、承托规则及生产材质沿原接口。

## 增量验收

- 桌面实际渲染通过眼高、茶几两处斜视、餐边柜及三处开主灯夜景，画面已目视复核，着色器无报错。正式方案文件哈希一致，隔离源码和缓存副本已按归属清理。
- 专项检查通过室内日光及饰面分支、台面接触影随拖动／抬升／隐藏及清理、茶几生产几何与项目往返、地面饰面、栅格阴影、场景阴影缓存和高清灯光快照。正式入口导出并解析全景 GLB，仍为 5,566 个节点。未执行 Blender 回读、光追、窄屏及全仓检查。
- M6 单次前后旋转抽测的帧间隔中位数均为 16.7 ms，P95 为 17.5 → 18.6 ms。茶几拖动的输入至渲染提交 P95 为 28.2 → 27.6 ms，仍出现约 115 ms 的单帧间隔。撤销重做、保存及刷新恢复通过，两件家具的生产 GLB 哈希与上一轮一致。随后缩小软影范围并复拍日夜景。
- 全景相机位于 (9310, 5440, 1660) mm，目标 (7450, 5400, 960) mm，水平视角 101°。岩板相机位于 (8380, 5550, 1290) mm，目标 (8220, 4160, 600) mm，水平视角 61°。采样记录使用同机位无损原图，以统一 900 px 宽的画布计算区域亮度。
