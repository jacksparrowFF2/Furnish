# 平板灯墙面柔光修正 · 2026-10-27

原因：原两束120°聚光锥及有限距离截断让墙面出现明显拱形边界。修正为灯面2×3采样、180°向下半球、penumbra=1、distance=0，每源10 cd；与原两源各30 cd保持峰值展示强度之和，不声称真实光通量相同。灯色、曝光及几何保持。

[修正前](before.png)／[修正后](after.png)为生产灯模型在同一简化厨房墙面／台面环境、相同机位与曝光0.8下的离线file渲染。原参数仅在验收脚本中构造，不进入应用回退路径。已视觉检查墙面、侧墙与台面，拱形截光消失。墙面x=750、z=−798 mm，在灯下250–1200 mm范围每10 mm采样，RGB和最大相邻跳变41→8，最暗值0→641；只表示此固定视图的显示亮度，不是实测照度或通用阈值。见[采样记录](wall-gradient.json)。

通过test-panel-light、test-product-rules、test-ceiling-panel-devices、test-bath-heater-se2、test-downlight及test-blender-render；覆盖生产尺寸与实际实体、开口和保存往返、六点分布与衰减、旋转／镜像后的快照方向／参数、开关。HTTP与离线file界面继续通过贴合、撤销重做、生产三维、开关、刷新、项目导出导入和390 px操作，见[浏览器结果](panel-light.log)。语法及git diff --check通过。

未运行全量check.cjs、Blender实机重渲染或实物配光验证。实时近似未提供面光软阴影／间接反弹，单灯光源数2→6，密集布灯性能未作普遍保证。无持久字段、迁移或加载机制改动。
