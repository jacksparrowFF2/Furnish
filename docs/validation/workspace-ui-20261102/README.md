# 主编辑工作区首轮改进

范围：主编辑器的面板、图层、概览、空间核对入口、家具库密度、方案选择和画布工具。按上述优先级实现，保留现有暖色主题和生产数据链路。

## 行为

- 布置：展开家具库，收起属性与图层。精调：展开当前对象属性，无对象时回到概览。检查：展开整案空间核对。允许手动继续开关面板，不强制恢复某种预设。
- 本机面板偏好仍使用`huxing-panes`。不修改方案、家具尺寸、空间确认、自动保存或撤销栈。
- 桌面图层与两侧面板总宽不足以保留520px画布时，图层浮动在画布上方；可关闭。520px为界面布局阈值，并非空间核对阈值。浮动面板会遮挡部分画面，不保证任意宽度下所有信息同时可见。
- 图层按组展开物体，保留显示、锁定、新建、改名、删除、定位、勾选范围和批量移层。删除与分配仍调用原核心及mutate；帮助内保留原撤销／重做入口。
- 概览先显示需处理、信息不足、已核对，点击可筛选核对事项；预算采购默认折叠，报价页仍显示价格依据。核对算法、候选通道扫描和人工确认机制未变。
- 紧凑家具列表保留规格与添加／拖放原行为，隐藏列表上的价格但规格窗口仍可查看；卡片视图和前一轮按宽度重排机制保留。
- 方案选择器保留新建、管理与原switchDesign保存链路。没有新增并排对比、自动推荐方案或另存通道。
- 选择／框选／测量及3D鸟瞰／漫游／视角常驻；标注、拆改、铺砖、吊顶、风格与其它3D操作放入工具菜单。保留工具事件、选中态、Escape焦点恢复及菜单内的真实生产入口。
