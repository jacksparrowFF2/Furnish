# 组件柜编辑界面与点击开合修复

2026-11-08，基于c6ba0f44。针对用户截图中的全屏控制缺失、左侧混入结构树、模型点击不能开合三个问题修复。保留原有项目文件修改，没有操作正式窗口的编辑草稿；其他会话无正在修改相关文件的迹象，沿用已有完成记录，不唤醒已完成会话。

## 行为

- 新搭建器默认全屏，标题栏可退出和重新进入。关闭后移除本次全屏按钮／类，延后执行的旧关闭回调不清理新搭建器的全屏状态。
- 宽屏按组件库、模型、结构树、属性四区排列；结构树和属性在右侧分别滚动。较窄窗口的右侧改为上下排列，390px手机宽度顺排，不产生水平溢出。树内尺寸最多显示两位小数并换行，不改保存数值。
- 真实射线命中门扇／抽屉后，同时选择组件并调用现有组件核心的开合接口。多段门按门段／门扇身份独立切换，普通门组及普通抽屉组保留原组行为，独立抽屉与活动上盖也可点击。右键、旋转拖动和取消指针不触发开合，放置组件时继续走安装流程。
- 开合沿搭建草稿历史与原应用保存，不新建撤销通道或数据字段。姿态／细节更新保持观察方向，尺寸或视图模式变化才重新取景；初始三维取景增加侧开门及选中框留边，适配较窄画布。
