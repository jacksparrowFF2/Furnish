# TG10K60W 材质基准 · 第一阶段

用户授权按优先级改善家电质感。本批完成洗衣机样板及可复用材质传递机制，冰箱、油烟机尚未应用本批材质。[八张实渲对照](index.html)包含相同几何／机位／灯光／曝光的旧材质与新材质、局部、完整开门及实际洗衣区。图片未经后期修饰。外观改善与空间验证分别判断，不将本批称为实物扫描或完全写实。

## 已落地

- 固定资产 v3：47 个具名件、595×560×850mm，原门轴、开角及尺寸拟合链路保留。玻璃改为薄壳，外包仍为376×376×12mm；玻璃壁厚约1.8mm、IOR1.47等均为视觉估计。生产缓存与空间确认仅对TG型号追加几何版本3，旧v2资产保留。
- 喷涂、银色面板、镀铬、橡胶、玻璃分别处理。`asset_pbr.py`只对已审阅TG部件接收clearcoat／transmission／ior／volume常量，其他型号维持原限制。实际全局材质缓存使用PhysicalMaterial，正式生产GLB保存物理扩展。
- [可编辑精修模板](../../../assets/models/washer-tg10k60w/v3/material-studio.blend)保留程序微表面、摄影灯光、负补光与AgX曝光。模板属于独立产品棚拍，不能直接绑定其他户型。程序节点尚未烘焙为WebGL纹理，因此网页与离线发布保留兼容物理参数，微表面完整效果在Blender精修层。
- Blender5.2导出器内联后会省略未连接的glTF厚度组，作者脚本通过限定清玻璃材质与部件身份的`optical_volume()`补写常量体积扩展，不改二进制几何。手工直接导出不能代替正式作者／发布流程。
- 光学玻璃关闭实体阴影以照亮内筒，是阴影近似；镜头射线仍使用透射与折射，未验证折射焦散或光谱准确性。文字、标签、内筒压型与实际反射仍有差距。

## 实际洗衣区的范围

通过Furnish MCP只读取得当前画布，planId=`custom_mv37igji`、方案“主卧布局改进”、保存状态saved。私有副本复用当前建筑与洗衣柜组，其他家具省略。洗衣机保持已存600×600×850和镜像，未修改用户尺寸或镜像，因而标识也随原镜像呈现。两盏灯为该角度摄影补光，不是住宅照明设计，柜体材质未在本批升级。

未向真实桌面发送修改、保存、导入或注册精修模板请求；未改正式D盘项目。仅私有流水线workspace登记临时模板。旧资产、实验图与本批下载工程保留在`output/appliance-materials`；长期保留可编辑产品模板与本目录证据。

## 下一优先级

先以此样板做外观评审，优先处理过亮玻璃与内筒细节；再按实际金属／玻璃分区适配冰箱和油烟机，逐型号验证材质传递、结构和空间能力。不要将本例IOR、厚度、阴影近似、灯光坐标或整套参数变成所有产品默认值。
