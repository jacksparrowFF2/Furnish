# 1601 二维性能与准确性复验

使用 `projects/workspace.furnish.json` 的 1601（61 件家具），将同一份字节快照注入全新 Chrome profile。HTTP 由只接受 GET/HEAD 的静态服务提供；离线模式直接打开 `index.html`。不连接正在使用的浏览器，不调用仓库写入 API，真实项目文件前后 SHA-256 相同。

## 复现

```powershell
node scripts/verify/verify-2d-performance.cjs
# 本轮修改前的五份源文件保存在本机忽略目录；使用它们做相同项目对比：
node scripts/verify/verify-2d-performance.cjs --baseline-dir output/playwright/2d-baseline
```

`results.json` 记录项目/源文件哈希、每次采样、均值、P95、派生/实体/净距调用次数和数值输出哈希。`before-http-answers.json` 与两个 `after-*-answers.json` 保留逐项完整结果；运行器实际断言结果一致，并断言缓存结果与直接调用核心计算一致。

每项平移、缩放、拖动计算先预热一次再采样 16 次，全重绘采样 4 次。拖动计算包括改变家具位置、吸附、排序与选中净距刷新；另外实际发出鼠标按下、8 步移动与抬起，验证原 commit、undo/redo 和刷新恢复链路。时间为隔离无头 Chrome 的同步函数耗时，未测 GPU/合成/显示延迟，不应直接换算为实际 FPS。

| 操作 | 修改前 HTTP 均值 | 优化后 HTTP 均值 | 优化后离线 file:// 均值 |
|---|---:|---:|---:|
| 未选平移 | 69.46 ms | 5.50 ms | 5.28 ms |
| 选中平移 | 261.19 ms | 9.49 ms | 9.56 ms |
| 选中缩放 | 260.06 ms | 11.26 ms | 11.65 ms |
| 拖动计算 | 213.59 ms | 58.76 ms | 58.11 ms |
| 完整重绘 | 648.70 ms | 159.53 ms | 158.97 ms |

166 项完整结果在三次运行中 SHA-256 相同，另与不经过画布缓存的核心计算逐项一致。运行器同时断言每项优化后均值低于修改前的 60%；本轮全部通过。窄屏补拍等待了侧栏的 300 ms CSS 动画结束，截图对应同一项目的初始布局。

## 通过范围

- 原项目全部家具四向净距、附近位置吸附；单选/多选、图纸 90°/180°、家具 37° 与镜像、尺寸/安装高度和未知高度。
- 邻居移动、柜门配置、墙面厚度、地面厚度、完成地面/原始测量基准、家具图层开关后的缓存失效。
- 画布碰撞与直接核心计算对照，全案空间检查；当前/命名项目往返和重复恢复无漂移。
- 同值单件/数组查询共享净距；平移复用毫米几何，缩放仍更新屏幕字号。
- HTTP 与断网 file://，真实拖动、撤销重做、保存与刷新；1900×1100 与 390×844 截图检查。
- `node-checks.json` 的 18 个增量套件；新增世界变换缓存对 204 个输入变化逐一与全新生产构造器比较。
