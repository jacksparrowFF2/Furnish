# 净距方向与参照标注

2026-11-04。单件家具的四向净距统一沿产品左／右／后／前，与方向徽标相同；旋转图纸不会改变产品方向，镜像只交换左右名称，不交换几何键或位移。多选保留图纸轴，明确写为“图纸左／右／上／下”。画布、属性、浮动面板、匹配的固定测量线和数字定位共用方向定义。短净距名称横向避让，完整家具与板件名称保留在提示及面板。

参照直接读取生产查询的板件名称，区分背板、隔板、侧板；普通外部家具显示“外部障碍”，墙显示“外部墙面”，台面／模块／包络仍保留各自边界含义。`directional()` 只新增派生结果 `enclosingStructure`，沿已有精确二维包含判定区分宿主内板件与外部实体板件；不改变距离、碰撞或可用空腔判定，不写项目。上下高度距离补充实际底板／层板名称。

## 底层评估

测距 `directional()` 与数字定位 `placeSelectionAtDirectionalGap()` 已共用 `bodyParts()`、生产板件和高度裁剪；柜内与柜外面对同一实体的不同面，不需要另造一套包含时反选外包框的规则。本次统一轴选择与显示参照，保留底层查询。以后若统一水平及垂直查询，仍需保留投影截面、承托接触、实际三维碰撞与包络边界的区别，不能用包络包含证明可用内腔。
