## 脚本调整与边界

既有用例在选择灯槽后显式启用，再编辑尺寸；总体成为默认入口后，单部件断言明确切换对应页签。区域编辑脚本明确进入区域步骤，移除对隐藏步骤控件的旧操作。边距核心的往返夹具改用不含旧直装灯带的普通边吊，避免将统一升级产生的合法变化误判为边界编辑漂移。初始验证中发现重新启用时删除字段未同步到草稿，已修复并由恢复原实体的断言复验。

没有运行全量check.cjs、真实触屏、Blender联动或现场施工验证。保留原闭合直线拼角、自交拒绝和空间算法边界。停用灯槽保留中央板原位，并不意味着板件仍有承托；UI已明确提示停用翼边后无承托。旧独立构件仍是有效设计，保留其编辑与按边界重建能力，不自动改变原有构件位置。
