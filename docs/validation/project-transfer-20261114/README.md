# 项目迁移入口增量验收（2026-11-14）

问题：导出完整项目、单布置JSON、自动工作区文件名称混淆，项目导入藏于户型库，跨电脑迁移不易发现。

顶部统一“导入／导出”，主区并列完整导出与导入，并在展开时读取当前户型的真实方案／历史数量。高级单布置出口折叠并明确数据范围；户型库及更多中的旧导入入口复用同一预览。自定义项目仍作为独立户型导入；内置户型保留原合并规则。工作区文件拒绝单项目导入并给出具体迁移路径；原文件不修改。导入预览可展开核对全部方案／历史名称，旧文件零方案时说明仅含当前布置。
