# 启动核对耗时（2026-10-31）

## 第二轮：平面重绘

本轮优化实际计算量，未将空间核对移到遮罩消失后：

- `volumeOverlap` 在每对家具中只解析一次双方板件；全投影包围盒不相交则无需高度裁切，剩余候选仍走原裁切与精判，保留1e-6／5 mm阈值及未知高度行为。
- `withCanvasPlan` 的只读范围涵盖图层、属性栏和页头；仅在这个同步作用域共享碰撞结果，模型异常改变可渲染对象集合会重算。作用域在finally中释放，不引入跨编辑缓存或持久字段。
- 数值实体记录器为每个生产网格预计算仿射基，顶点继续来自原生产构造器；方向变换直接忽略位移，避免大坐标下相减精度损失。

## 第一轮：工作区历史校验
