优衣库长款473548与京东条目款号对应；短款最终采用449725官方图，秋季采用459592官方图。京东图片页不可用后没有把其它款图片冒充京东同款。森马穿着图含弯袖及内搭，已看图淘汰，草稿在本机output中保留，不进入正式库。

## 结论与边界

尺寸／空间：软件毫米包络和生产传递通过，默认悬挂尺寸与厚度是估算。视觉：对用户指定的照片厚片目标完成执行者目视复核；不宣称真实服装三维轮廓或用户视觉确认。生产传递：最终v4源、离线脚本、正式导出及桌面均检查。

曲线用2.5像素采样折线表达，封边为等厚直挤出；不模拟羽绒压缩、软布褶皱体积或真实衣架机构。既有凸包碰撞会保守填充袖下与挂钩空隙；厚片没有自动挂接宿主关系，调整离地需根据实际杆高和总高定位。旧方案及用户当前布置未添加衣物、未批量迁移。
