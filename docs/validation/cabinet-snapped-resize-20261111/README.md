# 新增吸附柜箱改宽修复

2026-11-11。用户截图显示：新增柜箱吸附在原柜旁后，缩窄留下明显缝隙。

## 根因与修复

新增柜箱通过生产拖放求解器确定安装位置后，以独立中心坐标和组件树保存。原组件属性提交只写入宽深高及组件树，保持中心；600mm缩至200mm时，原贴合边移动200mm。增宽则会向相邻柜体扩展，可能穿板。这是实际编辑行为缺陷，非预览材质或测试夹具错误。

共享核心新增setPart，供组件属性提交和模块尺寸编辑共同使用。仅在新增独立柜箱存在唯一贴合侧时，改宽保持该侧固定，中心移动宽度差的一半；其它柜箱、原柜、台面及真实洗衣机不移动、不拉伸。接触读取编辑前的安装外沿，按柜箱自身轴向及垂直／深度相交判定，接触误差小于0.01mm；不是柜内净空或碰撞豁免。

不新增持久字段、自动恢复约束或版本：结果沿原x/y、尺寸和组件树进入同一草稿历史／mutate／保存链路，位置变化沿原缓存及空间核对输入失效。已移开的柜箱、垂直／深度不相交或两侧同时贴合的歧义情况保留中心；不自动猜测旧缝隙并移动既有数据。独立高度、底部离地和深度语义不变。后续若需要移动父柜后整组跟随，应另定义显式连接关系，当前只保持改宽时已有接触。
