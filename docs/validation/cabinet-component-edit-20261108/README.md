# 柜体其余组件定位与尺寸编辑

2026-11-08，基于32c98b96。继续审视组件库15类的画布定位与尺寸能力，在既有层板和独立抽屉手势上补齐可调整项。正式窗口、用户草稿及未提交项目保持，测试仅使用正式文件固定快照的隔离副本。

| 活动层板 | 上下拖动、净高、板宽深、退让、延伸、侧缝 | 复验原入口 |
| 竖隔板 | 左右拖动、左右净宽、隔板位置 | 接入统一编辑描述，补验三维斜视 |

| 独立抽屉 | 整组上下定位、并列数、层高、面板偏移、抽出比例 | 沿原drawerInfo／moveDrawer，复验点击和定位 |

## 交互与结构约束

挂衣杆、开放区、门组、封板、踢脚和收口板复用原指针捕获、方向键、Shift 1mm／普通10mm、网格吸附、Alt取消吸附、Escape及单次拖动历史。数字输入与画布共用核心`componentEditInfo`／`adjustComponent`，实体长度和净高通过`componentSizeInfo`／`editComponentSize`；移除界面中重复的杆高、抽屉位置、隔板位置和门组／开放区边界换算分支。原层板和抽屉核心仍作为委托入口。

门面整组拖动限定在“选择编辑”，保留“开合预览”的单击开门与拖动转视角。门缝标注是专用尺寸手柄，可直接拖动或单击聚焦相应段的数字框；它优先显示在门缝，不被普通尺寸对活动面的避让隐藏。门扇ID、逐扇开度及限位不随位置或分段尺寸重置。段面板最小高仍为既有60mm，分界限位计入原2mm边缝。

开放区没有实体面时也可拾取空腔，已有层板、挂衣杆或门等实体优先；选择整区后可通过空腔移动整区。整体移动保留净高，边界板、灯带及侧／背开口同步；改净高保持净底并调整上界。派生侧／背开孔的剩余板不作为阻挡自身移动的独立板，其他真实板件仍限制边界。开放区不提供碰撞豁免，也不自动移动内部其他组件。

挂衣杆按闭合生产板件限制上下位置，杆长换算为两端留隙，前后及截面编辑也检查实际相交。等于边界可用，既有杆与层板检查采用1e-6mm浮点容差处理边界反算，不放宽可见实体重叠。顶封板、踢脚和收口属于锚定尺寸编辑；改变它们会沿原结构尺寸链重建，不能宣称其他板件永远原位。尺寸拖动期间保持相机，结束后按需要重新取景。

## 持久化和验证

只写已有组件参数（at、from／to、range、height、size、endGap等），不新增持久字段、脚本加载或保存通道。实际改变原默认门组覆盖范围时使用既有range，最低格式沿既有v75；其他配置沿原最低格式，零位移不补写range。组件形状和位置原本已进入生产／数值板件／完整开启扫掠／缓存及空间确认输入，本轮不升级无关型号空间语义。杆仍为原方杆表达，没有新增衣架、衣物或五金承载认证。

- Node `test-cabinet-component-edit.cjs`：120组旋转／镜像／离地配置，144个整体移动实体逐件保持顶点、尺寸、身份与开度；开放区的边界、灯带和侧开孔同步。核对上下等于／超出边界、clamp、杆长／深／截面、门缝最小高度、独立门扇状态、空间输入及当前／命名／组件复用／项目往返，重复恢复三次无漂移。
- UI `--component-edit-only`：正视检查全部新增类及竖隔板，斜视检查杆、两类开放区、门组和隔板；实际鼠标拖动、单步撤销重做、Escape、方向键、数字位置／尺寸、门缝拖动和单击、组件库保存及刷新。刷新后按家具ID＋稳定部件键核对正式生产GLB每个网格的世界边界及部分开门姿态，容差0.04mm；另核对390px布局。
- 增量Node：builder、builder-editing、builder-upgrade、builder-multidoor、builder-open-zones、horizontal-editing、drawer-position、component-parity及脚本语法／差异检查。没有改变加载／恢复格式或生产构造器，不跑全项目check；参数化编辑不适用Blender资产重建。

其他相关会话已结束或未恢复，没有并发文件修改迹象，沿用既有协调结论。提交只包含本轮源码、测试和记录；用户未提交项目及历史资产／方案工作树保留，没有新增临时分支。
