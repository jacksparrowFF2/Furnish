- [标注图](../../../assets/models/balcony-garden/references/user/stepped-rack-dimensions.png)：总深500、上层深250、下层顶650、两层高差350、总高1000mm，长度自选。这是图示参考架的尺寸，不是当前阳台的强制尺寸。

本次采用宽1160、总深550、总高1300、下层顶800mm，保留既有设备／猫砂盆下部使用空间。模板上层深300mm；实际副本选360mm，为暂定盆径及冠幅提供位置。立柱30方、板厚20、板条间隙8均为可调设计值，不是厂家或结构计算结论。当前木色为平涂近似，没有实木纹理或防水涂层选型。

## 参数化模型契约

| 参数 | 当前副本 | 语义 |
|---|---:|---|
| w / d / h | 1160 / 550 / 1300 | 总外宽／总外深／上层台面顶高 |
| rackLowerHeight | 800 | 下层条板顶高 |
| rackUpperDepth | 360 | 上层外深，背沿与架体背沿对齐；当前前沿退后190 |
| rackPost | 30 | 立柱及横撑方截面边长 |
| rackBoard | 20 | 板条厚度，向台面以下扣除 |
| rackSlatGap | 8 | 相邻板条净间隙，0为并排无缝 |

整体尺寸与五项结构参数独立保存，改外包不拉伸板厚／立柱／显式层高；不合法组合拒绝而非偷偷改值。上下高差至少100，退台至少50，板面和柱厚有交叉校验。九根具名柱（含上层前柱）及条板／横撑均参加真实实体检查。各条板按固定约55mm节距重新排分，保留8mm净缝，末根不会被任意截断；这只是布局分格，不是加工清单。

操作：选中架体→属性→整体高度及五项结构输入；宽／深走原尺寸入口。修改层高后需同步调整盆栽mountHeight，目前没有花盆与层板的自动承托绑定。可在库中搜索“两层阶梯花架”，旧架不会被批量转换。

默认读取800／300／30／20／8，不物化旧缺省；新建默认沿create，复制保留，跨类型替换沿产品能力清理。格式v44覆盖当前、命名方案及我的家具，恢复缓存读取旧版本；原平板架及其它类型核对输入不改变。

下层三盆CX9730，CY1150／1650／1910，底高800；上层CX9875，CY1210／1660／1940，底高1300。下层豆瓣绿避开中柱后与第三盆保持实际叶片不相交。君子兰暂按冠幅600×340、高650、盆径260示意，较旧450深的冠幅变扁，避免后排叶片穿入窗侧完成面；实物冠幅未知，不能据此保证现有成熟君子兰必然适放。用户承诺的防猫隔离尚未建模。

[正式布局检查](layout-check.json)：聚焦架体、6盆、猫砂盆及基站无问题；352×352×80机器人连续路径9290／1220→8750／1220→8750／2200→8780／3000无家具实体相交；猫砂盆510×440×400向左抽至8750／1775的扫掠无相交。未运行实机导航／回充、水箱提取或猫砂上盖拆卸；架体仍在右端，未增加洗涤区前方占地。

浇水仍取下花盆至水槽，沥水后放回。板条缝会漏水，底碟不等于防水托盘。材料承重、连接、斜撑、防倾倒、窗扇把手和现场误差未验证，不能按当前示意直接下单施工。
