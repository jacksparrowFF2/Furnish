## 匹配相机与比较条件

本批为参考占位模型，不做单SKU摄影配准。作者场景使用近似商品斜视正交相机，中心(0,0,H/2)，位置(1.2S,-2.1S,H/2+1.3S)，S=max(W,H,D)，ortho_scale=1.65S，Blender米制Z向上；保存review.blend。640方图，AgX、默认曝光0，EEVEE，世界0.35灰，两盏面积灯90W／70W、尺寸0.8。灰模和材质图的几何、相机、灯光完全相同。无精确摄影相机匹配结论。

## 第1轮：轮廓与结构初版

实际查看各款clay.png和material.png。工具箱／药箱具备独立盖缝、实几何折平提手开口、金属扣／侧扣。纸品具备重复圆柱或六包分格。圆角、封膜厚度与内部分层均为视觉假设，封闭状态不提供真实内腔能力。

- 工具箱toolbox/v3、药箱medicine/v2：初版检查，未作外形修订，不制造前后对照。
- 卷纸rolls/v1、抽纸tissues/v1：材质图发现数量标签与包膜共面闪烁，列为本轮识别性差异；未通过材质阶段。

优先处理两项共面闪烁：前标签面退1mm，数量标记改为独立12／6字形网格，材质分区保持。对照v1/material.png→v2/material.png，作者相机及灯光保持。实际打开v2灰模及材质图，闪烁消失、字形可辨；v1保留。无其它外观精修，未称同品牌包装复刻。
