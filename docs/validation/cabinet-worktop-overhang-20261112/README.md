# 新增柜箱台面前沿出挑修复

2026-11-12。用户截图指出新增浅柜台面前沿贴齐柜箱，而邻柜有出挑。根因是生成器只合并同高度柜箱本体矩形，遗漏原台面的前沿出挑；属于实际生成缺陷，不是截图或夹具问题。

生成时读取原配置 `runCounterDepth - runDepth`（不小于0），沿每个参与柜箱自己的局部正面扩展，再旋转／合并。背沿与侧沿不新增出挑；原主台面、柜箱尺寸位置和管道／水槽扣孔仍沿现有机制。当前模板600mm柜深、620mm台面对应20mm，仅为既有软件配置，不是厂家或施工通用要求。虚拟框仍只读取实际承托板件，未支持的空框不参与。

只在用户点击“按柜箱轮廓生成台面”时重建，不加载迁移旧轮廓。重复生成不累加；原手动轮廓仍可恢复默认或重新生成。未新增持久字段、格式版本、缓存旁路或保存通道，规则仍共用浏览器／Node核心。
