## 相机与条件

外观检查组为正交近似斜视，Blender Z向上、正面-Y；相机 `(1.5,-2.7,1.35)m`，目标 `(0,0,.57)m`，ortho_scale=1.28，640×960。局部相机 `(.58,-1,.995)m`，目标 `(0,0,.92)m`，scale=.37，800×800。相机由look-at定旋转，重现脚本 [render-review.py](render-review.py)（从仓库根目录运行）及保存工程 `.local/fan-x231-review.blend`。

R1为另一侧透视且机头上仰，当前相机只近似整体可见侧比例，未精确求解焦距、倾角或畸变，未将参考非等比配准。该限制独立保留；多视图检查避免为单图扭曲已知外包。没有把自动三机位称照片匹配。

AgX、曝光0，世界灰.3；主／补／边光分别140／70／110W、面积2／1.5／1.2m，固定不变。灰材质覆盖与最终材质使用同一几何，同组A/B机位、曝光一致；没有程序纹理或未烘焙节点效果传播的声明。
