所有尺寸是本方案的设计取值，并非厂家安装要求。普通长餐桌没有门抽，其 frontClearance 为 0，餐椅实体仍正常参与碰撞和空间核对；餐椅实际拉出姿态需要现场试摆。原有未知床、书桌和椅子高度继续未知。没有拆改墙体、门窗、设备点位或地面构造。
