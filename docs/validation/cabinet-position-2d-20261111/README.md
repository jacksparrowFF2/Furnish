# 新增柜箱安装位置与2D补绘

2026-11-11。用户要求新增柜箱可前后移动，以对齐相邻柜箱前／后表面，并修复2D漏画。

## 根因与实现

1. 原生组合的模块表单已有部分位置控件，但选择组件后，共用组件属性替换整个属性容器；仅原地柜补回安装设置，新增独立柜箱没有补回。现在选择新增柜箱或其组件时，属性下方保留安装底高、整组左右位置、整组前后位置（正值向前）。同方向柜箱可作为参考，按钮执行前沿／后沿／中心对齐；优先列出高度重叠且距离近的参考柜箱，也可手动选择。按钮沿选中柜箱深度方向移动，保持宽度方向、底高、自身高和其它柜箱／台面。不同朝向的前后表面不平行，不列入自动对齐参考；仍可手动调整整组X/Y。对齐是一次位置编辑，不建立后续跟随或尺寸绑定。

2. 厨房SVG只画了原柜、水槽与连续台面，漏掉assembly.cabinetN。非洗衣厨房还可能提前返回整组包络矩形。现在新增柜箱调用同一组件柜SVG构造，按生产位置、转角和父镜像绘制完整结构，放在原台面设备孔遮罩之外。顺便补齐厨房吊柜新增模块的二维footprints，供既有占地／命中／净距使用。

3. 2D管道裁切遮罩原来只有旧宿主w/d加100mm范围，会截掉超出范围的新柜箱。改用实际组合外包，处理父镜像后再裁切；管道圆孔继续原世界坐标换算，不取消真实管道切口。

无新持久字段、数据版本、加载脚本或保存通道。位置仍保存原x/y/mountHeight，沿草稿一次历史及mutate保存；原尺寸、缓存和空间确认继续读取已有组合输入。打开、取消、恢复不批量移动旧柜箱。
