# 柜体侧面收口封板：功能与视觉复核

2026-11-03。参数化柜体功能扩展，按模型视觉模板裁剪到新增板件、界面和生产传递；不是固定产品的外观重做。当前正式方案未自动加封板，测试在正式 EXE 的独立源码、项目、缓存及端口副本中执行。

## 参考解读与尺寸依据

用户提供的收口做法示意图，红框为“5cm封板”，并确认左右独立启用、初值50mm、宽度可调、颜色跟随门板、2D/3D显示。原图见 [reference.png](reference.png)，SHA256 `5e99ed25588bc28bc6857ff9267867b38353eba374463bbf6dee5e48430319c1`。已实际查看原图红框：靠墙缝隙由窄的正面板条遮挡，和全深见光侧板是不同构造。图示不能证明板厚、固定方式、现场墙体平整度或铰链要求。

| 参数／特征 | 实现与依据 |
|---|---|
| 正面可见宽 | 左右独立，启用初值50mm来自用户确认；1–300mm是软件可编辑范围，不是厂家安装要求 |
| 板厚 | 沿当前柜体 `thickness`，与收口宽分开；模板18mm是既有软件设计值 |
| 左右／位置 | 面对柜门的局部左右；位于原柜体外侧，随柜体旋转、镜像及安装高度变化 |
| 正面／高度 | 正面与门板齐平，普通柜从柜底到完成顶；不挤占净宽，不改变原中心和内部结构 |
| 分层餐边柜 | 冰箱侧沿该段深度整高；储物侧在展示区底部按下段／上段深度分段，采用对应侧门板配色 |
| 饰面 | 同侧最外分区的门板色覆盖优先，其次复用原木色／整柜色规则；无独立收口配色字段 |
| 保持未知 | 修边、锯口、固定件、墙体起伏及实际五金，自身开门干涉未变成施工验收 |

`柜体原宽 + 左收口宽 + 右收口宽 = 含侧收口完成宽`。原宽仍包含已有见光板，模块外宽／内部净宽保持；收口独立于见光板、结构侧板和顶封板。

## 数据和生产链路

- 可选 `cabinet.sideClosures={left,right}`，单位mm，0为该侧关闭；两侧均关闭时UI删除字段。旧记录缺失保持无收口，仅读取默认，不批量迁移。
- `product-rules.cabinetSideClosure`集中侧枚举、宽度范围及初值；核心负责校验、不可变编辑、板件／配色和占地派生。
- 普通柜、衣柜、餐边柜、电视柜、壁柜和浴室柜箱体支持。洞洞板换鞋区保留专用构造，不开放此通用项。厨房的保留内部结构和洗衣附属柜在子柜内设置；厨房普通模块未新加独立收口入口。
- 独立柜箱只在整柜外侧生成一次，不在每个内部分箱重复生成。生产构造器、预览、数字实体和GLB共用实际板件；稳定身份按物理左右及高度段分配。
- 主2D显示实际窄板投影；预览区分柜体宽和含收口完成宽。厨房父组合追加子柜收口投影，碰撞快速排除也覆盖外伸部分；没有收口的厨房保持原边界算法。
- 新配置进入完整cabinet/kitchen缓存及空间核对上下文；变宽／开关使确认失效，改色、采购等非空间编辑保持确认。
- 当前／命名方案／自定义目录／嵌套子柜检测到新字段时使用项目及工作区v45；恢复缓存读取v45和所有原有版本。复制保留，新模板替换清理；重复恢复不移动或缩放。
- 设计草稿沿原保存、`mutate()`、撤销重做和自动保存链路；无新增脚本加载、网络依赖或独立持久通道。
