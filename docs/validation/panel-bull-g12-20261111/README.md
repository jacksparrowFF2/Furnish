## 分阶段复核

1. 轮廓：先查看原商品缩略图，用户纠正后以两张详情截图重列36款，加原SKU斜五孔。真实面壳／按键／孔后部件初版检查完成。初版不虚构修改前图。
2. 结构：v3全款渲染实际发现盖板与面壳共面、出线胶盖闪烁、USB横竖不符。v4增加盖板凹槽及出线孔环腔、校正USB竖排，保留v3／v4全款图。随后v4独立发布拒绝地脚灯框退化面，v5显式三角化并剔除零面积源面；v6完成灰模，v7校正门铃图标与按键前后层次，独立发布全37款通过。没有通过调整灯光掩盖拓扑问题。
3. 材质：同一几何保留哑光PC、孔后保护门、金属接口、灰胶盖、红按钮和不发光乳白灯罩。粗糙度／色值均为外观近似，没有真实物料光学测量；未为本任务扩展透明、程序节点或远程贴图能力。
