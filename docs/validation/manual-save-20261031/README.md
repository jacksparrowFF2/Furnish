# Ctrl+S 与一分钟自动兜底

2026-10-31。用户确认1分钟。基于 `68b6b22`，保留每次已应用编辑的即时恢复缓存，正式文件改为Ctrl+S优先与有界60秒兜底。

## 实际行为

- Ctrl+S／Cmd+S与保存菜单按钮走原flush／retry；只在回执确认后显示「已保存 HH:mm:ss」。没有修改不新增文件修订。
- 普通属性输入先失焦提交；详细编辑窗口的草稿不被擅自应用，提示先应用草稿。
- 第一个未保存编辑开始60秒倒计时；连续操作只替换待写内容，不延后期限。手动成功保存清除旧倒计时，下次修改重新计时。
- 顶部常驻未保存／保存中／已保存时间／失败／冲突；详情保留真实路径、最后成功时间和错误原因。关闭仍有原保存及未保存保护，切后台不立即写文件。
- file:// 的Ctrl+S写本浏览器恢复缓存，提示导出项目生成文件；未增加任意磁盘访问。MCP仍显式flush并报告真实persisted状态。

## 范围与边界

本轮为增量检查，未执行全量 `scripts/check.cjs`、所有独立浏览器流程、整屋3D／Blender或物理触屏检查。60秒是有未保存编辑时的兜底期限，不是空闲时重复写文件；重试失败或真实冲突不会被标成保存成功。当前正式窗口未自动刷新，用户先完成现有编辑／保存后刷新即可加载本轮脚本。
