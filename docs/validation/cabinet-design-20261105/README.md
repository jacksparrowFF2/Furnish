# 柜体设计与上下分柜验收（2026-11-05）

## 用户需求及结构依据

本次依据用户四张界面/柜体截图及补充见光板俯视图。图中上下为两个箱体，交界为下柜顶板和上柜底板；结构侧板/背板分段，左右外置见光板覆盖整高遮缝。参考图的2295、2450、610等是案例尺寸，本次没有将其设为通用默认。未更改当前正式装修方案；原有未提交 projects/workspace.furnish.json 保留。

## 实现及使用

- 设计器进入时填满应用视口，可在标题栏退出全屏；右侧属性栏随宽度适配，宽/深、高/离地并排，独立滚动。窄屏保持单列可滚动。
- 柜板边线由原暖灰半透明改为深棕90%不透明，原生产几何、阴影、材质不变。
- 普通独立柜箱的「整个柜体 → 结构、安装与外观 → 上下分柜」可启用「上柜与下柜为独立箱体」。每箱最高层板变为下箱顶板，其上增加同厚上箱底板，门缝位于双板接触面。板厚沿用当前设计，无额外厂家要求假设。
- 分界位置仍通过最高层板位置/净高编辑；同箱多个隔间同步分界，整柜位置、总宽/高与离地保持。上柜净高扣除额外一块板厚。每个独立箱可有自己的分界；同箱各格必须齐平且上柜净高至少40mm（软件编辑下限）。分界顶/底板不可当普通层板删除；增加/复制/均分层板仅在下柜内部进行并保持分界，新增空模块沿用所选模块的分界。
- 上下门段独立开合与限位；普通非分段模板启用时将整门限位复制到上下段，关闭分柜时沿用下段限位和开合。挂衣模板原分段行为保留。未实现分段逐扇独立当前开度，仍沿原门段组开合。
- 独立箱体的双板是同源生产板件，同箱内部隔板在双板区域终止，不穿板。左右见光板仍用既有endPanels，两侧可不同厚，整高连续且不随分柜切断；不自动启用/猜厚度。特殊分层、厨房保留结构、洞洞板及固定成品书柜不套用本开关。
- 较长纯说明移到相邻属性/组标题后的“？”按钮：点击打开、外点或Escape收起。帮助不改变输入值，Escape优先关闭说明。含操作按钮、链接的说明和短状态提示保持可见。

## 持久化及兼容

可选 cabinet.stackedBoxes 仅显式true，旧缺失为不分柜且不补写，关闭删除字段。仍用原草稿、mutate、撤销/重做与保存。完整cabinet覆盖三维/实体缓存及空间确认，纯配色不额外失效；替换模板沿既有清理。含新字段的当前/命名方案、家具库及嵌套柜体使用项目/工作区v50和v50恢复缓存，旧版本继续读取，无新增经典加载脚本。未知版本仍拒绝，旧应用不应读取新语义。
