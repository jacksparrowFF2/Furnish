## 路线和能力

Blender资产实际执行后台建模／作者预检、错误注入拒绝、独立发布到私有副本标准路径，再进入正式Furnish构造。Y52Y09使用柜体具名板件身份，核对12块曲边导入板和六格；转角书柜保留L形空缺；方凳检查数量与叠放总高。活动家电按各自门轴／滑轨和已有完整行程专项执行，不统一套洗衣机的机构。

既有参数化产品和柜体保留原生产构造；作者、源工程负例和离线发布明确不适用，未强制重做成静态网格。参数化板厚、净空、门抽及关联数据继续由原核心提供。厨房抽屉通过核心接口开启；完整洗衣区按主柜和附属洗衣机整组导出，以家具ID与部件键联合回读，不遗漏成员。

逐配置检查公共bodyParts／directional能力、生产实体、外部间隔、完整包含、实际穿入、高度分离、旋转镜像及项目往返；相应结构专项检查阈值、净空、完整扫掠和恢复。HTTP及断网file两入口实际验证尺寸编辑、撤销重做、刷新、窄屏和无外部请求。电视沿原宽高关联，板件沿自身固定板厚契约。每个生产GLB的部件身份、层级世界边界和Alpha均在真实Blender中回读；下载BLEND另核对几何、相机、Cycles、512px和AgX／曝光0。

三机位按标称与操作状态的实际生产联合包络取景，固定正面／斜视及开合、背面或底面方向。顶装浴霸、面板灯和筒灯另取底面机位。已逐页目视检查模型完整入镜、结构和操作状态，未将自动通过当作照片级外观批准。
