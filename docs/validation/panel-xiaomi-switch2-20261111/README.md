## 机位及实际渲染复核

作者预览为正交投影，单图700×700、ortho_scale=0.115m；正面位(0,-0.22,0.043)m，斜视(0.13,-0.24,0.13)m，目标(0,0,0.043)m。Cycles24采样，AgX，固定面积光与环境；灰模覆盖在同一斜视机位。机位为参考近似配准，原营销图的相机与灯光未知，不称像素级匹配。正常观察尺度优先对比轮廓、分缝、圆点与框厚。

实际查看v1正面、斜视、灰模及普通白／灰和Pro灰色补图。初版轮廓与结构符合系列识别特征，没有虚构首轮前后改进。尺寸回归发现初版指示窗微凸会将缩放深度增加约0.032mm；v2将其贴合键面并随Pro倾角，重新导出及独立发布，所有尺寸回归通过。源几何上一版保留在本地 `.local/panel-xiaomi-switch2-author-v1`，最终生产源v2；预览前后文件保留，不复写失败资产。

总览初图面积灯低于第一排，造成顶部过暗；按相同几何上移并对准灯光，另存修正后的总览。此为预览灯光调整，不宣称材质改进。正式生产斜视也实际打开核对：独立键、细缝、薄侧框、静态圆点和不透明材质均保留。剩余边界：没有同版本实物近照，材质色值／圆角及内部机构精度不能据营销图确认。
