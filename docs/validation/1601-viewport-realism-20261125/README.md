## 范围与验证

- 开放格、特定家具接触影与柜边处理在 1601 实时观察中生效。墙面和饰面反光继续按已有房间和部件范围匹配。材质、阴影及柜边观感属于实时近似。沙发曲率应用到正式生产模型，复核两种配色的生产外包、落地、缩放、旋转、镜像及项目往返。参考[归档沙发侧视图](../../../assets/models/yeswood-sofa/references/user/reference-side.png)的圆肩和靠包分缝，靠垫尺寸及摆放取隔离方案的导入模型。
- 最终桌面实拍完成鸟瞰、客餐厅眼高全景、餐边柜两个角度、沙发眼高和低角度、开主灯夜景及相机转动。第一版靠垫着色器因在法线阶段提前读取光照阶段变量而编译失败，修正后最终桌面渲染无着色器报错。正式生产入口导出并解析全景 GLB，共 5,566 个节点。未执行 Blender 回读、光追、窄屏及全仓测试。
- 增量验证包括窗光、台面接触影的移动／抬升／隐藏与清理、沙发生产构造和缓存、柜门抽屉扫掠及旧项目往返、栅格阴影着色器、产品规则、生产部件身份和场景阴影缓存。
- 在 Apple M6 的 2840 × 1554 流畅观察下，使用 11:00 同机位对照实际鼠标操作。旋转绘制间隔 P95 为 18.7 → 18.7 ms，茶几位姿输入到渲染提交 P95 为 29.3 → 28.1 ms。拖动各有 43 次有效位姿更新，仍各出现约 116 ms 的最长帧间隔。撤销重做、保存与刷新恢复通过。沙发和茶几的生产 GLB 共 75 个节点，沙发布料保留一个绒面材质及基色、法线贴图。使用 `FURNISH_RASTER_ROUND=finish-surfaces FURNISH_RASTER_SCENE=day FURNISH_RASTER_RUNS=before,after` 运行 `scripts/verify/verify-living-furniture-raster.cjs`，传入 1601 工作区文件与起点提交。
- 眼高全景相机坐标为 (9240, 5500, 1660) mm，目标 (7450, 5540, 1200) mm，水平视角 100°。开放格近景相机坐标为 (8580, 6410, 1660) mm，目标 (7130, 7310, 1350) mm，水平视角 61°。
