# 开放区、门板下延与上盖抽屉验收

2026-11-08，基于971d5655实现；收尾保留同目录会话合入的c073ff7d维护约定。前置已确认相关阵列会话无代码／Git占用；未重新唤醒已结束或归档的会话。用户原有 `projects/workspace.furnish.json` 修改不提交，保留其他工作树的独有资产与修改。

## 功能与数据

- 通用 `openZone`、`panel`、`drawerModule`、`slidingTop` 可以拖入、按10mm落点定位、编辑尺寸细节、移动／复制、撤销重做和保存复用。上盖复用同时创建所需顶板／背部开口；移动到已有完整开口时复用该开口。开放区、固定横板和上盖均有独立身份；开放区无板件时仍显示拖入及选择轮廓。
- 门组独立 `range` 与 `drop` 支持中间留空及门板下延，多个门组不能互相覆盖。下延不修改柜箱或隔间。生产门扇、把手、抽盒、缺口顶板及扫掠复用原构造器；删除了旧上盖抽屉的重复生产构造。升级后的v2树没有旧模板或兼容开关。
- 新能力最低格式v75，`openZoneRule=1`仅作用于使用这些能力的组件柜。原v72–74组件契约仍被回归覆盖；价格／颜色／饰面不会额外改变空间输入。所有修改仍沿原草稿、mutate、库和项目保存链。

## 能力边界

并列抽屉当前以组件为单位联动；分开定位的抽屉组件可独立开合。移除或移走上盖后，已形成的开放区作为独立组件保留，修改其背板和边界板可继续搭建。未实现滑轨／铰链孔位、五金载荷、线缆弯曲、门抽自身互撞或复杂连杆机构求解；模型数值不是厂家安装要求。源转换限可完整表达的18mm、无踢脚玄关／电视柜，未知特殊配置会拒绝。没有新增Blender资产，本轮未做Blender下载工程回读，也未将生产GLB结构通过表述为五金或施工认证。
