# 阳台花架与盆栽：视觉及生产复核

日期2026-10-31。范围为通用参数化布局模型，并非指定成品的Blender资产发布。编辑源为`src/render/balcony-garden-model.js`，原模型未覆盖。照片原件保留于`assets/models/balcony-garden/references/user/clivia.png`；模型含盆、底碟及植株，所有尺寸为暂定布局包络。

## 建模前参考解读

实际打开用户原图：宽带叶以近似二列扇形展开，深绿色，叶端钝圆而非针尖；橙色花序在直立绿花梗顶部；米白敞口盆、可见土面、独立浅底碟。未知背面、叶脉微结构、花数、实际尺寸及摄影镜头。盆径约为冠幅的三分之一，仅作照片比例估计。

## 受控相机与阶段

`scripts/verify/preview-balcony-garden.cjs`实际调用生产构造器，固定850方幅、32°透视镜头，植物机位(0.1,0.8,1.8)m朝(0,0.32,0)m。参考照片焦距未知；此机位近似匹配正面略俯视，未作像素配准。Three PBR，固定半球光及侧上方日光、ACES、曝光1。灰模与着色使用同一几何／光照／机位。

### 轮廓与结构

已实际打开[君子兰初版](plant_clivia-before.png)、[灰模](plant_clivia-gray.png)、[改后](plant_clivia-color.png)。本轮优先处理三项：

1. 初版叶面水平，正视成为窄条；改为扇面内宽叶，分开叶高和外侧下垂量。
2. 初版叶高偏低、花梗显得过长；提高内侧叶弧，保留不同叶长。
3. 初版花瓣宽度轴向错误；改为各花朵局部花轴的侧向展开。

结果可辨识橙花、扇叶与米白盆，但花瓣仍有折面，叶端和细脉、光泽层次均未达到照片级还原，保留为低细节布局模型，不宣称外观精修完成。

[开放架灰模](balcony_plant_rack-gray.png)与[着色](balcony_plant_rack-color.png)已实际打开，12件结构含六根落地柱，下层无底板。三个跨度由中柱分开；实际连接件、材料厚度与承重未验证。

### 材质与其它盆栽

已打开[吊兰](plant_spider-color.png)、[豆瓣绿初版](plant_peperomia-before.png)与[改后](plant_peperomia-color.png)，豆瓣绿补顶叶避免裸露茎梢。吊兰与豆瓣绿为通用形态概念，无特定照片／品种级还原声明。陶盆、土、叶、茎和花瓣采用独立标准PBR材质；无外网贴图、折射或程序节点传递声明。
