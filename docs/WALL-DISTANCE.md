# 点击墙间净距编辑

选中自定义户型的可编辑墙，在图中的净距数字上点击或按 Enter，或从墙属性进入「编辑墙间净距」。固定参考墙，按净距移动所选墙；净距为两墙内表面之间的 mm，范围 100–50000。装修阶段只允许非承重墙，原始承重／外墙基线仍受保护。内置示例和锁定墙不提供净距编辑标注。

`src/core/wall-distance-core.js` 为浏览器／Node 共用规则，`distances()` 提供与所选墙投影相交且具有房间净空间的最近平行参考，`edit()` 返回克隆草稿及影响墙段，失败不改变输入。

所选墙沿法线平移，墙上的门窗保持相对位置随墙移动。垂直连接墙的相交端点联动伸缩，连接墙上的洞口保留原绝对中心位置并重算 t；洞口超出缩短后的墙段拒绝修改。T 形接点可联动。连续同向墙段、越过其他平行墙、超出录入画布、房间连通数量改变或既有功能区无法恢复时拒绝，交给户型编辑器人工处理。不是通用 CAD 约束求解器，不支持斜墙。

预览列出联动墙数、前后净面积及变更后的空间事项。家具、房梁、水气点位、测量及标注的位置保持，家具不会自动推开。确认前验证方案快照，应用复用 `FurnishWorkspace.applyDraft()`，统一重建户型、房间设置与门窗覆盖，并记录一次 `mutate()`。取消和非法输入不写历史。净距标注是临时编辑图层，PNG、成果 SVG 和打印不包含其按钮。

回归：`tests/test-wall-distance.cjs` 覆盖轴互换／端点镜像、T 接点、洞口绝对位置、锁定、输入边界、梁高度保持和项目往返。浏览器验证图纸 Enter 入口、取消、确认、外墙只读、撤销重做及刷新后墙位置。功能区和复杂交叉连接仍需结合具体户型复核；自动检查不替代结构判断。
