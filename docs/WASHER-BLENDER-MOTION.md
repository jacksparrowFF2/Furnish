# 通用滚筒洗衣机：Blender圆形侧开门

2026-10-29。复用现有 `washer`，尺寸初值600×600×850mm和离地／洗烘叠放规则来自项目既有模型，不对应已确认的品牌型号。**左铰轴、最大110°、门厚、孔径与内部结构均为布局假设，不是厂家参数。** 烘干机保持原静态模型，本次未编辑真实装修方案。

## 资产与发布

[可编辑Blender源工程](../assets/models/washer/washer-v1.blend)和[GLB](../assets/models/washer/washer-v1.glb)包含15个具名网格、1个竖向Y轴。门环、深色窗和把手3件共用侧轴，其余12件固定。Blender中实际制作圆形投入口、环形门框、浅弧窗、箱体及控制区；无实时程序或虚构品牌。玻璃使用不透明深色PBR近似，未新增透明／贴图导入能力。

独立后台Blender建模，另一后台Blender重新导入GLB，校验身份、部件尺寸／中心、竖轴／枢轴／归属、圆环内外径及投入口通孔后发布离线普通脚本。只看外包正确不足以证明圆孔存在：投入口被封死但外包不变的资产明确拒绝。失败保留上一有效运行资产。未操作用户活动Blender／精修工程。

```powershell
node scripts/blender-asset.cjs author-washer output/washer-new-source
node scripts/blender-asset.cjs publish-washer assets/models/washer/washer-v1.glb
node scripts/preview-washer.cjs
node scripts/preview-laundry-stack.cjs
```

author使用新目录，不覆盖已有源文件。Furnish毫米 `(x,y,z)` → Blender米 `(x,-z,y)`。发布器是本型号布局配方的受限配置，不能导入任意第三方模型、动画片段、骨骼、复杂节点或纹理。

## 保持圆门与安装基准

`washer-motion-core.js`提供参考部件、拟合和完整开启空间，`washer-model.js`构造导入网格，`appliance-model.js`沿现有入口调用并保留连接层。新面板提供0–110°的 `washerDoorAngle`；旧缺失读取0且不补写，新建显式0。同类型替换／复制保留，换烘干机或其它类型清理不支持字段。

外包宽、深、高继续编辑；圆门及圆孔的半径比例取宽/600、深/600、高/850中的较小者，圆环与门窗在自身平面内等比拟合，再整体绕竖轴刚性旋转。面框边缘另行拟合机身，避免直接整机拉伸把门和投入口变成椭圆。非标准尺寸只作布局草模，不代表实际改制或容量。

本轮将闭合门及附件统一纳入600mm名义深度，原静态门环有少量前凸；输入尺寸和旧摆放数据保持，生产外形及空间语义已变化，应重新核对。名义外包不叠加安装预留。

原底部离地、顶部不随门角度改变，叠放连接层仍由设计核心派生。生产应用及洗烘预览在外层设置离地，数值实体默认构造在内部设置离地，两条入口各自只叠加一次；作为上层的洗衣机仍生成连接层，烘干机流程保持。支持0/1/35/1000mm连接层以及锁定和上下机高度联动，不判断实际叠放支架安全。

## 当前实体与完整开启

生产显示与数值记录器共用导入顶点，接回 `bodyParts()` 和 `directional()`；当前二维选择轮廓读取实际门体顶点并缓存，不用圆门的方形盒角估计量距。当前角度、尺寸及离地进入实体／三维缓存，价格配色不清除空间确认。

完整开启独立于当前角度，始终检查0–110°。圆门按12个高度区间分片，区间宽度取该段圆截面的最大值，包住门环／窗／把手；每片按≤2°采样并补足弧弦误差后取保守凸包。共用 `FurnishCabinet.openingIntersects()` 读取高度片，`shiftOpening()` 统一平移各片。已知高度采用实际相交片，未知高度保守处理；原柜门和烟机的竖向剖面能力保持。定位显示完整外轮廓，实际判定按高度片，不随关门缩小。

验证仅挡中间路径的障碍、圆门顶部的外包空角、未知高度、旋转镜像、当前碰撞及外部间隔。12片和凸包可能保守误报，共用平面接触容差仍适用，不是逐三角面连续精确碰撞。投入口已做视觉／射线和发布通孔检查；单个凹面框的数值截面仍可能填实孔区，不能据此承诺机器内部可摆放物体或无条件空腔豁免。

## 保存与验收

沿 `mutate()`、原锁定、撤销重做、刷新、自动保存、项目／命名方案和洗衣柜关联。包含本款的方案使用v35，以保护新增角度及实体／开启语义；v34窗饰和更早模型继续按实际所需版本。仓库、缓存与恢复同步支持35，空间确认含角度及 `blender-washer-motion-v1`。

部件身份为 `washer-v1:*`；未验证旧精修Blender材质自动接管新拓扑。见[增量记录](validation/blender-washer-motion-20261029/README.md)。未验收真实铰链限位、软管、排水、振动、承托或施工要求。
