# 参考图建模与视觉复核

适用于依据图片新建或实质重做固定产品，以及用户明确要求的外观精修。尺寸／运动／发布验证沿用[整链路流程](BLENDER-MODELING-PIPELINE.md)，视觉复核使用本文；两者分别给出结论。局部小修只复核受影响阶段和关联视图，不补造历史阶段证据。未指定产品的流程维护不自动重做现有模型。

## 1. 先解读原图

实际打开原图及重要局部后，再开始建模。参考原件沿[资产存放约定](MODEL-ASSET-STORAGE.md)保留在 `assets/models/<id>/references/`，不覆盖、重绘或用AI生成图替代实物证据。衍生裁图和标注放本次验收目录，记录原图路径、SHA256和原始像素裁切框。缺原图时记录缺失，不把已有文字描述说成看过图片。

先填写[复核记录模板](templates/MODEL-VISUAL-REVIEW.md)中的资料和特征表，至少明确：

- 型号、版本、配色是否一致；尺寸图、营销图和实机照片各自的用途及冲突。
- 主体轮廓、面板分区／接缝、门窗／控件中心、支脚与离地、凹凸层次等影响识别的特征。
- 每项关键值属于标注尺寸、用户确认、照片估算或未知；照片估算不升级为厂家尺寸、隐藏结构或安装要求。
- 遮挡、反光、看不清的文字及不可见侧，分别写明未知、适度简化或待补依据。

特征与具名部件对应；影响轮廓、遮挡、视差或运动的凹槽／压圈／胶圈／把手／可见内件采用分层几何。印字和细纹理按发布器支持选择贴图、材质或矢量网格，不能为了贴图效果绕过离线能力。透明窗与后方内件独立，保留真实开口与运动归属。

### 1.1 以识别特征安排建模投入

后续参考图建模默认采用以下方法。适用于其它产品，具体部件和精度按参考资料及实际展示尺度决定：

1. **先抓比例和识别点。** 从同型号全图及局部提取最影响辨认的特征，先核对主体／底座／支架比例、主要中心位置、前后厚度及凹凸层次，再投入小字与微纹理。每项关联参考区域、依据类别和稳定部件键；标注尺寸与照片估算分开。
2. **按视觉作用选择真实几何。** 会改变轮廓、孔洞、遮挡、投影或斜视视差的网罩、格栅、压圈、把手及可见内件，应表达实际层次和前后距离。开孔构件保留真实开口，后方可见物独立；只有不改变这些关系的表面印字／细纹才适合用贴图近似。不可见内件不凭空补齐。
3. **重复结构保留形状规律。** 对弯曲肋、百叶、辐条等，先核对走向、曲率、疏密、厚度和边缘连接，再选择足够的采样；不以增加面数或部件数作为还原度目标。实物数量无法辨认时明确为模型采样，按正常观察距离及局部渲染检查，并兼顾正式模型加载和导出成本。
4. **按物理分区组织部件和材质。** 需要独立轮廓、材质或运动语义的部分使用稳定身份；喷涂／塑料／金属／橡胶／玻璃分别调整基础颜色、粗糙度与金属度，检查法线和平滑。独立物理件不必机械地一件一个网格，分组不得丢失需要单独验证的身份。先用正式发布支持的PBR表达，再按已声明能力补细节。
5. **把“看过渲染”落实到阶段。** 灰模整体先判比例，灰模局部再判层次，最终材质用固定条件检查。修订时保留同机位前后图；没有修订就记录初版检查，不制造前后改进证据。相机或灯光不匹配须说明，不能据漂亮效果图推断照片匹配通过。
6. **核对最终用户实际看到的模型。** 从正式生产构造器取整体与关键局部，检查上述识别点、部件和材质是否保留，再沿适用链路导出回读。独立Blender源效果与应用效果分别验收；技术传递通过不能代替目视还原度结论。

方法来自[FA18-X231案例](validation/fan-x231-visual-20261104/README.md)的实践及用户对本次还原度的正向反馈。该案例的28个部件、72根前网肋、估算尺寸、相机、灯光和静态姿态只属于该模型，不作为其它产品默认值；不能从一次反馈推导通用相似度分数或精确实物还原结论。

## 2. 匹配与固定相机

为主要照片建立匹配视图，记录投影、焦距或正交比例、相机位置／旋转、画幅和裁切；存在镜头畸变或拍摄参数未知时标明近似。先对齐整体轮廓、可见侧面和主要水平／竖向边，再判断部件比例。透视照片不能直接当正交尺寸图，也不为贴合单张照片扭曲已确认尺寸。

另保留正面／侧面等尺寸检查视图；同一模型应同时经受多视图检查。匹配照片视图与整链路自动三机位用途不同，自动取景不表示已匹配照片。相机或画幅必须变更时，新建比较组并重渲前后版本，不将不同机位的图称作受控对比。

## 3. 分阶段渲染、看图、修改

| 阶段 | 主要核对 | 进入下一阶段的依据 |
|---|---|---|
| 轮廓 | 外包与比例、曲率、主要分区、底部离地 | 统一灰材质的整体及必要局部对照，主要轮廓差异已处理 |
| 结构 | 接缝、孔洞、凹槽、把手、透明窗后层次、活动件端态 | 灰材质／适用剖面或开合图能说明真实结构，识别性差异已处理 |
| 材质 | 喷涂、金属、橡胶、玻璃、粗糙度和微表面 | 使用同一最终几何／机位／环境／曝光的材质A/B，并核对生产传递 |

每阶段至少实际渲染并打开整体和关键局部图检查；脚本运行成功、网格数量或尺寸合格不作为视觉通过依据。灰模图用于轮廓／结构判断；玻璃层次和反射另用适用材质补图，不能仅凭灰模判断光学表现。只有受控模型前后图要求同光同曝光；参考照片的未知布光不声称已复现。

每轮在记录中列出最影响识别的最多三项差异，以具体位置、方向、比例或层次描述，例如“外圈相对窗口过厚”，不用“更真实”等无法核对的指令。每项关联参考局部、修改部件、修改前后图及复核结论。只改相关部件，保留上一有效源工程和发布资产。

已解决项重新打开结果确认；改过的部件需要检查对相邻部件、其他视图及开合的影响。高影响问题未解决时不进入后续阶段掩盖问题；若依据不足或受工具能力限制，记录原因和未通过范围，交付当前可恢复版本，不反复猜造或虚报通过。阶段通过由执行者根据实际图像记录，不额外引入用户逐轮审批。

## 4. 证据与复现

复制模板到 `docs/validation/<product>-visual-<YYYYMMDD>/README.md`，随阶段填写；图片用相对路径关联，裁图不可脱离原图来源。大型中间工程可保留在本机独立输出目录，记录实际位置与哈希；最终源、GLB和离线发布仍遵守已有资产版本约定。

建议每轮保留以下内容，文件名可按项目已有习惯调整：

```text
README.md                  # 已填写的模板及每轮差异
reference-crops/            # 衍生局部，原图保持不动
round-01/                  # 后续轮次另建目录
  front-before.png / front-after.png
  detail-before.png / detail-after.png
  comparison.png           # 并排或叠合图，标清参考／渲染
```

叠合前记录配准和缩放方法；局部采用相同对应区域，不以非等比拉伸掩盖差异。轮廓和关键点比例可辅助量化，但阈值按资料清晰度与用途说明，不设“相似度达到某百分比即通过”的通用规则。颜色像素差异不能独立证明几何或材质正确。

## 5. 正式生产复核与交付

源工程视觉阶段完成后，沿现有作者预检、独立发布、生产构造、生产GLB与Blender回读执行受影响的增量验证。对正式模型重新取相应视图及局部，对照已确认的特征，核对身份、法线、材质槽、透明件和活动件实际姿态。未烘焙程序节点的效果仅归精修工程，不声称完整穿过GLB；具体材质能力仍按型号／部件白名单。

现有 `verify-model-pipeline.cjs` 的自动通过只说明其声明的技术检查；本流程的参考解读、局部对照与视觉结论需要执行者实际完成，不因模板存在而自动通过。只跑相关配置，不默认运行 `all`。

交付分别写：尺寸／空间验证结果、视觉阶段结果、正式生产传递结果及剩余简化。每项使用“通过／失败／未执行／不适用”，关联证据和原因；用户尚未确认的外观只能称执行者复核通过，不能称用户已认可。
