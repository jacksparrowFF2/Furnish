## 实现与兼容

`src/render/water-purifier-model.js` 为生产构造器，主应用与独立预览共用；面盖采用圆角截面加倒圆挤出，机身复用现有 RoundedBoxGeometry。没有新增网络依赖或加载机制。模型保持 mm 输入，在构造边界换成 m，旋转／镜像使用原根组变换。

产品核心定义高度、底部安装语义、身份与可编辑能力；复用现有 `h` 与 `mountHeight` 字段，不新增项目版本。新建明确写入底高 0；缺失时读 0，不迁移已有其他产品。复制、同型替换保留参数，跨型替换沿核心能力清理。编辑走原 mutate、撤销和自动保存，现有高度／尺寸缓存与核对签名已覆盖实际输入；缓存复用时保留底高。

## 预览与验证

生成预览：`node scripts/preview-water-purifier.cjs`，打开 `output/water-purifier/preview.html`，可切正面、斜视、侧面及俯视。

`tests/test-water-purifier.cjs` 覆盖目录规格、底高有效范围／非法值、复制替换、重复恢复、当前及命名方案往返、生产几何包围盒、旋转镜像、有限法线及缓存重建。浏览器用例 `scripts/verify/verify-water-purifier.browser.js` 覆盖 HTTP 与断网 file 模式的预览、实际目录新增、属性尺寸／底高、0 值、锁定、撤销重做、复制、刷新、下载再导入、命名方案、主 3D 及 390 px 属性面板。

本模型用于布局和外观展示；通用实体核对不识别柜内空腔，也不代表承托、接口和维护空间的施工验收。实际验收结果见本次改进记录。
