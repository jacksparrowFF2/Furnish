# 房梁高度录入与三维检查

2026-10-13。入口：项目工作台 → 备份／加载项目 → 原始结构／拆改 → 房梁离地高度。每根已导入的 DXF 梁有独立的梁底、梁顶和确认／取消按钮。两项都清空并确认，可恢复为高度未知。结构锁定后仍允许补录高度，不改变墙线、梁投影或原始基线。

## 数据契约与复用

- `draft.beams[].bottomHeight`、`topHeight` 是距完成地面的绝对 mm；同时存在，满足 `0 ≤ bottomHeight < topHeight ≤ 20000`。上限是输入保护范围，不是建筑标准或默认高度。
- 两项都缺失是旧数据的合法状态。单项、null、字符串、非有限数或逆序由 `FurnishDraft.validate()` 拒绝，不将空输入转换为零。
- `FurnishDraft.editBeam()` 返回校验后的副本；UI 确认后通过现有 `applyDraft()` / `mutate()` 保存。取消只丢弃未确认输入；撤销、重做和自动保存复用项目通道。
- `FurnishDraft.beamVertical()` 是状态、检查及渲染的唯一高度解释入口。`build()` 只缩放梁的二维坐标，高度不随图纸标定变化。
- `review:'beam-height'` 保留作为旧 DXF 来源标记；当前是否待核对由高度是否完整决定。导入报告的 `beam-heights` 仍保留为历史导入记录。
- 项目格式仍为版本 1；当前、命名方案和基线中的梁属性随原有备份链路保存。旧项目不补默认梁高。空间确认 v3 已包含完整梁数组，高度变化会使原确认失效；无需再改确认版本。

## 物理检查与显示

已录入的梁按投影多边形 × 梁底至梁顶参与柜门、抽屉、上翻门和抽屉操作空间检查。共享 `openingIntersects()` 做平面与高度相交，上翻门继续使用扫掠截面裁剪，避免整体外包框空角误报。竖向面接触不认定穿入，平面沿用 5 mm 容差；未知梁在物理开启范围中显示待核对，不当作明确冲突。

已知梁在 3D 中从真实梁底向上挤出至梁顶；未知梁仅保留二维虚线与待录入文字，不生成假设实体。二维工具提示显示已录入高度。梁继续不切分房间、不计入墙体拆改量；本轮不推导 DXF 高度，也不增加梁的水平形状编辑或人体漫游碰撞。3D 几何缓存包含梁数组，高度修改触发重建；观察剖切不改变空间检查。

## 梁与家具实体（2026-10-13 补齐）

`spaceCheck()` 新增 `kind:'beam'`，独立于柜门／抽屉开启结果。家具侧读取 `FurnishDesign.furnitureVerticalBounds()`，梁侧读取 `FurnishDraft.beamVertical()`，高度相交复用 `FurnishGeometry.verticalOverlap()`。开启障碍和梁实体检查共用一次预计算的刚性家具包络与梁高度，不另建产品高度默认值或类型能力表。

平面不相交或者已知高度不相交时不报告；柜顶等于梁底是面接触，柜顶高于梁底 1 mm 且与梁有平面正重叠时报告。家具完全高于梁顶同样免除。平面沿用 5 mm 容差，竖向沿用 `1e-6 mm` 浮点容差。未知梁高或家具高显示 `pending:true`，文案明确为投影重叠待核对，不写成确定三维穿入。

刚性壁挂／吊装物仍参与梁碰撞，不能套用地面占地检查的豁免；地毯、植物和柔性窗帘沿用开启障碍的排除。家具包络保持现有产品语义，包括旧柜默认高度、记录的高度、设备离地基准和历史模型包络。本轮是布局包络检查，不逐块检测内部空腔、凹槽或分层柜各高度处的局部深度；局部精细实体作为后续扩展，不能用本项结论替代实际板件核对。

结果保留家具 `id` 与独立 `beamId`，同名梁可分别核对。属性面板、柜体草稿预览、产品资料及全案共用结果；明确冲突和待核对采用各自提示样式。全案“定位”同时高亮家具占地与对应梁投影。确认仍使用 v3：新结果种类不会复用旧开启确认；已有上下文包含梁高和家具高，两侧几何变化使确认失效，价格／颜色不影响确认。本轮不增加持久字段或改变项目版本。
