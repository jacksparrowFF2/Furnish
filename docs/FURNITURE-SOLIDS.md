# 家具生产实体与空间判断

2026-10-22：在已有柜体、厨房板件及换鞋凳／樱桃木茶几的基础上，增加 22 类家具的生产实体读取，共 24 类 `solidModel` 产品能力。没有新增保存字段或家具版本，也没有为旧家具另建兼容分支。

## 覆盖范围

| 生产构造器 | 产品类型 |
|---|---|
| 原有专用模型 | `bench_yeswood_oak`、`coffeetable_yeswood_cherry` |
| 基础家具共用模型 | `bed`、`sofa`、`armchair`、`cornersofa`、`dresser`、`desk`、`chair`、`coffeetable`、`table`、`roundtable`、`island`、`barstool`、`officechair`、`bench` |
| 专用模型新增读取 | `table_folding_1100/1200/1300`、`tea_table_800`、`tea_bar_mijia_pro`、`cat_tree`、`pet_feeder_mijia_2`、`sofa_yeswood_cherry` |

基础家具构造器从页面原实现原样抽到 `src/render/basic-furniture-model.js`，生产三维和实体读取共用它。各专用模型继续使用原构造器及尺寸依据；本轮没有重新测量实物，没有把模型假设变成厂家安装要求。柜体／厨房继续走已有 `FurnishCabinetMotion.solidParts()`，共用测距、碰撞和按高度裁剪。

`product-rules.js` 声明 `solidModel` 能力，`model-solid-recorder.js` 提供同步数值适配，`furniture-solids.js` 运行生产构造器并在边界转成 mm。它不是完整 Three.js 实现；新增构造器或几何 API 时必须补验真实生产几何。折叠形态、茶吧机开门状态和基础模型的随机位置种子进入缓存；旋转、镜像在共用边界变换。猫爬架斜抓板的旋转复制和局部位移单独核对生产网格。

挤出轮廓按实心区域分解，保留已建模的孔；环体拆成局部段，避免把大孔填满。无体积的贴花／装饰面不当成实体。圆角板件使用小范围保守边角，曲管使用局部保守包围块；同一零件的非凸截面仍可能被局部凸化。它们减少整件家具包络误报，不等于逐三角形精确碰撞。

## 状态与边界

- 生产数据只读，不写回家具；保存、复制、替换、撤销、项目往返沿用现有通道。空间确认规则标识升级到 v2，使旧确认重新核对；采购和配色字段仍不参与空间签名。
- 未声明实体能力的模型保留既有包络／专用规则，不推定内部空腔。猫砂盆复杂多孔踏板尚未接入，普通家电等也未因本轮增加空腔豁免。外部导入模型仍无通用结构识别。
- 基础模型部分高度和装饰是既有示意几何，不是新增的可编辑持久高度。过小尺寸可能让原有装饰超出输入宽深，碰撞以实际生产几何为准。
- 板件之间的实际空隙可用，管件／曲面局部保守量仍会产生小范围误报；未知高度继续按原规则保守处理。施工净空需要实测或厂家资料。

## 验证

`tests/test-furniture-solids-coverage.cjs` 对全部 24 类能力核对真实 Three.js 生产几何外包，对 11 类代表家具覆盖已知空隙／真实碰撞、0/37/90°旋转、镜像、折叠形态、开门、项目往返、外部间距和斜抓板变换。原柜体、阈值接触、未知高度及恢复测试继续运行。

`scripts/verify/verify-furniture-solids.browser.js` 覆盖 HTTP 与离线 `file://` 的换鞋凳、茶几、餐桌、折叠桌，核对共用测距读数、实体碰撞、撤销／重做、刷新、390px 和逐件三维截图。完整检查范围及剩余边界见 [本轮记录](validation/p1-solids-sync-20261022/summary.json)。
