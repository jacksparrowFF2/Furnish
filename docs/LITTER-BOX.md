# 封闭式猫砂盆

入口：家具库「生活用品 → 封闭式猫砂盆」，类型 `litter_box`。默认灰白配色，静态外观模型，用于装修布局和占地比较。

| 参数 | 数值 | 依据 |
|---|---|---|
| 外包宽 × 深 × 高 | 440 × 510 × 400 mm | 用户第一张图标注 44 × 51 × 40 cm |
| 安装基准 | 底部 0 mm，随工作方案原家具地面基准 | 落地摆放，复用现有完成面基准 |
| 正面 | 局部 +Z，半透明猫门一侧 | 两张用户参考图 |
| 默认配色 | 米白上盖、灰色盆底 | 第二张外观图近似 |
| 品牌、型号、价格 | 未知 | 用户未提供；目录价格 0 表示待填写 |
| 内部尺寸、壁厚、格栅、猫门尺寸 | 外观估算 | 参考图未标注，不作为产品实测尺寸 |
| 猫铲及其突出量、维护/开盖预留 | 未知，未建模 | 配件是否计入标注尺寸不明确 |

参考附件：`codex-clipboard-42189e27-4f7a-46e2-af85-2410da557372.png`（蓝色尺寸图）、`codex-clipboard-69bb6ffc-74fe-40eb-a760-ac7c21d964eb.png`（灰白产品图）。外形相似性用于本次布局近似，不能据此确认两图来自同一厂家型号。

生产构造器 `src/render/litter-box-model.js` 表达中空圆角盆底、U 形上盖、半透明固定猫门、爪印、实际开孔的顶部漏砂格栅及中心盖板。附件猫铲、除臭片、铰链运动、底盘拆卸和真实内部机构省略；无交互开门或开盖。底盆与上盖比例、圆角、壁厚和开孔按图片近似。宽深高允许布局缩放，不能据缩放推定厂家产品规格或猫的适用体型。

2D 图例前边为猫门，与生产 3D 同向。原工具条编辑占地宽深；属性中编辑高度和上盖颜色；盆底保留灰色。旋转、镜像、复制、替换、撤销重做、自动保存及命名方案/项目往返走原链路。没有新增持久字段或项目版本；产品核心给出默认高 400 和落地包络，旧实例缺高时只读取默认，不回填旧记录。替换清理由原产品能力处理。

布局实体检查仍使用整件包络；不将中空内部视为可供其他家具嵌入的空间，也不增加厂家安装或清理预留要求。

预览生成：`node scripts/preview-litter-box.cjs`，打开 `output/litter-box/preview.html`。预览直接调用生产构造器，使用入口自带离线 Three.js。验证入口：`tests/test-litter-box.cjs`、`scripts/verify/verify-litter-box.browser.js`。具体本次验收见改进记录与 `docs/validation/litter-box-20261019.json`。
