# 三维家具直接操纵（2026-11-07）

在鸟瞰 3D 中选择家具，显示透明的小型三轴手柄：X 红色、Y 绿色为图纸平面移动，Z 蓝色为升降；橙色环绕竖轴旋转，家具保持直立。取消物体中心的高度大卡片，数值栏优先避开生产模型投影、手柄及已有工具；空间不足时收成紧凑栏。详情按钮按需展开高度读数。窄屏隐藏重复的顶部摘要，保留侧栏／详情入口。

点击或拖动对应轴后，数值栏切到当前动作：Z 是最低底部离地绝对输入，±10 mm；X/Y 输入本次相对位移，±10 mm；旋转输入本次相对角度，±15°。普通平移按10 mm取整，旋转按15°取整，Shift 取消取整；Z 继续按实际层板吸附，Shift 暂停吸附。多选／分组整体平移并绕共有占地外包中心转动，保持成员距离和相对高度。任一成员锁定或模型无效时不提供整组编辑。

`selection-transform.js` 通过主场景适配器读取实际生产模型、相机与选择，不另存家具状态。拖动预览只改变生产根组的平移／竖轴转角，不改工作方案；松手先恢复预览，再经 `FurnishDesign.transformFurniture()` 与一次 `mutate()` 提交全部成员。核心高度仍调用 `FurnishProducts.editBottomHeight()`；原90°按钮也复用刚体核心，保留原中心及组内坐标取整。Esc、窗口失焦、指针取消／失去捕获、切换选择／模式或场景同步取消预览，不增加历史。

平移按相机的局部投影导数换算；某轴几乎正对相机时，显示可抓取的回退方向，以100 px/m换算。旋转环使用水平面投影及射线求角；接近平视时改为面向屏幕的圆环与屏幕角度，避免环塌成一条难以抓取的线。Z 吸附阈值为12屏幕像素、最多50 mm。手柄、数值栏只在界面显示，不进入生产导出或项目数据。

底部离地沿现有家具基准：旧方案仍为毛坯测量基准，新方案可为完成地面；不会把读数直接当成绝对世界高度。特殊中心、台面、宿主等安装语义由产品核心换算。台面关联设备调整沿原核心解除台面跟随。新增本地经典脚本，已验证HTTP和断网file加载；没有新持久字段、格式版本或保存通道，缓存与空间确认继续读取既有安装输入。

`FurnishSnapping.elevationTargets()` 从 `FurnishGeometry.bodyParts()` 读取实际生产板件及世界标高，只识别水平薄板的顶面；未知完成地面、包围盒、竖板／斜板不提供吸附。目标必须与物品平面投影有实际重叠，且贴合后不能与同一宿主生产实体相交；因此踢脚顶面被底板遮挡时不作为候选。多选按共同位移换算候选，并检查全部成员与目标宿主。Shift 暂停吸附。

边界：吸附不证明完整承托面积、承重或安装预留；不自动解决其它物品的干涉，也不阻止自由拖动／数字输入穿板，仍使用原空间核对。仅有数值外包而没有生产板件的桌面／物品顶面不吸附。拖动不会把整件缩放为目标位置；特殊安装模型最终仍按原生产构造器重建。

数值栏按实际投影选择不遮挡位置；若物体／现有工具已占满视口，只能选择重叠最少的紧凑边缘位置，不承诺任何缩放下都存在完全空白位置。轴使用世界／图纸方向，本次不实现任意倾斜、轴心重定位、局部坐标系切换或完整 SpaceClaim 工具集。
