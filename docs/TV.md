# 电视视图一致性

2026-10-21：修复普通 `tv` 的平面与生产三维投影不一致。旧 SVG 将额外灰块画在正面且超出深度，旧 3D 使用固定 30／25 mm 厚度，将屏幕放在后侧，深度编辑无法反映到实体。

现以原保存的中心、宽深和旋转镜像定位：正面为局部 +Z（平面 +Y）。后壳宽为 60% w，位于后侧 60% d；全宽屏幕位于前侧 40% d，玻璃及底部标志均包含在深度内。后壳高为屏高的 60%，居中。比例是既有通用电视的外观近似，不是特定厂家结构或安装要求；没有新增支架、底座或安装净距。

保持既有 16:9 屏高 `w × .5625`、中心离地 1200 mm 及产品规则垂直包络，不更改旧实例 `h` 语义。各目录规格和自定义宽深沿用原输入；无新字段、迁移、加载依赖、保存或撤销通道。缓存已读取宽深、颜色、姿态；布局／碰撞继续使用原 w × d 保守矩形，不推定后壳两侧为可用空腔。本次不改空间规则或确认签名。

专项：`tests/test-tv-view-consistency.cjs` 比对真实生产几何与 SVG 部件边界，覆盖全部目录规格、自定义深度、旋转镜像、离地包络及输入不变；`test-plan-height-order.cjs` 验证电视与低柜层叠。浏览器入口 `node scripts/verify-browser.cjs tv-views` 使用隔离方案检查 HTTP／断网 file、视图切换、深度编辑撤销重做、刷新及窄屏；不写用户设计。
