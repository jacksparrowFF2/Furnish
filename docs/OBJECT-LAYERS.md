# 物体图层管理

2026-10-19。顶部「家具库／属性」旁新增「图层」直接开关；「显示 → 图层管理」及选中家具属性栏的入口也打开同一个侧栏。

桌面图层面板停靠在家具库与画布之间，独占一栏，不遮挡画布及工具条。窄屏使用下方半屏面板，上方画布仍可操作；× 或顶部「图层」可收起。开合状态保存在已有本机面板偏好 `huxing-panes.showLayers`，刷新保留，未改变项目数据字段或版本。

侧栏不使用模态遮罩，可直接选画布物体、改属性、撤销重做及切换 2D／3D；当前选择和图层状态即时同步。重新渲染保留新层名称草稿、重命名草稿、搜索和滚动位置；切换户型清除跨方案的勾选和重命名目标。

## 2026-10-20：调宽与图层切换

桌面拖动图层侧栏右边缘可调整宽度；聚焦分隔条后左右方向键每次调整 10px，Shift 加速为 50px，Home／End 到边界，拖动时 Escape 取消。宽度范围 260–720px，并为画布预留空间；屏幕或其他侧栏挤占空间时临时缩窄，空间恢复后使用原偏好。宽度保存在本机 `huxing-panes.layerWidth`，与开合共用偏好存储，不增加项目字段或历史记录。窄屏仍使用半屏面板，返回桌面恢复偏好宽度。

点击图层名称同时切换分配目标与下方物体清单，显示「当前图层：名称」；重置搜索、类型筛选和旧勾选，避免旧筛选遮住该层物体。「全部图层」恢复跨层清单，分配目标不变；目标下拉只负责分配，不改变清单范围，便于把当前层物体移往另一层。隐藏／锁定层仍可查看清单，点击名称不改变画布显隐、锁定或物体归属；这些操作仍通过明确控件执行。删除当前层后清单回到 0 层，跨户型重置为全部图层。

## 2026-10-20：Shift 连续勾选

物体清单先点击一个复选框或文字行建立起点，再按住 Shift 点击另一项，将当前显示顺序中两端之间的所有条目设为终点点击后的勾选状态；正向、反向和整段取消均支持。普通点击只切换单项，保留其他已勾选项；连续 Shift 点击保留原起点，正常界面重绘也保留有效起点。

范围只取当前图层／搜索／类型筛选后的清单，不包含被筛掉的物体。搜索或类型变化重置起点，但沿用原有跨类型显式勾选；图层切换、跨户型、全选筛选结果及批量分配后重置起点。起点从清单消失后，下一次 Shift 点击按单项处理。勾选和起点都是临时 UI 状态，不修改项目、不新增历史；实际移入图层仍由原批量分配按钮执行。

## 2026-10-20：墙砖显隐覆盖完成面实体

墙砖图层现在统一控制：3D 墙砖排版表面、瓷砖厚度实体、粘结层实体，以及 2D 墙面完成面轮廓。原实现只隐藏排版表面，露出仍然可见的黄色瓷砖厚度实体；2D 完成面未接入图层，且墙体重绘顺序会覆盖较早应用的显隐，现已修复。结构墙继续显示，隐藏图层仅用于观察，不修改实体尺寸、净尺寸、吸附或空间核对输入。

`FurnishLayers.wallFinishKey(plan,solid)` 将生产完成面按原墙体编号、侧、法向及原沿墙范围对应到有效墙砖面；拼角采用 `rawRect` 防止扩角误判。功能区与物理房间编号可能不同，不以房间编号相等作为绑定条件；同墙两侧、垂直端面及不同沿墙范围分别匹配。派生的 3D 网格使用已有 `userData.layerObject`，2D 使用 `data-layer-wall`；均未增加项目字段或改变几何构造。没有有效墙砖排版的独立完成面继续按原方式显示。

当前可见 SVG 保留隐藏，完整 SVG／打印恢复完成面；撤销、重做及刷新均重新应用显隐。参见 [墙砖图层验收](validation/wall-layer-finishes-20261020.json)。

## 2026-10-20：物体定位与建筑部件选中框

点击物体清单名称，在当前 2D／3D 视图选择并定位该项；家具复用现有选择及三维定位观察，地面／飘窗台、墙砖、天花和吊顶使用对应部件的平面范围定位。复选框仍仅用于批量勾选；Shift 点击名称保留原连续勾选语义。隐藏图层只提示先显示，不自动改变显隐或勾选。

3D 房间／飘窗台选择现在显示生产网格的橙色包围框；从清单定位其他建筑部件时，同样按物体图层键框选其实际可见网格。包围框随模型变换更新，排除隐藏对象，切换选择时清理；2D 对清单定位的建筑部件增加对应范围轮廓。层隐藏后清除该层当前定位目标。定位状态复用临时 `ui.sel.layerObject`，不进入项目、历史或自动保存。

参见 [定位验收](validation/layer-location-20261020.json)。

## 行为

- 每个工作方案独立管理命名图层。未分配的受管物体读取为 `0` 层；旧项目不补写分配或图层配置。
- `0` 层不可删除或改名，可以显隐、锁定。其他层支持新建、重命名、显隐、锁定与删除，名称不可重复。
- 删除层只清除其分配，使物体回到 `0` 层，不删除任何物体；一次撤销恢复图层和分配。
- 选中家具可整批移入目标层，也可在管理器按名称搜索、按类型筛选、勾选家具、地面、墙砖面和吊顶后批量分配。
- 同一层可以混合多种物体。显隐同时影响主 2D / 3D；隐藏模型不参加三维拾取，相关家具预留标注、选中标注和墙砖编号同步隐藏。原有家具总开关、瓷砖观察模式及墙体观察功能继续独立作用。
- 锁定层中的物体仍然可查看、选中和复制；移动、旋转、镜像、尺寸、柜体开合、替换、删除及原参数编辑受到保护。单件锁定与图层锁定取并集；解锁图层不清除单件锁定。应在图层管理中解除图层锁定。
- 各操作沿原 `mutate()`、历史和自动保存。编辑失败回退事务，且在柜体、叠放等归一化之后再次检查锁定对象，防止联动编辑间接修改锁定家具。
- 复制／剪切后在同一户型粘贴继承复制时的图层；跨户型粘贴或来源层已删除时回到目标方案的 `0` 层。替换同编号家具保留分配；删除家具同步清理分配，撤销恢复。
- 2D PNG 遵循当前显隐。完整成果 SVG／打印使用 `visibleLayers:false` 时恢复所有受管物体，保持原完整成果契约。

## 数据契约

`work.objectLayers` 可选：

```json
{
  "version": 1,
  "layers": [
    {"id":"0","name":"0","visible":true,"locked":false},
    {"id":"layer_example","name":"家电","visible":true,"locked":false}
  ],
  "assignments": {"furniture:f123":"layer_example"}
}
```

规则集中于浏览器 / Node 共用的 `src/core/layers-core.js`。最多 200 层、每层名 80 字、10000 条分配；名称和编号唯一，所有分配须指向存在的层，导入与实际恢复均校验。`0` 层的显隐、锁定和普通层一样保存；恢复重复执行不改变原数据。

分配键：`furniture:<id>`、`floor:<roomId>`、`ceiling:<ceilingId>`、`roomCeiling:<roomId>`；墙砖采用 `wallTile:` 加 `[wallId,side,cross,rangeStart,rangeEnd]` 的 JSON，沿墙范围统一保留六位小数，与毫米实体坐标无关。同墙上下分带共用墙面图层。房间地面包括生产表面、各厚度层和所属门槛；天花包含自动灯具，装修吊顶按构件编号单独管理。

图层不是产品物理参数，不给家具或厂家安装规则增加字段。模型几何、空间核对、工程量和采购仍读取完整方案；图层编辑不进入空间确认指纹，不使已确认的空间问题失效。主三维直接切换现有生产模型的可见性，不把隐藏物体从建模、开孔或碰撞输入中删除，也不为显隐反复重建生产模型。

含 `objectLayers` 的项目／工作区外层版本为 15，使用独立 v15 浏览器缓存。项目、命名方案、仓库及 IndexedDB 恢复均可往返；仍兼容 v1–v14。首次没有 v15 缓存时沿现有规则读取最新旧缓存，保留原缓存。内置户型创建编辑副本时，墙砖图层绑定调用现有墙面映射规则同步转换。

## 范围与后续边界

本轮受管对象为家具／家电整件、地面／地砖表面、墙砖面、装修吊顶及房间天花。建筑墙体、建筑门窗、梁、测量与文字标注继续走原显示／编辑机制；柜体内部板件没有拆为独立图层。没有实现 CAD 冻结、图层颜色或线型继承；图层锁不冻结由上游建筑几何派生的表面。

墙侧范围或房间编号因建筑重分区而改变时，旧绑定保留为未匹配记录，新对象按 `0` 层读取，不把旧层推断分配给不同对象。普通复制内置户型使用明确映射；更广泛的几何编辑自动重绑定留待后续处理。

验收包含 Node 规则及持久化回归，以及 `node scripts/verify-browser.cjs observation-layers` 的 HTTP／断网 file:// 实际操作、桌面与 390 px 截图、真实项目下载再导入。实机触屏与全部历史浏览器专项不在本轮验收范围。
