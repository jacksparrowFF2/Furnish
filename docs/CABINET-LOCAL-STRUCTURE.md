# 柜体局部结构与组件收敛（第四、五阶段）

2026-11-08。前置阶段见 [柜箱组合](CABINET-COMPONENTS.md) 和 [上下柜](CABINET-TIERS.md)。本轮完成局部底板、分柜踢脚及逐层活动层板退让；生产构造、数字板件、测距碰撞和导出继续共用同一模型。

## 字段与编辑

所有值使用 mm，由 `product-rules.cabinetDetail` 定义软件范围，不是厂家加工、承重或通风要求。

| 配置位置 | 语义与默认 | 范围 |
|---|---|---|
| `columns[i].bottomPanel:false` | 取消当前隔间底板；缺失即保留 | 普通可组合柜；底板与踢脚独立 |
| 柜箱首隔间 `columns[i].plinth` | `{enabled,height,inset}`；同箱隔间共用；缺失继承整柜底座高、启用、前沿内退40 | 高0–250，内退0–300且小于柜深 |
| `columns[i].shelfInsets` | 与 shelves 等长的数组；null表示该层不退让；元素 `{front,back}` 各从基准前后沿扣减；全部为null时移除字段 | 每边0–300；实体剩余深度至少1 |

底板控制显示在隔间属性；踢脚显示在物理柜箱的首隔间。活动层板前后退让显示在选中层板属性，并显示实际板深。固定上下柜分界板、洞洞板门底分界板、置物台固定结构板及固定成品书柜不使用活动板退让。

局部底板／踢脚当前用于普通可组合柜，不扩展到置物台、分层餐边柜、洞洞板组合、厨房派生柜、浴室柜和上盖抽屉等专用结构。普通上下柜的下柜可分别设底板／踢脚；上柜仍零踢脚、不另设局部踢脚，底板和活动层板沿子柜编辑。层板退让可用于可编辑的普通柜、置物台及餐边柜活动层板，保留各自结构分区。

取消踢脚只删除踢脚实体，不降低箱体底板；改变底座高度按该箱有效净高缩放层板和抽屉高度，取整到1mm；单改踢脚启用或内退不重新取整。取消底板时该格侧板／背板向柜底延伸，层板持久位置仍相对原底板上表面的设计基准。下方净高量到实际柜底或保留踢脚顶面；实际设备碰撞和测距读取生产板件，不把无底格整段豁免。移除结构后的承重与安装需另行设计。

合箱要求相邻箱的有效踢脚设置一致，否则整次操作失败；不静默覆盖任一柜箱。模块增删、复制、排序、拆箱保留各隔间所属踢脚；新建独立模块继承整柜默认。混合有底／无底时阻止整柜自动重分配门，避免改变开口归属；仍可按隔间配置门扇。

层板复制会复制退让，新增层板默认不退让；删除、排序及手工重列位置按原层板位置映射退让，均分层高保留对应层号的退让。转换上下柜时下柜保留自身设置，上柜以独立的空层板、默认底板和零踢脚初始化。

## 共用规则与第五阶段清理

- `shelfPart` 输出唯一的活动层板 mm 实体；普通柜、置物台和餐边柜的生产层板使用同一个组件，配方只传实际横向跨度和身份。移除模型内三套层板深度／中心计算及旧的缺失深度回退。固定成品书柜的圆角与边缘是产品构造，仍显式限定到该产品模板。
- `bottomParts`、`plinthPart` 统一普通柜底板／踢脚实体；`boxParts` 将分柜高度交给相同柜箱构造。分柜开合扫掠与上下柜复用同一坐标放置函数，旋转、镜像及整组离地各应用一次。
- `autoDoors`、`entry.autoColumns`、`entry.editable`、旧 `backPanel` 在读取边界统一消费，编辑／恢复得到的配置不再携带这些字段；旧无背板转换为明确的 `backThickness:0`。删除模板、采购规格和运行校验中的重复清理／旧开关分支。历史别名只在输入边界解释，不为旧几何保留版本选择。
- 同深 `stackedBoxes` 仍是现有实际结构操作，置物台、冰箱位、烟机空腔、上盖抽屉及碗篮仍是不同结构／机构；本轮没有把这些差异误删为兼容代码，也不宣称仓库所有历史数据读取代码已清空。

## 保存、缓存与确认

显式含任一新字段的当前方案、命名方案或家具库最低项目格式v70；包括仅上柜含逐层退让的情况。工作区和缓存接受v70；其余产品按原格式判断，不统一抬高所有项目版本。

复制、同类型模板替换清理、撤销重做、自动保存和恢复沿现有完整 cabinet 与 mutate。新参数进入完整配置缓存和空间确认输入；底板、踢脚或退让变化使空间确认失效，价格、采购状态和配色不失效。重复恢复不缩放或重新取整。没有增加第二套保存通道、脚本加载器或柜体几何版本开关。
