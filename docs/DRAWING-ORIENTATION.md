# 图纸显示、自动尺寸与真北

「显示 → 图纸朝向与自动尺寸」或右上角方向指示打开设置。缩放条旁的旋转按钮每次转 90°；任意精确真北角度从原始图纸上方顺时针计算。示例：原图右侧为北则录入 90°，画布再顺时针转 90° 后，指北针指向屏幕下方。

可选 `work.drawing` 包含 `rotation`（0／90／180／270）、`northAngle`（null 或 0≤值<360）、`dimensions`（auto／full／overall／original）和 `openings`（布尔）。缺少字段通过核心读取默认值，不补写历史项目。北向未知时指示「北向待设置」，不宣称屏幕上方为真北。恢复与导入都校验字段；沿用项目、命名方案、复制项目、恢复点、自动保存和撤销链路，不建立新工作槽。

显示旋转只变换 SVG 与看图视口，保留墙体、原始基线、门窗、梁、水气点、家具、标注和测量的原始 mm 坐标。鼠标坐标在边界逆变换回真实 mm，平移／缩放／放置／定位继续使用同一接口；3D 进入视口的中心反变换回户型坐标。指北针按真北与显示旋转共同派生。真北调整 3D 示意日照的水平向量，不转动模型或改变空间核对记录。当前日照没有地理位置、日期或真实太阳位置计算，不能据此判断具体季节的采光时数。2D 显示旋转不规定 3D 相机的环绕角度。

自动尺寸由有效墙体轮廓派生。默认 auto「精简」只对外轮廓投影极值的转折生成分段链，每轴保留一侧及一个总尺寸；矩形没有转折时不再重复总尺寸。门窗洞口用原矩形补齐轮廓，避免把开洞当作外形凹口。内部隔墙不参与精简分段；房间内部使用选中后的截面净尺寸。full「四边详细」保留所有墙面投影及四边总尺寸；overall 仅保留每轴一个总尺寸；original 保留原图预设。可另开启门窗洞口宽度。分段链不声称等于凹形房间净尺寸；梁、竖管和家具不参与结构尺寸。几何编辑与撤销后重新派生，不保存生成结果。保留「仅总尺寸」和「原图预设尺寸」，复杂导入图纸可切换。屏幕标注保持至少 10 px，过短分段仅保留刻线与说明，放大后显示数字；PNG 和报告按所选精简／详细模式重新生成固定字号标注，独立于当前缩放。

PNG、成果 HTML 保存显示旋转与方向指示；DXF 坐标继续保留原始基准，DIMENSIONS 层输出分段、总尺寸、可选洞口宽度及毫米文字，NORTH 层按原始坐标绘制真北。DXF 使用可分别编辑的线／多段线和文字，没有原生关联 DIMENSION 实体，改 CAD 几何后不会自动重算这些标注。第三方 CAD 打开验收仍待执行。

关闭承重墙状态时，所有普通全高墙使用同一颜色且不画类型点线。开启时恢复承重墙高亮、外墙颜色与类型线型；低墙和拆改图层仍表达自身高度或修改状态。显示设置不改变结构锁定规则。

回归与浏览器验收覆盖派生尺寸、洞口、四种旋转、非法配置、旧数据不补字段、重复恢复、命名项目往返、空间确认不失效、真实拖动坐标、撤销重做、刷新、完整项目下载再导入、3D 和 390 px。截图在 `output/playwright/workflow-tools/drawing-*.png`。真实 file:// 启动和实机触屏边界仍见 [离线验收](OFFLINE-ACCEPTANCE.md)。
## 标注与打印排版

`dimensionLayout()` 只派生文字位置和显示密度，先总尺寸后长分段，最多四个向外排版位置；不能找到无冲突位置时省略文字，原尺寸线与数值保留。低缩放的短段简化刻线，导出使用固定毫米字体。

`roomLabels()` 按房间轮廓、名称、家具占地及显示旋转缓存派生位置，候选点和三档字号优先避免占地；只改显示，不改 `room.at`、面积或家具。孔洞采用奇偶填充。拥挤空间采用尽力排版。

打印通过 beforeprint/afterprint 装配和清理完整 SVG，复用成果 SVG 的浅色、完整范围与固定字号路径。原界面隐藏，A4 方向由完整图纸宽高确定；浏览器媒体预览已验收，系统打印输出仍需实机验收。
