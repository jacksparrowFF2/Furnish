# 卷纸与抽纸参数化阵列（2026-11-07）

## 范围与旧方案

支持现有 `toilet_roll_heartlink_layer9` 和 `tissue_heartlink_layer6` 两种纸品；旧整提包装参考模型保持静态，不推定隐藏单件结构。复用原 Blender 发布资产的 `roll-01` 或 `pack-01-*`，按单件重新定位及刚性转向，不增加第二套外观几何。原 `.blend`、GLB、离线资产仍为有效来源。

缺失 `paperArray` 的实例继续调用原整层生产构造，不补字段、不改 ID、分组、中心、旋转、离地、配色及单独堆放层。默认编辑值从该实例的原外包派生：卷纸3×3，抽纸3×2，一层；因此用户已有非标缩放也不被新标称尺寸覆盖。首次编辑任一阵列参数才写入可选对象，并重新计算外包。新增库实例同样先显示原单层，以原数量为阵列初值。

## 参数与尺寸

`product-rules.js` 声明能力、范围及共享 `paperArrayConfig` / `paperArrayLayout` / `editPaperArray` / `clearPaperArray`。可选 `paperArray` 是完整对象：

| 字段 | 意义与范围 |
|---|---|
| count | 总数量，1–200整数 |
| columns / rows | 每排数量／每层排数，各1–50整数 |
| unitW / unitD / unitH | 未转向单件的局部宽／深／高，10–20000 mm |
| gapX / gapZ / gapY | 当前排列左右／前后／层间的净间距，0–1000 mm |
| orientation | 卷纸：upright、side-x、side-z；抽纸：upright、turn、edge-x、edge-z |
| pattern | grid 整齐；stagger 隔排向局部右侧错位半个横向节距 |

总宽／深／高均不得超过20000 mm。总层数由 `ceil(count/(columns*rows))` 派生，按左右→前后→向上填充；最后一层允许不满，整体外包按实际存在的单件计算并居中。错位不验证承托或实物堆放稳定。单卷横径／纵径可独立适配旧布局的非标缩放，用户确认标称值仍为Ø100×140；抽纸为140×100×50，非厂家外箱规格。

`w/d/h` 保存为派生整组外包，与对象参数不一致的输入拒绝。显式阵列通过单件尺寸、数量及间距改变大小，共用尺寸调整接口拒绝直接拉伸整组，以免改坏单件和间距；位置、整组旋转、镜像、底部离地及可选三维倾斜保持原语义。改变阵列不自动调整其它家具或其它纸品层。

## 生产与保存

- 原 Blender 单件按真实部件及材质复制，内部使用m，核心计算及项目使用mm。每件保留 `unit-NNN:原部件` 身份，离地仅叠加一次。
- 属性面板沿一次 `upd` / `mutate`，支持锁定、撤销重做、自动保存和刷新。MCP暴露完整参数、范围及有效初值，完整对象编辑调用同一核心派生外包；`null` 恢复原3×3或3×2单层，保留当前未转向单件尺寸和整组位置。
- 复制／粘贴保留对象；同型号替换保留阵列及派生尺寸，跨型号清理。没有直接修改正式项目JSON。
- 仅显式包含该对象的数据采用v62；当前、命名方案、我的家具及工作区／恢复缓存支持旧版。旧缺失字段不物化，重复恢复无漂移。
- 数值实体、主3D缓存、姿态的规范几何／frame缓存及空间确认均覆盖完整阵列输入。配色、采购与价格不进入空间确认输入。
- 平面符号按单件投影和层次生成；实体、净距、碰撞及GLB导出复用同一生产构造器。单件之间的间隙不作为实体，不新增柜内空腔豁免。

## 验证与边界

定向测试：`tests/test-paper-array.cjs` 检查真实Three单件外包、全部朝向／排列、末层不足、稳定部件身份、逐件尺寸和中心、间隙碰撞、旋转／镜像／离地／倾斜、参数拒绝、缓存及确认、复制替换、v62往返和重复恢复。原纸品、三维姿态、工作区保存及恢复测试另行回归。

`tests/test-paper-array-ui.cjs` 在同一打包EXE的独立源码、项目、端口和缓存下验证属性、撤销重做、锁定、错误输入、保存刷新、窄屏、MCP配置与恢复、实际3D和逐部件生产GLB；补充HTTP及阻断HTTP网络的file入口。使用项目测试目录管理器清理成功批次的独立源码及缓存，保留截图、报告和导出；失败批次保留以便排查。

不包含全量回归或新一轮外观重做。卷纸中心孔沿既有碰撞算法的保守单件处理，不认证孔内穿插；错位堆放和横放仅提供布局几何，不认证真实稳定性。数量上限为软件资源保护，不是柜体容量或承重。

实际通过项、截图、生产GLB与Blender重开结果见[本次验收记录](validation/paper-array-20261107/README.md)。
