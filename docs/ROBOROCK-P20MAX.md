## 朝向、外观和参数

底部落地（最低点 0 mm）；局部 +Z 为入口和机器人前置相机方向，2D 的 +Y 为正面。沿用应用旋转和镜像机制。白色塑料、圆润水箱版外壳、圆拱进站口、上下水版低矮矩形上盖、底部托盘、机器人超薄圆盘机身、顶部齐平传感器及前置黑色相机窗口按图近似。外壳曲率、接缝、托盘筋条及内部停靠位置均为外观估算，非尺寸图标注值。

宽、深、高和颜色可编辑。尺寸变化按整个静态模型缩放，仅作布局近似，不代表真实产品存在其他规格。高度保留到 0.1 mm；旋转、镜像、复制和保存使用现有机制，无新增持久字段或虚构开合交互。2D 包含占地、顶盖分缝及前侧标识；水箱版平面同步圆润顶盖、灰色托盘和两条坡道，上下水版停靠轮廓为示意虚线。

未建模内部清洗/烘干机构、真实刷毛、供排水接口和电源线。水箱版品牌标识为本地矢量笔画近似，无外部字体和图片依赖。安装及维护预留没有厂家资料，不能据此判断柜内安装可行。图中水箱版促销价格含优惠和补贴，未作为长期报价；库中采用现有 0 待填写价格占位，需用户填写实际采购价。
