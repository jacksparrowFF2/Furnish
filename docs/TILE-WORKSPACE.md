# 铺砖工作区（2026-10-19）

主画布统一使用「铺砖」。房间属性、原墙地砖快捷调用和三维墙面编号都转入同一工作区。预设管理从「预设 → 管理预设与关联」进入。旧墙砖／地砖列表、统一美缝、独立三维起点及引导已删除重复表单和提交逻辑，只保留兼容转发。

## 选择、编辑、预览、一次应用

1. 在房间列表勾选地面／墙面，或在「图上选面」点击实际房间轮廓与墙面编号。Shift／Ctrl点击可多选；图中聚焦后Enter／空格选择，Shift组合多选。跨房间保留选择；「选地面」「选全部墙面」替换为当前房间范围。墙面沿用厨房、卫生间与阳台既有识别范围。
2. 多选显示共同值，差异显示「多种值」，只修改编辑过的字段。选择和启用分开；关闭排版保留参数。规格、缝宽、美缝、起铺、厚度、标高和上下分带进入同一草稿。
3. 平面／立面读取实际房间边界、墙面和洞口。3D独立实例调用生产地面、层体、墙砖及完成面构造器，不替换全局state；普通点击实际墙地面选面，Shift／Ctrl多选，导航支持旋转、平移与缩放。
4. 「调整砖缝基准」在二维和三维共用毫米坐标与手势规则。拖动圆环或实际表面平移网格，点击设置基准；12屏幕像素内吸附真实边角、边线，洞口和孔洞继续排除。远处基准以区域内等价砖角表示。方向键按1 mm，Shift按10 mm微调。
5. 分带墙通过「当前分带」选择要拖动的带，仅修改此带起铺。跟随地砖对缝时水平基准由地砖派生，只能调整竖向。未知完成标高／墙位置时拒绝空间取点，数字草稿仍可编辑。
6. Esc、指针取消、失去捕获或窗口失焦会回退当前手势，包括手势产生的关联变化，保留此前其它草稿。松手不写项目。无活动手势时Esc先结束基准调整，再走草稿关闭守护。
7. 「应用铺砖」将完整草稿一次交给原mutate，并结束基准调整；全部修改可一次撤销重做。取消丢弃完整草稿。关闭、遮罩与Esc遇到未应用草稿时提示继续编辑／放弃关闭。非法输入不会因修改其它合法字段而清除。

保存继续使用原自动保存、仓库、命名方案、撤销及项目往返。编辑期间项目发生外部变化时阻止旧草稿应用；无草稿时读取最新值。打开、选择和预览不补写旧记录、未知厚度或关闭配置。无新增项目字段、版本或自动迁移。

## 参数与预设关联

参数词汇、能力和分组由 `tile-parameters-core.js` 共用。参数下显示「独立参数」「跟随：预设名」或「部分跟随」。

- 默认「仅修改此处」：只解除实际改变的参数组，其它组与其它表面关联保留；同值输入不解除。宽高和方向为规格组，起点X／Y为同一组。仅改单带起铺不解除分界／规格组。
- 「更新预设及其关联表面」：在草稿中更新来源分项及订阅相应组的全部表面；查看其它房间能看到结果。不订阅的字段仍为本地修改。取消全部回退，一次应用保存来源及受影响表面。
- 预设填入草稿可选分项和参数组。默认「复制为独立参数」只解除覆盖组的跟随；「改为持续关联此预设」明确建立／替换订阅。内置预设关联时生成可编辑副本。
- 旧文件恢复不重新套用、不推断或自动清理关联。明确编辑才改变订阅。删除／解除预设关联仍保留实体参数。
- 库编辑、保存当前排版和关联管理保留；库应用回到同一工作区，不再有第二个应用窗口。管理库前需应用或取消当前草稿。

## 分带、层厚与核对

整面墙修改规格／缝宽时，仅同步各带同名字段，保留分界、编号、名称与其它起铺。分带表单支持2–20带、按洞口上下沿生成、各带起铺和对缝；取消分带需明确选择。预设同步单带布局时保留目标未订阅的分界结构。

未知厚度留空，0有效；只修改某层保留其它层。墙面按范围分段保存的粘结层，在普通编辑和预设更新中逐段保留。毫米标高仍由原核心计算。

「完成面与起铺核对」显示当前草稿毛坯、完成地面和已启用墙砖基准。多个墙面／分带不同基准显示「多种基准」，未知待确定；各带节距也进入检查。整案家具高度基准在同一草稿明确修改，作用于全案，保留家具原输入高度。

## 实现与验收

- `tile-editor-core.js`：稳定目标、部分字段编辑、订阅组变化及原子安装，复用原墙地／美缝／预设核心。
- `tile-interaction-core.js`：SVG／三维共用局部毫米坐标、世界变换、实际边界吸附及单带补丁。
- `tile-layout-drawing.js`：实际平面、立面和户型选面图；`tile-layout-preview.js`：生产三维、射线选择、手势与资源释放。
- `tile-workspace.js`：一份草稿和一次应用；旧UI只保留转发或其它界面复用的只读片段。

核心回归包括 `tests/test-tile-editor.cjs`、`tests/test-tile-workspace-complete.cjs` 及原墙地／美缝／预设／分带套件。浏览器命令：`node scripts/verify-browser.cjs tile-workspace tile-workspace-complete tile-library`，隔离运行HTTP及断网file://，覆盖保存、一次撤销重做、刷新、项目往返、390px、主生产3D、图面和射线选面、二维／三维拖动及取消、独立参数组与预设同步。

[初版验收](validation/tile-workspace-20261019.json)保留；本次见[完整验收](validation/tile-workspace-complete-20261019.json)。

算法边界：地面不支持大小砖混铺；墙地节距不同仅对齐起铺缝；不做切砖优化、施工下料或找坡。未执行实体触屏及完整读屏验收。
