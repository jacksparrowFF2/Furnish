## 全新克隆后的预览

运行 `node scripts/generate-previews.cjs`，从维护源码重建当前 19 个独立预览页面。命令无需 npm 安装或网络，执行后按照控制台／模型文档中的本地 output 路径打开。单个模型仍可运行对应的 `scripts/preview-*.cjs`；方太两款设备共用 `scripts/create-fotile-previews.cjs`。

玄关柜二会先生成其依赖的洞洞板柜预览，不要求克隆中已经存在兄弟 HTML。餐边柜及扁桶热水器分别由 `scripts/preview-sideboard.cjs`、`scripts/preview-waterheater-flat.cjs` 重建。浏览器验证脚本如需预览页面，先运行生成命令。

生成命令会更新本机同名预览；不要用它保存人工修改过的唯一版本，维护内容应回到脚本或模板。本次整理没有运行它覆盖本机旧文件，生成验收在独立临时副本中完成。

## 链接和验证

文档中的图片链接指向仓库内的长期证据。预览链接指向生成脚本；文档代码片段中的 output 截图／日志路径表示当时的本地产物，在全新克隆中不会自动出现。清理索引见 [本次迁移清单](validation/output-cleanup-20261016.json)。

`node scripts/check.cjs` 继续运行全部测试；新增干净副本验证会在没有 output 的临时目录中重建预览，检查共享脚本声明、模块语法、离线引擎和本地依赖。现有本机预览仍由 check 按适用范围额外检查。资料链接检查覆盖长期资料、技能文件和生成器入口。

本次完整检查通过 172 套回归；284 个本地文档链接、全部归档路径和 UI 报告图片引用通过检查。另在独立的本地服务夹具中实际打开新生成的餐边柜和热水器预览，确认模型显示且无页面错误；没有操作当前项目。`file://` 实机验收受浏览器工具协议策略限制未执行，离线引擎及路径只做了生成／语法检查，不能将 HTTP 结果视为 file 验收。

取消跟踪不会删除本机文件，也不会移除已提交的 Git 历史。测试截图和日志今后留在 output；需要归档的证据再明确复制到 docs/validation 并补充说明。

其他已经克隆过本项目的电脑在拉取这次取消跟踪的提交时，Git 会移除原先受跟踪且未修改的 output 文件；需要保留那台电脑的旧产物时，拉取前先备份其 output 目录。本次已为当前电脑逐文件校验并保留原件。
