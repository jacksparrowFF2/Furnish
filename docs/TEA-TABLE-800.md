# 藤编移动茶台 · 80cm

家具库「桌 · 台」中的 `tea_table_800`，依据用户 2026-10-20 提供的两张产品图片制作。品牌、型号、单价及厂家安装要求未知；目录价格 0 沿用未录入价格的现有约定。

| 参数 | 数值与依据 |
|---|---|
| 宽 × 深 × 高 | 800 × 400 × 720 mm，第一张图片标注 80 × 40 × 72 cm |
| 柜体高度 | 地面脚轮最低点至台面挡边最高点 720 mm，模型对图片标注范围的解释 |
| 含陈设总高 | 897 mm：台盘基准 697 mm ＋最高玻璃壶 200 mm；均为外观估算 |
| 正面 | 抽屉与藤编门一侧，局部 +Z；左右以面对正面为准 |
| 材质 | 深木色、浅藤编及黄铜色拉手，图片外观近似；无材料性能推断 |
| 内部结构 | 左侧上下开放格、中央抽屉，右侧格栅藤编门；分区、板厚、脚轮及台盘细节均为估算 |
| 台面 | 左侧黑色排水盘，右侧双炉区；图片有黑色及木色茶盘差异，本模型采用第一张的黑色方案 |

模型为静态布局与外观近似，门、抽屉和陈设不提供交互。按参考图摆放右侧两只玻璃烧水壶、左侧六只小茶杯及一只高杯、一只茶壶和一只茶漏；上层左侧两只透明茶叶罐、右侧两只矮陶罐，下层三只高储物罐。玻璃、茶叶及陶罐纹饰均为简化几何。柜体仍为 720 mm，含陈设总高约 897 mm，尺寸与摆位均为图片估算。未模拟排水、电气、水路、内部五金或承重，不据此作安装核对。尺寸编辑按原有宽、深、高整体缩放，不能解释为厂家实际规格。无额外操作预留假设。

## 实现与数据

`src/core/product-rules.js` 定义柜体默认高 720 mm，并按 897/720 派生含陈设的垂直包络；`src/data/catalog.js` 定义默认宽深及价格状态；`src/render/tea-table-model.js` 为应用和独立预览共用生产构造器，藤编孔纹使用实例化几何，不引入外部纹理。`furniture-svg.js` 对齐顶视占地和正面方向。生产入口沿用原坐标、旋转、镜像、地面基准及缓存输入。

不增加持久字段、项目格式版本或保存机制。高度 h 继续表示柜体高度，陈设与柜体同比例缩放；产品包络用于空间／梁／吊顶检查及高度摘要。含本型号的核对上下文追加 `tea-table-accessories-v1`，要求旧记录重新核对，采购、价格和配色编辑不清除空间确认。原 w/d/h、颜色、位置、旋转和镜像沿原 mutate、历史及自动保存链路。旧项目保持原结构，缺 h 的本类型运行时读 720；其他茶吧机型号不变。复制、替换、当前／命名方案及恢复复用原规则。

运行 `node scripts/preview-tea-table.cjs` 生成 `output/tea-table/preview.html`，可直接离线打开或在本地服务中查看。
