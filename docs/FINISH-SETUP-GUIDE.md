# 地面与墙砖分步设定引导

入口：「地砖」或「墙砖」区域列表中的「分步设定引导」。当前范围为计入面积的厨房、卫生间和阳台；按区域用途识别，不按名称猜测。

1. 先确定厨房、阳台地面。点击区域的「设置地面标高」，在原浮动编辑器填写毛坯、面层、找平层，或选择目标完成标高，点击应用。
2. 再设置卫生间参考高差。参考区域应已确定完成标高；面层及毛坯独立保留，找平层留空可推算。5 mm 是可修改初值，不会自动覆盖已有降低量。
3. 在墙砖列表启用需要的墙面，再统一毛坯绝对起铺高度。应用保留各墙砖尺寸、砖缝、方向、横向起点及开关；关闭项不自动开启。
4. 查看汇总中的毛坯、完成地面、绝对起铺线和起铺线距完成地面的高度。可直接进入逐墙立面或空间核对。

示例：毛坯0、面层10、找平40时，厨房／阳台完成50；卫生间参考厨房降低5且面层10，留空找平推算35、完成45。墙砖绝对起铺50时，分别距完成地面0／5 mm。示例不自动填入项目，不作为现场实测值或施工要求。

引导可点击任一步，也可跳过暂未确定项；按钮上的完成标志来自实际已保存参数。没有地面记录、关闭地面、参考失效和未知高度均保留待确定，不能将旧显示的0当作已确认标高。起铺对齐检查只读取已启用墙面；部分关闭项保留关闭。不同竖向砖尺寸或砖缝另提示后续横缝可能不齐。

引导不保存独立进度、不新增项目字段、不改变旧项目版本。再次进入、刷新、撤销或重做后，从共用核心重算状态。每项应用仍经原编辑器的mutate、撤销和自动保存；单纯进入、导航或退出不写项目。通过引导内「返回本步清单／下一步」离开有草稿的编辑器时，先提示继续编辑或明确放弃；原编辑器其它关闭方式沿用原有行为。

`finish-guide-core.js` 提供浏览器／Node共用的只读状态检查，UI复用原地面／墙砖表单。完成状态仅表示参数关系已确定，不表示空间核对或工程验收已通过。真实触屏硬件未验证。
