# 完成面与起铺核对

2026-10-19：原分步引导已并入「铺砖」，不再逐个打开独立编辑器。旧调用打开同一工作区的「完成面与起铺核对」，没有独立进度或保存通道。

1. 选地面，在「厚度与标高」填写毛坯、砖厚与粘结找平层，也可显式选择目标完成标高或参考其它房间。多选统一部分字段，卫生间等例外单独修改。
2. 选墙面，确认启用状态、所属完成地面以上起铺或毛坯绝对基准。默认各自完成地面以上0；需要共用水平线时才选绝对标高。未修改的规格、偏移、关闭状态与分带保留。
3. 在平面／立面或3D检查实际排版；选择当前分带单独调整。实际范围始终由墙面、完成地面与门窗洞口决定，起铺仅影响网格相位。
4. 展开核对查看当前草稿。不同墙面／分带基准显示「多种基准」，未知保持待确定。整案家具高度基准在此明确选择，与其它草稿一次应用，保留家具原输入高度。
5. 取消、一次撤销重做及刷新恢复沿原项目链路。参数确定不表示空间检查或工程验收通过。

示例：毛坯0、砖厚10、找平50时完成60；卫生间找平45时完成55。墙砖可分别从60／55起铺，也可明确选择绝对60。示例不自动应用，不是现场实测值。

`finish-guide-core.js`保留浏览器／Node只读检查，覆盖每个已启用墙面的各带；UI为同一草稿汇总区。旧数据不补写、不推定未知值。详见[铺砖工作区](TILE-WORKSPACE.md)及[完整验收](validation/tile-workspace-complete-20261019.json)。
