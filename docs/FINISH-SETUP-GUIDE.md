# 地面与墙砖分步设定引导

入口：「地砖」或「墙砖」区域列表中的「分步设定引导」。当前范围为计入面积的厨房、卫生间和阳台；按区域用途识别，不按名称猜测。

1. 先确定厨房、阳台地面。点击区域的「设置地面标高」，在原浮动编辑器填写毛坯、面层、找平层，或选择目标完成标高，点击应用。
2. 再确认卫生间地面。可按毛坯、面层和粘结找平层直接计算，也可选择参考高差推算。直接填层厚即可完成此步，不要求另存参考关系。
3. 在墙砖列表启用需要的墙面，默认从各自完成地面起铺（完成地面以上 0 mm），卫生间与其它区域的绝对起铺标高可不同。需要跨区域同一水平线时才主动选择毛坯绝对标高。应用保留砖尺寸、砖缝、方向、横向起点及开关；关闭项不自动开启。
4. 查看汇总中的毛坯、完成地面、绝对起铺线和起铺线距完成地面的高度。可直接进入逐墙立面或空间核对。

示例：毛坯0、面层10、粘结找平50时，普通区域完成60；卫生间粘结找平45时完成55。墙砖默认分别从60／55起铺，均距各自完成地面0 mm。也可显式设置共用绝对起铺60，此时卫生间距完成地面5 mm。示例不自动填入项目，不作为现场实测值或施工要求。

引导可点击任一步，也可跳过暂未确定项；按钮上的完成标志来自实际已保存参数。没有地面记录、关闭地面、参考失效和未知高度均保留待确定，不能将旧显示的0当作已确认标高。起铺状态检查只读取已启用墙面，已知的各自完成面起铺与自定义绝对起铺均可完成此步；部分关闭项保留关闭。不同竖向砖尺寸或砖缝另提示后续横缝可能不齐。

引导不保存独立进度、不新增项目字段、不改变旧项目版本。再次进入、刷新、撤销或重做后，从共用核心重算状态。每项应用仍经原编辑器的mutate、撤销和自动保存；单纯进入、导航或退出不写项目。通过引导内「返回本步清单／下一步」离开有草稿的编辑器时，先提示继续编辑或明确放弃；原编辑器其它关闭方式沿用原有行为。

`finish-guide-core.js` 提供浏览器／Node共用的只读状态检查，UI复用原地面／墙砖表单。完成状态仅表示参数关系已确定，不表示空间核对或工程验收已通过。真实触屏硬件未验证。


区域地砖列表新增「批量设置地面标高」，支持选择全部／部分计入面积区域，统一毛坯、面层、粘结找平层，可单独指定卫生间粘结找平层；逐区域预览后一次应用，沿原 mutate 和撤销保存。非瓷砖区域同样设置面层标高。已有墙砖起铺设置不在地面批量操作中改写；若需把旧共用绝对标高改为各自地面，在墙砖批量入口选择默认的完成地面以上 0 mm 并应用。
