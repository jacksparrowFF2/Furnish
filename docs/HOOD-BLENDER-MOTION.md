## 源资产与接入

[可编辑Blender工程](../assets/models/hood/v2/hood-v1.blend)及[GLB](../assets/models/hood/v2/hood-v1.glb)包含27个具名网格、1个水平X轴父节点。上部玻璃等7个随动网格（玻璃、控制环、4个控制标记、品牌标记）共用该轴；下部玻璃、接油槽、楔形箱体和装饰罩固定。侧壁、顶板前沿及格栅按布局结构重做，不是厂家板厚／内部结构。

独立后台Blender根据参数制作几何，再以另一后台Blender重新导入，校验部件身份、闭合尺寸／中心、轴心与轴向、父子归属、静止变换及来源哈希，发布为离线普通脚本。控制环按实际环面采样校验尺寸，不能将旋转后的盒角当环面边界。失败保留上一有效资产；未操作用户活动Blender或旧精修工程。

```powershell
node scripts/blender-asset.cjs author-hood output/hood-new-source
node scripts/blender-asset.cjs publish-hood assets/models/hood/v2/hood-v1.glb
node scripts/create-fotile-previews.cjs
```

author拒绝覆盖已有源文件。Furnish毫米 `(x,y,z)` → Blender米 `(x,-z,y)`；运行不需要Blender／网络。此配置不支持任意第三方模型、动画片段、骨骼、形变、贴图或复杂节点材质。

## 尺寸与运动

`hood-motion-core.js`定义参考部件、尺寸拟合、当前轮廓及完整剖面；`hood-asset-model.js`构造实际导入网格。原 `fotile-model.js` 正式入口将JCD10TA交给资产模型，TH36B-T灶具继续原实现。预览使用同一正式入口，不以旧几何回退掩盖加载失败。

主机按实际 `w/d/bodyHeight` 拟合；装饰罩独立按 `coverWidth/coverDepth/总高−主机高` 构造并保持背齐。面板先在自身坐标拟合长度、宽度和厚度，再围绕缩放后的顶部枢轴刚性旋转，避免非均匀根缩放把已开启玻璃剪切变形。闭合倾角根据拟合后的斜面派生；开启绝对角保留−0.18rad图片近似，标称转动行程约48.36°。门厚按主机高／深中较小比例拟合。

`hoodPanelOpen:boolean`仍只保存原有闭合／开启状态；中间相位仅供生产构造器验收，不新增持久角度字段或电机动画。**顶部轴心、行程及隐藏结构为布局假设，不是厂家限位／五金尺寸。** 非标准比例只是草模；代表规格的自碰撞检查不证明全部合法数值组合均符合实际结构。

## 当前实体与完整开启

当前生产导入网格由数值记录器读取，通过 `bodyParts()`、`directional()`参与测距、吸附和碰撞，二维轮廓跟随面板，缓存覆盖开合及独立几何。此前只读两个闭合外包段；旧柜位测试改为检查实际生产部件。关闭时保留原有已知柜位适配，开启时不以柜位“容纳成功”豁免面板穿板。

完整开启核对始终覆盖闭合至定义上限，不随当前布尔姿态缩小。围绕水平轴，在深度—高度平面按≤2°采样，补足圆弧／弦误差后取保守凸包；沿玻璃宽度生成三维扫掠。复用 `FurnishCabinet.openingIntersects()` 的高度剖面裁剪，核对墙体、实际家具／柜板、梁、竖管、地面和净高；未知高度保留pending，定位显示同源扫掠。离地高度与完成地面基准只叠加一次。

剖面可排除扫掠包围盒里未占用的空角，但凸包仍可能保守误报，平面接触沿共用5mm容差；它不是逐三角面连续精确碰撞。当前实体碰撞沿共用高度裁剪截面，对倾斜薄件可能保守；自碰撞专项另外使用生产网格的竖向剖面，避免把两个斜面间的真实间隙当穿插。没有新增真实安装合规或管线验算。
