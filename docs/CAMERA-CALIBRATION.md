# 漫游物理视角校准

2026-10-30。入口为“显示 → 3D 场景 → 校准漫游视角”。手动水平 FOV 仍用于鸟瞰；启用校准后仅漫游使用物理投影，不移动相机或改写项目。关闭校准保留参数，可重新启用。刷新后恢复本机偏好；不同浏览器／来源的本机设置不承诺互通。

## 输入与操作

两种方式均需填写眼睛到屏幕的距离，单位 mm。

已有校准时可选“已有校准，只改眼距”，刷新后默认复用已存屏幕尺度，无需再次输入尺寸或重新测量标尺。

- 屏幕参数：填写整个发光区域的实际宽度，不含边框，以及系统当前显示设置的横向分辨率。不要填写浏览器窗口宽度或 Three 的渲染缓冲区宽度。
- 实测标尺：用实体尺测量面板中线段从左边到右边的长度。按实际 `getBoundingClientRect().width` 读取线段 CSS 宽度，不假设边框、窄屏或页面缩放后的线段仍恰好是 200 px。

24／27 寸快捷键使用所选 16:9 或 16:10，默认眼距 600 mm，距离快捷键为 500／600／700 mm。6.5 寸手机默认采用明确标注的 20:9 示例，也可选 19.5:9，默认眼距 200 mm，快捷键为 150／200／250 mm。预设只填草稿，不自动应用，也不猜测横向分辨率；需核对实际设备或用标尺实测。

对角线 `d` 英寸、横向／纵向比例 `r` 对应可视宽度 `W = 25.4 d r / sqrt(1+r²)`。手机示例按竖屏采用 `r = 9/20`。数值不是厂家型号尺寸。

| 示例 | 可视宽度 | 眼距 | 整屏水平张角 |
| --- | ---: | ---: | ---: |
| 24 寸 16:9 | 531.3 mm | 600 mm | 47.8° |
| 27 寸 16:9 | 597.7 mm | 600 mm | 53.0° |
| 24 寸 16:10 | 516.9 mm | 600 mm | 46.6° |
| 27 寸 16:10 | 581.6 mm | 600 mm | 51.7° |
| 6.5 寸 20:9 竖屏示例 | 67.8 mm | 200 mm | 19.2° |

表中为整屏角度；实际 3D 画布通常更小，程序使用画布实际宽高，不能直接把整屏角度设给画布。

## 投影与缩放

`src/core/navigation-input.js` 提供纯函数和本机偏好接口，沿原经典脚本加载，不增加依赖：

1. 由整屏宽度／横向分辨率，或实测线段宽度／（线段 CSS 宽度 × 当前 DPR），得到 `mmPerPixel`。
2. 画布物理宽高 `w = clientWidth × DPR × mmPerPixel`、`h = clientHeight × DPR × mmPerPixel`。
3. 眼距 `D` 对应水平角 `2 atan(w / (2D))`、垂直角 `2 atan(h / (2D))`；角度转为度数。
4. Three 的 `camera.fov` 使用垂直角，aspect 使用画布宽高比；校准不受手动镜头 40–90° 范围或垂直 75° 上限限制，避免把窄视野误改宽。任一方向低于 1° 或超过 150° 时明确回退手动，并提示参数无效，不暗中限幅后仍宣称完成物理匹配。

依据：[Three PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html) 定义 `fov` 为垂直视场；[MDN devicePixelRatio](https://developer.mozilla.org/en-US/docs/Web/API/Window/devicePixelRatio) 定义设备像素／CSS 像素比例，页面缩放会改变 DPR，手势放大不改变 DPR。模型按画布张角采用中心针孔透视推导。

ResizeObserver 处理侧栏与窗口变化；原渲染循环检测 DPR 改变，覆盖画布 CSS 尺寸未变时的页面缩放。物理换算使用真实 DPR，与渲染器为性能将像素比限制到 2 的策略分开。进入／退出漫游、刷新后重入与语言切换同步更新读数。校准表单按钮不走菜单自动收起，显示菜单复用工作流的视口内定位和滚动，窄屏不会偏出视口。

## 数据与边界

偏好独立存于 `furnish-camera-calibration`：`enabled`、`mmPerPixel`、`distanceMm`。读取严格验证并复制，损坏记录回退手动；存储不可用时当前会话仍可应用。无新增项目字段／格式、空间核对输入或撤销通道，手动水平镜头键保持。

按正对画布中心的固定单眼视点计算。更换显示器、改变系统分辨率或设备旋转后应重新核对尺寸；不自动识别设备物理宽度。手势放大／平移页面、眼睛偏离画布中心、头部移动、双眼视差和屏幕弯曲不在本次校准内。观看距离改变时可选距离快捷键，但没有自动测距或头部跟踪；实际效果仍需用户在真实设备上验收。
