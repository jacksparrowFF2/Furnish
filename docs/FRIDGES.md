# 冰箱模型与尺寸编辑

家具库「电器」新增「纯平四门冰箱（双抽屉）」，类型 `fridge_french_drawer`。

## 资料与尺寸

- 依据用户提供的两张产品图片（2026-10-12），尺寸图标注宽 83.3 cm、深 59.5 cm、高 191 cm；默认外包尺寸为 **833 × 595 × 1910 mm**。
- 上部对开门、下部两层全宽抽屉、两条深色内凹拉槽、右门竖向显示屏、白色平整面板及小支脚按照片近似制作。
- 具体型号与价格未知；库中的 0 是待填写价格占位，并非采购报价。
- 局部正面朝 +Z，宽沿 X、高沿 Y；最低点为地面。外包尺寸包含支脚和外观细节，不叠加安装预留。
- 图片标注两侧各留 2 mm、底部散热，仅记录为图片资料；型号与完整安装手册尚未确认，本次未增加施工或散热验算。

## 编辑与兼容

原有「冰箱」「对开门冰箱」和新增款均支持属性面板宽、深、高编辑。旧冰箱缺少 `h` 时仍默认 1800 mm；新增款默认 1910 mm。复用现有 `w/d/h`、尺寸调整基准、锁定、撤销、自动保存、复制、导入导出和 3D 缓存机制，无新增存储字段。

所有冰箱的完整外包框按输入尺寸缩放；原有外凸把手纳入深度。缩放仅用于布局，不代表修改真实产品规格。新款二维图例显示占地及前端对开门接缝；抽屉层数由三维正面表达。静态模型未实现开门、抽屉拉出、内部结构、商标或精确白色纹理。
