# 床头反射灯槽与灯光预览参数

2026-11-14。`cove_light`是易来L2灯带方案的定制反射铝槽，不是易来成品灯具或官方型材的复制。商品参考为https://item.jd.com/10096645938884.html；商品确认与待核参数保留在D盘选型目录。本次没有据未确认的瓦数反推流明。

## 参数与生产

默认2000×45×35mm，长／深／高和底部mountHeight独立。默认底部离完成地面1250mm，支撑条与乳白扩散件向上发光，前挡边遮光；1.5mm壁厚、10mm灯带宽、6mm发光高度均为定制方案估算，非厂家安装图。宽至少100、深25、高20mm，规则集中在product-rules.coveLight；生产构造器与数值实体共用，包含五块壳板、承托、扩散体及上发光薄面。没有空腔碰撞豁免。

`lightPreviewLevel`为0–100%，`lightKelvin`为2700／3000／4000K的预览选择，色值为RGB近似；新灯槽初始30%／3000K，缺失仅读相同值。辐射量由每米100cd的规划估值乘长度与预览比例，再沿lighting-core的683约定换算。未知真实光通量、IES和最低稳定调光范围，不能据成图验收照度／眩光。

床头灯槽独立于“顶灯”总开关：其光面和光源带independentEmitter／independentLight，只按自身预览亮度开关，0为关；隐藏图层／物体仍完全不出光。此能力仅标记的新灯槽使用，旧筒灯、主灯、浴霸、桌面灯及吊顶灯带保持原总开关语义。

通用surface_light与MJTD07YL也可选lightPreviewLevel，旧缺失仅读100%，新建不补字段；各自仍跟随原顶灯开关。此字段只改变预览亮度，不宣称成品可调光或已控制真实设备。0关闭全部实际光面与直接／虚拟采样。

## 兼容与范围

参数／类型显式保存采用v91，当前／命名／我的家具／项目／仓库／IndexedDB及快速缓存沿原链路；旧版本仍可读。复制、同型替换保留，跨型按共用字段能力清理。编辑走mutate和原undo／autosave，没有新保存通道。三维快照缓存读取亮度与色温；它们不改变物理实体，不清空间确认。尺寸、位置、朝向、镜像和底高保持原空间签名。

2D使用长条截面，3D／数值实体／生产GLB来自同一构造；高清读取真实上发光矩形，Cycles读取独立发光薄面，不重复输出实时聚光替身。定制参数化部件不新增Blender作者资产；整链路以parametric路线验证正式导出和Blender回读／渲染。
