# 建模资产存放与整理

2026-10-31。**Furnish仓库是资产及元信息的统一来源**。[产品索引](../assets/models/README.md)和[机器可读索引](../assets/models/index.json)随Git提交，使用项目相对路径，记录当前发布源、来源哈希、其他版本、材质工程、型号文档和构造入口。本机D盘整理库仅是可选导出副本，不负责判断正式版本。整理不改变加载、产品规则、项目数据或材质发布能力。

## 统一入口与维护

```powershell
node scripts/index-model-assets.cjs --write
node scripts/index-model-assets.cjs --check
```

前者更新项目内README／JSON，后者检查索引未过期、来源哈希匹配与所列文件存在；生成结果可重复且不包含时间戳、机器绝对路径或当前方案。输入沿现有生产规则和`model-profiles`验证清单，不另建第二套产品注册。新增／发布模型后更新索引并随资产一起提交。索引是管理元数据，不作为浏览器新的加载清单。

模型源、运行资产、规则、资料按职责留在现有目录，通过产品索引关联，而不是把它们强行搬到同一个文件夹。D盘副本用于人工查看、精修或交付，修改副本后仍须经原发布流程回到项目。

全屋精修工程体积较大且存在本机绑定，保留在原`D:/1601装修/渲染`；当前绑定继续由未入Git的`.local/blender-project.json`维护。本次建立16份本机BLEND的只读入口，未复制这些大工程。用户项目与本机路径不进入公共资产索引。

## 正式来源与用途

| 位置 | 内容 | 使用约定 |
|---|---|---|
| `assets/models/<profile>/` | 作者BLEND、GLB、部分参考图和材质精修工程 | 保留版本目录，运行资产来源哈希决定当前源 |
| `src/data/*-blender-asset.js` | 已发布的离线几何／基础材质 | 浏览器直接打开与本地服务共用；不能独立移动或手改 |
| `src/render/*-model.js`、部分`index.html`入口 | 生产模型装配及参数化构造 | 预览、空间实体及生产导出共用 |
| `src/core/` | 产品默认值、部件、尺寸／运动等规则 | 不能以导出静态网格替换柜体参数化规则 |
| `scripts/blender-model-*.py`、`scripts/blender-asset.cjs` | 可重复建模与严格发布 | 新目录重建，失败不覆盖上一有效资产 |
| `docs/<型号>.md`、`docs/references/`、`docs/validation/` | 资料依据、参考图、验收报告及截图 | 文档中的验证范围以实际记录为准 |
| `output/`、`.local/` | 隔离验证副本、试验、渲染任务、下载及精修绑定 | 不视为正式模型库，不因目录名／大小判断可删除 |

当前盘点：15组Blender配置，93组整链路清单配置中另有78组参数化配置；家具库137条目、110种type。验证配置数、产品类型数与可下载文件数是不同概念。源目录现有26个BLEND（含4份material-studio）与22个GLB；不能把48个文件当成48个产品。

## 本机整理副本

本次输出 `D:/1601装修/建模资产库`，产品图片独立位于同级的 `建模参考图片`。打开 `资产总览.html`，可按产品／型号搜索，进入当前BLEND／GLB、型号文档、生产构造器和作者脚本。

```text
建模资产库/
  资产总览.html
  资产索引.json
  资产文件清单.csv
  家具库条目.csv / 全部家具库条目.json
  Blender成品模型/
    <产品名> [profile]/
      当前发布源/           # 本次识别的BLEND和GLB副本
      离线运行资产/         # 供追溯，非独立运行包
      其他保留版本/         # 非当前发布源，保留原相对版本路径
      材质精修工程/         # 不混作作者几何源
      来源记录.json
      来源与使用说明.txt
  参数化模型/
    配置索引.json
    说明.txt
```

本次复制63个资产文件，全部逐项SHA256验证；源文件未移动、重命名或删除。当前GLB由`model-profiles.sourceFiles()`按运行模块的`sourceSha256`定位，同时保留同路径BLEND，拒绝来源不符；不根据vN大小或mtime猜测当前源。BLEND与GLB配对沿现有约定，本次不重开Blender证明二者几何一致，不新增模型验收结论。

副本中的历史／材质工程保留可恢复性，不表示均已验证或可直接发布。修改副本不会自动同步到Furnish，应在新版本目录精修，经作者预检、独立发布及对应增量验证后更新正式源。程序材质节点不等于已烘焙GLB贴图。

参数化柜体、窗饰及旧构造没有独立作者BLEND，索引保留真实构造路线。需要某个尺寸／姿态的静态GLB时从Furnish实际生产入口导出；历史测试导出不充当当前官方模型。137条家具库条目另列，避免将78组验证样本误称为全部参数化产品。
