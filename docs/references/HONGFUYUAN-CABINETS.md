## 主卧尺寸链的可验证事实

三段内部宽之和：`416.4 + 866.8 + 867.8 = 2151`。

与总宽差：`2295 - 2151 = 144`。

由尺寸定义点读取：左端 36、第一段间隔 36、第二段间隔 36、右端 36，故 `36 + 416.4 + 36 + 866.8 + 36 + 867.8 + 36 = 2295`。

用户于2026-10-28确认：“对，是独立柜箱加两侧见光板”。对应三个柜箱各有两块18厚侧板，左右各另有一块18厚见光板；净宽加六块侧板108和两块见光板36，得到2295总宽。柜箱外宽依次452.4／902.8／903.8，总计2259，再加两侧见光板36闭合。

这是一项已确认的生产结构依据。共享隔板模型若直接套用三段净宽会得到不同外宽，不能静默吸收差额；当前设计应分别表达柜箱连接和饰面板，并保留当前房屋自己的尺寸与需求。
