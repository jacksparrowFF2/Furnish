# 吊顶与照明规划（2026-11-13）

本次新增通用灯体和受限 MCP 编辑能力，服务于 1601 的设计副本。正式方案通过 MCP 复制、编辑和保存，未直接改写用户项目 JSON；方案数据和效果图保留在用户装修目录，不随源码发布。

## 通用灯体

`surface_light` 是可调尺寸的布局占位，默认 600×400×50 mm，底部离地 `mountHeight` 默认 2500 mm，仅为新建初值。没有厂家型号、价格、光通量或安装要求。它复用现有整板设备的参数化灯体构造器，但没有 `ceilingPanel` 能力，不能替换铝扣板或自动打孔。

普通家具的尺寸、底高、旋转和镜像进入同一生产构造、数值实体、净距和项目恢复。前沿沿原 +Z 语义；发光面向下。小型床头／镜前／柜底占位只表示位置与体量，不能当作已选定的成品型号或壁装结构。

灯面、边框和背壳为通用几何，不属于参考图固定产品建模，因此无新增 Blender 资产。已有 SE2 和 G12 的 Blender 网格、29件／原各款部件身份及实体尺寸不变，只在运行时增加非实体光源与已有发光面材质控制；无需升级空间几何版本。

## 实时光照边界

通用灯以一个向下半球采样近似面光，600×400 mm 参考体量为100 cd，按面面积比例缩放到0.15–2倍，两个弱反射采样合计4 cd并同比例缩放；颜色 `#fff1dc`。这是一组展示假设，不能用于反推灯具流明、色温、瓦数或室内照度。实际主灯建议固定暖白4000 K、灯带2700–3000 K可调光，采购规格另行核对。

SE2 仅给已有 `diffuser` 增加展示发光，三个向下采样合计60 cd、颜色沿规则；没有从24 W推算流明。G12仅 `nightlight` 款的 `diffuser` 和0.6 cd、1.8 m有限范围的向下光参与夜景，其他面板不会发光。夜景表现为感应触发后，未实现真实红外范围、延时、环境亮度阈值或米家联动。

顶灯总开关控制筒灯、通用灯、SE2及原灯带；夜灯依照原 `scene3d.night` 独立显示。所有修改沿原场景设置、撤销与保存，没有新增方案字段。

全屋同时启用大量面光采样，曾实际触发 `MAX_FRAGMENT_UNIFORM_VECTORS(1024)`，导致标准材质不显示。正式场景现在在每次渲染前按相机距离分配局部光源：同一家具／吊顶构件先取一个采样，再分配额外采样；最多24个展示光源、6个展示阴影，并按当前显卡 uniform／纹理数量进一步收紧。建筑日照保持原机制。灯面发光和实体一直保留，关闭／隐藏的父层不会被预算重新点亮，相机移动会恢复附近原本启用的灯。

预算用于实时查看，远处照明、漫反射和阴影会近似；截图并非全屋光度仿真。GLB生产导出仍沿原实体与材质链，不宣称携带这套运行时感应和光源预算。

## MCP

新增 `get_ceilings/configure_ceilings/remove_furniture/configure_scene/add_furniture_batch`，共16工具，契约见 [MCP.md](MCP.md)。吊顶完整区域沿 `setRegion/removeRegion` 重新生成；家具批量新增沿库构造、共享尺寸／参数校验、一次原 `mutate` 和正式 `flush`。默认层、已有构件及家具锁定均须尊重，错误整批拒绝；没有另一套方案、保存或撤销机制。

测量使用原顶与完成地面绝对mm。当前1601普通地面完成层60 mm、卫生间55 mm，不能把2700 mm模型原顶标高直接当作完成面净高。新旧方案保留这些既有输入，输出净高须注明基准。
