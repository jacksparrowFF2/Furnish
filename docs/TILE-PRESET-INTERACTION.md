# 铺贴预设：正式使用与参数范围（2026-10-19）

已接入实际 Furnish。原先的[独立交互示意](validation/tile-presets-20261019/demo.html)保留作方案记录；实际编辑从主页面「铺砖 → 预设」进入。

## 保存和应用

当前入口为「铺砖 → 预设」。选择分项和覆盖组后「填入草稿」，实际墙地、洞口及生产3D预览共用当前工作草稿，点击「应用铺砖」才一次写入。默认复制为独立参数；需要持续订阅时明确选择关联方式。跨房间多选与不同墙面分项可在同一草稿中逐面设置。

预设库从「管理预设与关联」进入，保留新建、另存内置、保存当前排版、编辑、删除与关联管理。库内拖放或点选房间打开同一铺砖工作区并预选此预设，不再弹出另一份参数应用表单；库内多分项需在工作区按实际墙面明确选择，不按来源面号推断新房间混排。内置预设只读，持续关联时生成可编辑副本。

工作方案、命名方案、项目复制、导出导入、仓库及本机自动保存继续携带预设和关联。打开旧项目不补写或重新套用，不推断来源。完整流程见[铺砖工作区](TILE-WORKSPACE.md)。

## 关联更新与独立设计

- 预设卡片的「已关联 N 处」可查看目标房间／墙面和每处同步范围，勾选后解除关联会保留当前排版。
- 一个表面关联一个预设，重新应用会替换该表面的原关联和同步范围；同一个预设可关联多个房间与墙面。
- 删除预设或分项会解除相应关联，保留实际铺贴。原墙侧／房间不再存在时，不按墙面编号猜测新目标；下次保存预设会清理失效关联。
- 铺砖默认「仅修改此处」：只解除实际改变的参数组，其它组和其它表面继续跟随；同值输入不解除。「更新预设及其关联表面」在同一草稿同步来源与订阅者，取消全部回退、应用后一次撤销。未订阅的参数保持独立；旧文件恢复不会因这些操作语义自动解除关联。
- 「保存当前排版」仅创建参数库快照，不推断哪些既有表面使用该预设；通过应用明确建立关联。
- 关联保存在当前工作方案内，不跨工作槽或历史命名方案实时修改。复制、命名快照和导出会携带关联。

## 参数范围

| 参数组 | 墙砖 | 地砖 | 应用时默认 |
| --- | --- | --- | --- |
| 砖规格、旋转方向 | 宽高20–6000 mm；0°／90° | 宽高20–6000 mm；−360°至360° | 覆盖预设所含字段 |
| 砖缝宽度 | 0–50 mm | 0–50 mm | 覆盖 |
| 美缝 | 跟随砖色／自定义；按选中墙面保存 | 跟随砖色／自定义；按房间保存 | 覆盖 |
| 材质 | 沿用当前共用墙砖材质 | 当前已有的瓷砖、石材类地面材质 | 覆盖 |
| 同墙上下分带 | 2–20带、各带上沿、规格／方向／缝宽，最后延伸至墙顶 | 不适用 | 预设包含时覆盖分带；起铺仍单独选择 |
| 起铺位置 | 沿墙偏移 | 原图坐标X／Y | 保留 |
| 起铺高度 | 数值与完成地面／毛坯绝对基准 | 包含在地面标高组中 | 保留 |
| 墙地对缝 | 是否自动跟随地砖 | 地面本身为对缝基准 | 保留 |
| 层厚 | 墙砖厚度、粘结层厚度 | 地砖厚度、粘结找平层厚度 | 保留 |
| 地面标高 | 不适用 | 毛坯标高；按层厚／目标完成标高／参考其它房间；参考房间及降低值 | 保留 |
| 排版启用开关 | 分墙面 | 分房间 | 保留 |

预设编辑时，勾选参数组才把该组包含在预设内；应用时再次决定覆盖哪些组。未知层厚与标高可以留空，不推定工程尺寸。房间专属起铺与参考标高通常不要跨房间复制；错误的自引用会被核心校验拒绝，未知或循环参考会继续以待核对提示。

砖面图片／自定义墙砖纹理、采购价格、材料包装规格、损耗率、地漏找坡不包含在此预设中；这些不是当前铺贴网格或材质字段。纯配色与仅修改预设库不清除空间确认，实际厚度和标高仍参与完成面及空间核对。

## 混排的范围

一个预设可以有多个分项，例如「主窗800×800」「窄墙400×800」「柜后800×400」，每个分项还可以有不同的缝宽、美缝和高级参数。正式支持**不同墙面编号使用不同分项**。从当前阳台保存的预设附带来源编号分配建议，但只有来源房间与墙面绑定完全相同才使用建议；当前房间已经混排时仍默认保留，需逐面明确指定。

同一面墙现在支持上下分带，洞口由生产几何裁切；不支持随机拼花或同一地面大小砖组合。地面预设可保存多个候选分项，每次给一个房间选择其中一个；不能将多候选称为同一地面的混铺。

单墙美缝优先于房间颜色；恢复随砖色可覆盖房间的自定义色。房间美缝编辑和全屋统一美缝会显式统一所选房间全部墙面，并清除这些房间的单墙覆盖；打开混色房间时先保留现状，选择方式才开始预览。

## 同一面墙上下分带

在「铺砖」选定单墙，展开「墙面上下分带」。也可在预设编辑的「同墙上下分带」参数组保存同样配置；内置有可修改的分带示例，示例高度不会自动应用。

- 预设未勾选此参数组时隐藏全部分带设置；选择「取消分带，沿用整墙参数」时隐藏各带明细、分界基准和增加带按钮。重新勾选或切回分带恢复本次表单草稿；只有显式保存／应用才写入项目。
- 可设置2–20带，从下往上输入每带上沿，最后一带自动到墙顶。边界以所属完成地面或毛坯绝对标高为基准；不改变地面标高或墙层厚。非法／重叠／倒置边界会阻止应用。
- 「按本墙洞口上下沿分带」读取当前墙面实际可铺区域的高度变化，包括窗台、窗顶或门顶；生成草稿后可继续改高度与各带规格。没有对应洞口或完成地面未知时保留待核对，不推定工程尺寸。
- 每带分别设置砖宽、高、0°／90°方向及缝宽；可选独立偏移、起铺高度基准与跟随地砖对缝。空白字段继承整墙设置。各带共享整面墙的美缝与物理层厚，不支持每带不同砖面色／厚度。
- 门窗孔洞继续留空，分带范围裁切到实际墙面。分界缝宽取相邻两带中较大值，两边各退半缝；仅在真实实体墙面上生成美缝面，立面与生产3D共用几何。
- 预设应用默认包含分带区间、各带规格／缝宽，仍保留目标的起铺基准；来源预设的单带起铺与对缝只在相应高级参数被勾选时复制。整墙普通预设不自动取消既有分带，各带显式覆盖值优先；需要整墙铺贴时，在分带方式中明确选择取消。
- 应用前查看实际立面草稿，应用后更新实际3D，可一次撤销、刷新恢复、保存为预设并随项目导入导出。分带起点支持数字编辑和二维／三维手柄；先选择当前分带，只改变该带。整墙默认参数和当前分带实际参数明确区分。

## 瓷砖观察

当前铺砖工作区的独立生产3D预览直接查看墙地与层体，不加载家具；关闭后不影响主场景家具显示。旧瓷砖观察API保留兼容，没有独立主工具栏入口。

## 数据与验收

可选`tilePresets.version=1`存储无关联的参数库；含关联时为`version=2`，`bindings`保存预设／分项编号、房间及稳定墙侧绑定、应用参数组，使用外层版本14与v14缓存；旧版本仍可读，不在恢复时自动改写实际排版。`tileGrout.walls`用墙面绑定存储单墙颜色。预设库或单墙美缝使用外层版本12；含实际分带或分带预设（含明确取消分带选项）使用外层版本13，仍接受旧版本。房间级颜色继续可用版本11。规则在`src/core/tile-preset-core.js`与`tile-grout-core.js`，正式编辑沿`mutate()`，不新建保存或历史通道。

同墙分带专项见[验收记录](validation/wall-tile-bands-20261019.json)。正式预设集成专项验收及算法边界见[正式预设验收](validation/tile-presets-integrated-20261019.json)。
