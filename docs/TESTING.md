# Furnish 实机测试清单

## 户型库管理与文件分享

- 户型库顶部统一提供「导入 DXF／图片 · 新建户型」和「加载户型／项目文件」。主工具栏原导入入口改为「编辑户型」，继续编辑当前数据。
- 每张卡片可「导出」，文件为 `.furnish.json`，含户型结构、原始基线、门窗／飘窗尺寸、家具、材料、命名方案和项目附件。接收方在户型库加载文件、检查预览并「加载并编辑」即可恢复。
- 自定义户型加载遇到已有编号时创建独立副本，当前方案、命名方案及原基线／历史结构编号一并转换，已有户型不被覆盖。内置示例文件恢复对应内置户型的方案。
- 自定义卡片可「删除」，确认后清除该户型的布置、命名方案和历史快照。删除当前户型时先切换其他户型；刷新应保持删除。内置示例不提供删除。
- 内置三室两厅两卫中，同一飘窗的三面窗高度、窗台高及台体高度同步；重置也整组恢复，切换户型后仍能重置。应用尺寸按钮保持橙色背景、白色文字。
- 运行 `node tests/test-plan-sharing.cjs` 检查分享格式及副本编号转换。浏览器验证真实导出文件加载到空浏览器、删除后刷新、飘窗三面同步及按钮可读性。

## 飘窗转角与三维门开关

- 自定义飘窗三面窗共享转角中心线，前面两端与侧面的前端坐标一致。每个前角只生成一根60 × 60 mm方柱；上下窗台墙与过梁以同一条中心线形成连续接缝，避免两根偏移柱及墙体错台。
- 三维拾取忽略隐藏对象及非网格辅助线，尤其不允许已剖切隐藏的天花拦截门扇。真实可见墙体仍能遮挡点击。
- 在三维鸟瞰中点击可见门扇，应关闭；再次点击应打开，角度动画正常。漫游点击与E键共用同一拾取逻辑。
- 浏览器检查实际网格中每个飘窗前角有且只有一根方柱，并实测门打开→关闭→打开。`node tests/test-bay-windows.cjs` 检查三面窗共用端点且处于相邻墙体范围内。

## 原始结构解锁与精确窗尺寸

- 结构编辑器在锁定阶段显示「解锁并重新核对原始结构」。确认后回到录入阶段，保留当前墙体、门窗、户型编号和家具；取消或不保存则不改变已保存的结构。修改后重新确认并保存即可建立新基线，无需重新导入。
- 保存结构重新核对结果时清空旧撤销历史，避免历史操作恢复过期的基线。原基线保留在完整项目的 `originalRevisions` 中，最多10份；该档案目前没有独立恢复按钮。
- 自定义普通窗使用手动毫米输入：窗宽、洞口窗高、窗台高；窗顶＝窗台高＋窗高，且不超过2800 mm。输入后点「应用尺寸」，同步三维、墙漆量和方案保存，窗宽调整仍检查墙角／其他洞口／隔墙交接冲突。
- 窗高至少100 mm，窗台高允许0–2400 mm。内置预设布局可精确编辑窗高与窗台高；预设窗宽仍按图纸定义。已锁定承重／外墙上的自定义窗需先解锁原始结构再改尺寸。
- 面板使用单列输入并格式化数值，不再把墙厚当作窗高，不再显示浮点长尾。验证290 px面板和390 px手机布局无横向溢出。
- 运行 `node tests/test-window-dimensions.cjs` 检查毫米高度、使用面积、几何范围、结构锁定、备份和旧版数值窗台覆盖兼容。

## 综合 DXF 示例（2026-10-08）

- 「DXF 模板与规范」现在只提供一份综合示例下载／直接加载入口：`furnish-template-complete.dxf`，替代此前分开的多墙厚和窗／飘窗示例入口。旧文件保留作历史回归夹具。
- 标准 R2000 ASCII DXF 已通过独立库重新读取和审计；此前窗示例的 LWPOLYLINE 缺少 `AcDbPolyline` 子类字段，会被严格 CAD 读取器拒绝。
- 选择默认墙层应得到 12 段墙、3 个房间、净面积 21.5912 m²。墙厚预填 200／240／100／120 mm；两个 GUIDE 图层默认不选。
- 中间 100 mm 隔墙有 3 段，右侧 120 mm 支墙形成 T 形交接。选择中间任一段再「选择整组折墙」，批量改厚仅影响这 3 段。
- 下侧外墙的 1200 × 600 mm 落地外凸折形计入面积，外墙 7 段属于同一组。顶侧青色抬高飘窗参考线不作为外墙导入，也不增加面积。
- 普通窗位于顶墙 CAD X=1000–2200；导入后在 X=1600 补录 1200 mm 窗洞。飘窗位于 X=3600–5200，在 X=4400 使用「飘窗」补录：洞宽1600、外凸进深600、台高450、窗顶2400 mm。保留完整基墙，独立窗台与三面窗由应用生成，不计净使用面积。
- 运行 `node tests/test-complete-template.cjs` 检查图纸、离线嵌入内容、折墙编组、多墙厚修复及两扇窗洞面积不变。

## 自定义飘窗实体

1. 在原始结构录入阶段，选择「飘窗」，设置门窗宽、外凸进深、窗台高、窗顶高，再点击房间与室外之间的外围墙。不得与门窗、墙角、隔墙交接或其他飘窗重叠；朝外方向自动识别。
2. 保存后二维显示独立窗台和三面窗；三维窗台高度、三面玻璃及窗台墙体与输入一致。净面积和房间数不包含窗台，窗台材料单独参与材料估算，墙漆只扣基墙上的洞口。
3. 点击任一面窗可修改位置（距所属墙起点）、洞口宽、进深、台高和窗顶，或删除飘窗；支持撤销／重做、刷新及完整项目备份恢复。确认原始结构后承重／外墙及其飘窗锁定。
4. 运行 `node tests/test-bay-windows.cjs`，检查水平／竖直／反向墙上的几何、净面积、墙漆扣减、错误尺寸、内墙拒绝、结构锁定与备份恢复。

当前支持直墙上的矩形外凸窗台与三面窗，不支持弧形、斜面或跨墙角飘窗。

建议先「项目工作台 → 项目备份 → 导出完整项目」，然后用示例新建户型测试。请保留当前浏览器与 `http://127.0.0.1:8765/` 地址：换浏览器或端口会使用另一份本地存储。

## 1. 原始结构录入与确认

1. 点击「导入 DXF / 描图 → 新建」，导入 `sample-layer-walls.dxf`。
2. 勾选两个图层，把 BEARING 指定为承重，PARTITION 指定为非承重。
3. 导入后先处于原始结构录入阶段。点击外墙顶部约四分之一的位置补录原有门；勾选「入户门」可作为漫游入口。避免隔墙交接处和墙角。
4. 「墙属性」可修改每段墙的类型、厚度、起点坐标和长度。坐标相对于描图画布，单位 mm。
5. 点击「确认原始结构并锁定」，再「保存装修方案，开始布置」。之后承重墙／外墙不可删除、移动、改型或增删门窗；已有门的开启方向仍可在主界面调整。

预期：原始结构保存后不随装修方案修改；再次打开编辑器，锁定墙仅可查看。之前版本保存的自定义户型自动迁移为已锁定结构。

## 2. 真实拆改、房间和材料

1. 原始示例使用 200 mm 墙厚，识别两个房间，净面积合计 **21.28 m²**。
2. 编辑器中用「墙属性」把中间非承重墙的 X 坐标增加 250 mm。两间房面积应改变，总净面积仍为 21.28 m²。
3. 在主界面启用「拆改」，点击中间隔墙。整段中心线墙及关联门窗被拆除，原轮廓保留红色虚线。
4. 房间应合并为一间，净面积变为 **22.04 m²**；地面材料数量和墙漆面积同步更新。
5. 撤销／重做应恢复／重做拆改；拆改工具下点击红色已拆墙可按原始结构恢复。移动墙的旧轮廓需用墙属性或撤销恢复。
6. 项目工作台可查看原始／当前户型及拆除、新建长度，并下载拆改对比 SVG。

边界：真实拆改适用于自定义户型。内置 12 套示例保留原项目拆除标记方式。房间合并时采用与新房间重叠面积最大的原房间材料；如有混合铺装，请核对并重新选择材料。当前支持正交闭合户型，不支持庭院／独立柱岛。

## 3. 多方案比较与完整备份

1. 拆墙前保存「方案 A」，拆墙后保存「方案 B」。比较 A/B 的房间数、面积、拆改量、家具和总预算。
2. 通过文件菜单载入 A/B，检查墙体、家具、材料、工程费用是否各自独立。
3. 在项目备份页添加原始 DXF、PDF 或报价附件，再导出完整项目。附件需手动添加；图片底图和网格模型已自动包含。
4. 在另一浏览器／空浏览器存储中导入项目，核对原始结构、所有命名方案、当前方案、工程费用、品牌资料、模型和附件。
5. 旧版「导出方案 JSON」可从项目备份页迁移导入。损坏的完整项目或更高版本文件应明确拒绝。

完整项目文件包含版本与校验值。每个附件最多 2 MB，最多 5 个；完整项目导入上限 30 MB。本地保存增加 IndexedDB 大容量镜像，原存储不足时可回退；浏览器数据被清除仍需通过项目文件恢复。

## 4. 使用空间检查与工程预算

1. 家具放到门的开启范围内，运行使用空间检查，应该提醒开门与家具冲突。也检查门与墙、两扇门的开启范围。
2. 在品牌家具资料里填入正面使用空间，例如 600 mm；把另一个家具靠到其正面，再检查柜门／抽屉空间。正面沿家具本地“下方”，旋转会同步改变检查方向。
3. 自设间隙提醒阈值（默认 800 mm），检查候选狭窄间隙；提醒不等于完整的通行路径或规范判定。
4. 添加人工费用：工程量来源选净面积，单价填 100。原两房应计 **¥2,128**，拆墙后一房应自动更新为 **¥2,204**。
5. 水电、防水、吊顶、定制柜等可手填工程量，或绑定净面积、涂刷面积、拆墙／新墙长度。编辑、删除和完整报价 CSV 应与主界面总预算一致。

预算默认按层高 2.8 m、门高 2.1 m、窗台 0.9 m／窗顶 2.4 m 估算；内门按两个墙面扣洞口。单价由你输入，避免与已有家具、地面、乳胶漆重复计价。

## 5. 品牌家具、外部模型和 PDF

1. 录入品牌、型号、实际宽深高、单价、日期和来源链接。新家具会进入「我的家具」，放置副本应保留资料。
2. 导入 `sample-furniture.obj`，例如设置 1000 × 600 × 2000 mm，切换 3D 核对尺寸比例。保存、刷新、备份恢复后网格应仍存在。
3. OBJ 为静态网格，Y 轴向上；支持多边形三角化及负索引，上限 2 MB／20000 三角面。暂不支持 MTL、贴图、GLB 或动画。
4. 使用「辅助：导入图片 / PDF」导入 `sample-floorplan.pdf`。PDF 渲染为图片底图，多页可选择页码，仍需两点校准并描墙。
5. 示例外框两端对应 6000 mm，描四面外墙及中间隔墙、墙厚 200 mm 时，应识别两个房间，合计 **19.88 m²**。

PDF 必须通过本地 HTTP 页面打开；当前 127.0.0.1 页面可直接测试。另开项目时运行 `node scripts/serve.cjs`，无需 npm 安装，也不把文件上传到在线服务。DXF／图片仍支持直接打开 HTML。

## 中心线多墙厚、折墙与窗户补充

- 「DXF 模板与规范」新增可下载／直接加载的**多墙厚／折墙示例**和**窗／飘窗辅助示例**。原有 200 mm 两房模板不变。
- 导入多墙厚示例：图层预填承重 200、外墙 240、非承重 100／120 mm；各层可分别修改。预期 8 段墙、3 个房间、净面积 **21.0152 m²**（界面显示 21.02）。无修复位移时，开关自动修复应保持厚度和面积一致；修复导出的 DXF 保留厚度图层后缀和编组元数据。
- 点中间折墙任一段，点「选择整组折墙」应选中 3 段；批量改为 140 mm 应只改这 3 段，面积减小。撤销／重做、刷新、完整项目备份恢复后厚度与编组应保留。Shift+点击可追加任意墙段，手工编组不改变墙的几何位置；每段坐标、长度、厚度仍可独立编辑。连续描墙在 Esc 结束前属于同一组。
- 描图中填充轮廓表示实际墙面，虚线表示中心线；厚度修改以中心线为基准向两侧展开。不同厚度的 L／T 交接按相接墙面收口，修改隔墙不会延伸已锁定承重／外墙的墙面。确认后，包含承重／外墙的批量改厚按钮应禁用，不能绕过原始基线保护。
- 窗辅助示例：仅选择 `FURNISH_EXTERIOR_200`，不要勾选 `FURNISH_WINDOW_GUIDE`／`FURNISH_BAY_GUIDE`。导入后应为 1 个房间、4 段墙、净面积 22.04 m²、尚无门窗。点「窗」输入 1200 mm，在 CAD 顶墙 X=1600 的中心位置补录普通窗（描图坐标 X=1800、Y=200 mm）；保存后可选中窗调窗台高度，3D 显示墙洞及窗玻璃。窗顶当前默认 2400 mm。
- 抬高飘窗辅助线宽 1600 mm、外凸 600 mm，仅表示参考，不自动生成外墙或增加房间面积；导入后使用「飘窗」工具补录实体。不要把抬高窗台画成落地房间外轮廓。实际可使用的落地外凸空间可按其正交外墙轮廓录入，会计入净面积。
- 新增 `node tests/test-centerline-walls.cjs` 共 12 项，覆盖混合墙厚、折墙分组、T 交接净面积、修复／下载／备份元数据、批量修改、锁定边界和窗辅助层排除。多墙厚双线转换仍明确拒绝，不自动猜厚度；本轮继续以中心线为基础。

实施顺序：P0-1 模板闭环 → P0-2 导入阶段引导 → P0-3 选中／属性与尺寸反馈 → P0-4 历史与保存反馈 → P1-5 检查定位 → P1-6 比较与备份预览。以下均已接入程序，可在 `http://localhost:8765` 刷新后测试。

1. **模板与上传**：点「导入 DXF / 描图 → DXF 模板与规范」。分别下载规范示例、空白模板；点「直接加载示例并检查」，核对毫米、3 类墙图层、修复前后 5 → 5 段、调整 0 mm、2 个房间、21.28 m²。示例 CAD 中心线 6000 × 4000 mm、隔墙 X=3000；200 mm 墙厚时，每间净尺寸 2800 × 3800 mm、10.64 m²。描图坐标有 200 mm 留边且 Y 轴向下，因此隔墙起点 X=3200、Y=4200。分类只是示例，须用户核实。
2. **空白模板**：在 CAD 打开应包含毫米设置和 FURNISH_BEARING／PARTITION／EXTERIOR／ANNOTATION 图层。尚未绘墙的空白模板上传应解释无墙线；绘制闭合中心线后重新上传。标注不识别为墙，CAD 门窗符号不自动导入，已有门窗需在完整墙线上补录。厚度导入统一设置，随后可逐墙修改。
3. **导入引导**：上传自己的文件，按文件检查 → 单位 → 图层分类 → 修复预览 → 导入核对提示操作。取消任何墙图层类型应禁用导入并解释错误；大缺口不能被凭空补齐，含曲线／三维的所选墙图层须拒绝。原始线灰色，修复线橙色，核对后才导入。
4. **属性与尺寸**：主画布点墙显示属性并高亮；家具、门、窗显示已有属性面板。自定义墙支持长度、位置、厚度、类型输入。未锁定示例把隔墙起点 X 从 3200 改为 3450，房间面积改变、合计仍为 21.28 m²，撤销／重做正确。描图「墙属性」现在在画布上方显示，不弹模态窗口；点端点圆点拖动时显示毫米长度，保持正交和端点吸附。改变连接后导致斜墙或破坏锁定结构的操作会拒绝；仍须核对闭合。
5. **确认与保存**：描图修改显示「本次编辑未保存」，主界面显示保存时间，刷新仍显示上次保存时间。保存未确认的原始结构应保持「未锁定」。点击确认时须核对房间数、净面积、墙数和门窗数；确认与保存是不同步骤。确认保存是历史边界，不可用撤销解锁原始结构。旧命名方案／快照载入时继续使用已确认基线；修改锁定墙的旧方案会被拒绝，需复制新户型重新核对。
6. **检查关联画布**：使家具挡住门或柜门正面空间，运行使用空间检查。点定位，应选中相关门／家具，并高亮家具、门摆动或正面区域；间隙提示标出扫描点，8 秒后消退。可「确认后忽略／恢复提示」；家具位置、尺寸、方向、结构或阈值变化后提示重新有效。阈值为设计偏好，检查不构成建筑合规或安全认证。
