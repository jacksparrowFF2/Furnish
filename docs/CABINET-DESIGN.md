# 柜体详细设计

## 柜边对齐墙边延长线（2026-10-27）

墙体吸附与对齐辅助线同时开启时，移动及宽深拉伸可沿远处墙边延长线对齐，沿边间隔上限6000 mm，屏幕捕获仍使用原10 px（特殊类型沿既有规则）。普通柜拉伸优先有限接触，其次墙边延长线；固定对侧锚点，显示跨间隔辅助线。厨房外边及边长拖动共用此墙边基准，家具参考仍要求有限邻近。关闭辅助线仅保留原有限贴墙候选。对齐不证明接触、可安装或实体无碰撞；曲线外轮廓仍保留有限支撑求解。无新保存字段，见[验收记录](validation/wall-extension-snapping-20261027/README.md)。

## 统一家具升级与实际实体（2026-10-21）

本节取代历史记录中“旧柜体继续保留缺失参数、另走旧生产构造器”的当前行为。按用户要求，furniture-upgrade.upgradeList / upgradeWork 是统一输入升级入口：当前方案、命名方案、仓库加载和旧缓存恢复都会升级；普通柜体补当前 cabinet，厨房模块／洗衣柜附属柜的内部配置同步规范化。新模板和库中添加使用同一标准结构；移除停用 autoDoors / entry.autoColumns，洞洞板旧 accessories 仅在升级时转换为七个明确开关，板厚统一为 18 mm，删除运行时旧 12 mm 回退。

旧 counter 组合保留原编号及名义宽深、坐标、旋转／镜像和总价，升级为标准地柜；原上排转换为单独 kitchenwall，挡水背板转换为 block，稳定生成编号，整体成组。新增部分继承组、物体图层、锁定和采购状态，总价只计在原主件，附属部分单价 0。已有手工 cabinet / kitchen 结构保留其参数，仅清理停用偏好；缺失结构按当前模型物化，内部净空须重新核对，不能承诺与旧简化模型逐板相同。小于标准厨房可表达范围的旧占位对象转为明确 block，保持保守占位，不推定空腔。

不另设保存／撤销通道，旧文件仍可导入，但只做一次转换；重复恢复不再增生部件或漂移。本地装修工作区已升级，之前的数据仍可从 Git 历史及本地升级前副本恢复。空间确认语义更新为 normalized-cabinet-structures-v2，受旧模型改变影响的核对需重做。

换鞋凳和樱桃木茶几使用同一生产构造器读取实体，沿共用 bodyParts / directional / volumeOverlap 计算；没有设备类型空腔豁免。柜体安装规则保持原严格阈值，普通网格家具不再冒充封闭柜体包络。[验收记录](validation/furniture-solids-upgrade-20261021/summary.json)。


## 精简对象编辑与直接开门（2026-10-20）

本节取代前面各批中“常驻全柜对象列表／点击只选择”和“同组按钮等宽、字段占满列”的界面描述。既有尺寸与模块规则保持。

- 顶部只保留一处对象标题及返回上级；“查找部件”默认折叠，先选隔间／模块或附属柜，再从该范围选择部件，选择后收起。没有隐藏的全柜兼容列表。输入未失焦时仍先提交到草稿，非法输入继续提示并保留可修正值。
- 普通层板默认只有高度、复制、删除；组内新增／均分、完整列表和分隔板选择收进高级设置。抽屉默认聚焦所选高度与开合，组列数／层数／样式和批量操作折叠。门宽／配对和外观精细控制继续可用，默认折叠；去除重复柜门开合和选中说明。

两个编辑器共用临时部件查找标题生成器，渲染器通过 `activateDoor` 回调复用原核心开合和草稿读入；保存仍只一次 mutate，内层及父级取消范围不变，无新持久字段、项目版本、几何／安装规则或独立保存通道。

具体通过、未执行范围和最终桌面／窄屏截图见 [简化验收](validation/cabinet-simple-20261020/summary.json)。这次没有运行全量检查或实体触屏验收；真实五金、自身干涉和加工精度仍沿用布局模型边界。


## 柜内设备与实际板件净距（2026-10-20）

柜内净水器及其他设备共用 `FurnishGeometry.bodyParts()`，柜体板件来自已有数值记录器 `FurnishCabinetMotion` 对生产 `cabinet-model.buildRaw()` 的记录，不重新编写柜壳／层板尺寸公式。`boards(f,{includeStatic:true})` 扩展静态板件与当前门抽屉姿态；原 `boards(f)`／运动切孔检查仍保持闭合基准及原输出。

`solidParts()` 返回世界平面、毫米高度和实际板件顶点，组合普通柜、餐边柜、玄关柜、厨房模块、转角、台面及附属柜；旋转、镜像、安装底高与完成地面基准沿原转换。厨房承托孔、相邻侧板开放及静板洗衣缺口复用已有生产参数。缓存最多 64 组，覆盖柜体配置、当前开合、位置、相邻柜体和台面设备开孔输入。

四向测距按每个设备自身高度截取板件，不用整柜外包框堵住空腔；上翻／下翻门先裁剪三维板件再投影，分层多选不互借其他成员高度。参照显示实际侧板／背板等；开放方向仍可量到更远家具或墙，不虚构一面内壁。浮动“四向净距”补充设备上、下方距离，负值表示相对板面已穿入，并列出相交板件。它们是模型几何距离，厂家的接口、散热、换芯等预留仍独立核对。

正常空腔中的设备不再产生整柜投影重叠；穿入侧板、层板、底板或门抽屉仍由共用实体检查提示。数值定位保持原板件参照并检查移动路径；项目确认增加 `cabinet-inner-solids-v1`，普通柜指纹读取有效默认结构并排除纯颜色／门板材质，采购／价格仍不参与。梁碰到多个板件合并为每件家具／每根梁一条结果。厨房自动避让继续避让其他柜体整体占位，避免自动嵌入另一柜的空腔。

无新增持久字段或格式版本，复制、替换、撤销重做、命名方案、项目往返与重复恢复继续走原链路；旧版 `counter` 整块占位和未详细设计的旧浴室柜不推定内腔，继续显示包络内边距。管孔／洞洞板微孔、斜边台面倒角与运动板件上的洗衣缺口仍按未切孔／完整板面保守处理；详细浴室柜上部盆镜组件也保留保守包络。这些边界不能用于确认微孔通行或施工安装合格。

验收见 [实际板件净距记录](validation/cabinet-interior-20261020/summary.json)。新测试核对 1,260 个生产板件与 960 条上／下翻门高度裁剪射线；相关增量回归、HTTP／离线 file://、数值定位、穿板、开门、2D／3D、保存刷新和窄屏均有记录。

## 参数来源与恢复默认（2026-10-20，第三批收尾）

柜体设计的三批计划至此收尾。对象参数中明确显示“沿用整柜／沿用隔间／默认值／单独设置”，编辑参数即形成原有可选字段覆盖；“单独设置”也可锁定与上级恰好相同的值。“恢复…”删除覆盖字段，后续仍跟随上级，不把当前默认值复制保存。

- 普通隔间与厨房模块铰链上限沿用整柜；展示门上限沿用隔间，再沿用整柜，保持既有 90° 缺省链。
- 门板颜色恢复整柜色；木色板恢复材质默认色。材质恢复素色板，把手恢复长条；已有模板显式指定的材质、无把手和配色保持到用户主动恢复。这里只复用现有默认规则，不新增整柜材质或把手字段。
- 外观与默认值折叠为高级项，同次草稿修改保持展开；层板工具只显示层板操作，抽屉组复制仍可从隔间／抽屉进入。提示说明实际选中对象与共享范围，保留逐扇配对、门宽、精确列表、顶盖及专用柜能力。

`cabinet-core.withDoorSetting()` 共用可选字段写入／删除与校验，两个表单共用来源／恢复控件；恢复、固定、修改均留在原设计草稿，保存一次 mutate，取消丢弃，无新版本、持久字段、默认迁移或保存通道。旧设计仍遵守第二批保存升级契约，必要的历史结构和安装默认保留。

增量验收与截图见 [第三批验收](validation/cabinet-setting-inheritance-20261020/summary.json)。未运行全量检查，未进行实体触屏设备验收；布局模型和五金干涉边界沿用原说明。


## 对象参数与旧设计升级（2026-10-20，第二批）

当前编辑器取消“整体尺寸／分区结构／门板与铰链／空间核对”的页面切换。单击柜体、隔间、层板、门板或抽屉显示其对应参数；对象列表可选择被遮挡的部件，整柜／当前隔间按钮用于返回父对象。普通柜体、厨房地柜与吊柜均使用该交互。门板／抽屉的生产尺寸标注也可点击或用键盘选择。单击预览只选择，开合由参数区或“全部打开／关闭”执行；主场景原开合不变。

层板提供当前板件位置数字输入，沿原约束与拖动接口应用；抽屉聚焦当前层，门板显示所属隔间的共用规格及既有逐扇细节。材质／门型、抽屉层高／分列等共用范围在参数区说明，不虚构逐板独立材质或加工能力。层板精确列表、整组抽屉高度列表折叠保留；配对、门宽、盖板方式、上下门／展示门、上盖抽屉、多列开合及空间核对仍可编辑。Enter 应用数字到草稿，不关闭设计器；保存仍是一次原 `mutate()`。

厨房普通模块的门板、抽屉、层板可直接定位；L／U 展开与镜像保留原模块索引。保留内部结构模块的板件和洗衣柜附属柜自动定位到同一个对象编辑器，内层保存只更新父草稿，父级取消仍完整撤回；模块外形／安装高度继续在父级设置。模块列表中的“隔间”提供模块本身宽度、功能等参数，不自动进入内层，专用内部入口保留。末端薄柜仍由整柜的对应末端参数编辑。

`cabinet-core.upgradeDesign()` 为统一的设计升级边界：无参数化结构的旧柜按已有核心默认和原尺寸物化；已有结构原样保留，历史玄关层板规则仍由共用核心解析。保存去除已停用的 `autoDoors/entry.autoColumns`，不再在 UI 中保留旧自动模式。可选结构默认值不无故展开，避免仅升级就改变既有采购规格；门型变化时保护原有效抽屉列数。重复升级、恢复、当前与命名方案往返无漂移。打开／选择／取消不改原记录，撤销可恢复升级前的数据。没有新字段、版本或独立迁移／保存通道。

删除旧页面状态、旧导航样式、厨房 `arrange()` 搬移 DOM 的分类路径及预览点击即开合的双重分支；生产预览统一 `selectPart()`。必要的旧默认值读取与烟机／浴室柜安装语义仍保留在核心／原专用路径，不能当作冗余删除。选择、标注和拾取元数据不持久化；生产几何、开启规则与缓存输入继续使用实际配置。

本批使用实际生产几何验证 19 个模板及旧无结构／旧玄关设计升级前后相同，并验证相关回归、HTTP、断网 `file://`、保存取消、撤销重做、刷新、项目往返和窄屏。范围、截图及未执行项见 [第二批增量验收](validation/cabinet-object-inspector-20261020/summary.json)。下面各节保留历史演进说明，以本节对象入口为准。

## 尺寸与显式设计操作（2026-10-20）

本节覆盖下文历史版本关于“改宽自动配门”“修改分区净宽即改总宽”“修改分区数立即重建”的行为说明。

- 改整柜宽度保留分区数量、门型、层板和抽屉；普通分区按净宽比例分配，餐边柜冰箱位净宽和烟机嵌合区净宽保持固定。不能容纳现有结构时拒绝，不自动删隔板。
- 分区数字净宽默认保持总宽，由右侧相邻分区补差；末分区由左侧补差。至少保留相邻分区 100 mm 净宽，超界输入明确报错。生产预览隔板拖动／键盘微调调用同一 `adjustColumnWidth()`，拖动到边界截停；数值可保留小数。单分区须显式勾选“随此分区调整总宽”。该选项只属于本次表单，不持久化；勾选后其他分区净宽不变。
- “整体尺寸 → 重新划分隔间”输入目标数量后点击“按数量均分隔间”才重分。总宽和冰箱位保持，储物格均分；原序号配置保留，新增复制末个储物格并关闭门／抽屉，减少移除末尾储物格。结果先留在生产预览草稿，取消可完整放弃，保存一次入历史。此操作不自动选择门型。
- “门板与铰链 → 为当前隔间配门”按当前净宽建议单门或对开，不增删隔板、层板、抽屉，不改净宽。显式重配会清除该格自定义逐扇配对和门宽比例，材质、把手、角度上限等保留；现有手动门型、翻门、逐扇设置仍可继续使用。单门／对开是普通隔间建议，并非厂家门宽要求。
- 烟机嵌合柜保留既有居中三分区及整柜联动门，禁用通用重分／配门按钮，继续使用专用嵌合尺寸和手动门设置。上盖抽屉不能同时配柜门；原玄关柜、餐边柜、厨房模块和洗衣柜能力保留。

编辑器与通用家具缩放共用 `scaleStructure()` 派生内部高度和宽度，调整板厚／底座时也保持门板与分界层板的附着。实际内部高度变化时才按既有规则取整，未改尺寸不对旧小数结构取整。表单直接生成整体、门板、分区及其结构子组，删除 `organizeForm()` 按控件选择器搬移 DOM 的分类机制。

没有新持久字段、项目版本或恢复迁移；旧 `autoDoors/entry.autoColumns` 继续校验、保留，普通尺寸编辑不再依据这些偏好重排。模板初始生成及已有 `autoDoors()` 组合接口继续兼容。旧数据恢复不触发新的设计操作；`setColumnWidth()` 保留为明确调整总宽的底层接口。

验收范围、截图及未执行项见 [本批增量验收](validation/cabinet-edit-operations-20261020/summary.json)。

## 抽屉面板宽高（2026-10-18）

进入详细设计的「整体尺寸」页同时显示全部柜门与抽屉面板的宽高，底部统一为「全部门板／抽屉面板尺寸」清单。门板编辑页的图中标注聚焦当前分区，清单保留全部面板；尺寸开关同时控制两者。抽屉注明自下而上的层序与面对正面的左右列序，上盖联动抽屉单独命名，保留结构与整体洗衣柜附属柜沿用各自的模块／分区名称。

抽屉尺寸由生产构造器在管线开孔前读取实际外面板网格的宽高，包含面板门缝与盖板方式的影响，不用抽屉层高代替面板高。覆盖普通、并列多抽、玄关柜、分层餐边柜、厨房／吊柜保留结构和上盖联动抽屉；碗碟篮仅有两块外面板，隐藏内抽的篮架前沿不虚构第三块面板。只读 `cabinetDrawerSize` 元数据不进入持久数据，无新增项目字段、保存、撤销或空间核对通道。固定封板、内部抽盒板、水平上盖及独立设备门不在此清单；布局模型尺寸不等同于加工单。

## 进入设计即显示门板尺寸（2026-10-18）

## 选中层板的净高编辑（2026-10-28）

普通柜体详细设计选中层板后，右侧主面板只保留当前层板的「上方净高」「下方净高」、可调范围、复制和删除；原定位高度折叠至「定位高度与基准」，整组层板设置仍在所属隔间。对象标题与返回上级保留，整柜尺寸及门板组参数不混入层板面板。

净高单位 mm。`cabinet-core.shelfClearances()` 复用 `spaces()` 派生紧邻层板的上下空间，量到相邻板件表面：下方净高 = 当前板下表面 − 下方边界；上方净高 = 上方边界 − 当前板上表面。包含板厚、底部抽屉／烟机嵌合区以及玄关／餐边柜的上下储物分层，不跨开放操作区量距。范围沿用 `shelfLimits()`，并收紧联动上柜门底／洞洞板开放区的既有有效范围。

`editShelfClearance()` 先严格校验数值及范围，再修改原 `columns[].shelves[]`；上柜门底已附着该层板时继续同步。允许小数 mm，不改总高、其他层板或固定分层。没有新增持久字段、默认值、版本或加载路径；保存仍是原草稿的一次 mutate，取消不写入方案，现有 cabinet 缓存和空间确认读取完整结构。
