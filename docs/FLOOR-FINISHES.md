# 地砖铺贴与地面标高（第一阶段，2026-10-16）

输入、持久化及计算使用 mm；三维边界换算为 m。1601 的现有层高、窗台和设备安装高度由用户确认为毛坯地面基准，不随地面设置更改。其它旧项目不自动迁移基准或推测层厚。

## 数据与算法

可选 `work.floorFinishes = {version:1, areas:{[roomId]:settings}}` 独立于材质、预算及采购订单。绑定功能区 ID，支持同一物理空间内不同铺贴设置。没有该字段时保留原显示和高度。仅用户启用新卫生间设置时预填 `mode:reference, drop:5`；参考区域需选择，未知层厚留空。

- `rawZ`：毛坯地面绝对标高，默认录入值 0，可改；不以卫生间高差反推沉箱或毛坯高差。
- `tileThickness`：面层厚度；非瓷砖材料同样可使用地面标高。
- `baseThickness`：粘结＋找平层的合计厚度，避免重复计入。
- `mode:layers`：完成标高 = 毛坯标高＋面层＋粘结找平层。
- `mode:level, targetZ`：目标完成标高减去毛坯和面层，推算找平层。
- `mode:reference, reference, drop`：完成标高 = 参考区域完成标高−降低量。卫生间默认降低 5 mm，可改为 0 或其它数值；参考不存在、循环、未知或推算为负时保留输入并待核对。

目标／参考模式中已填找平层与推算结果冲突时不覆盖实测输入，完成标高待核对；留空才采用推算厚度。毛坯／目标标高范围 ±20000 mm，厚度及降低量 0–1000 mm，是输入防错范围而非施工推荐值。

可选 `layout:{width,height,gap,angle,origin:[x,y]}` 定义实际砖面尺寸、右／下侧砖缝、原图方向及参考整砖左上角。节距为砖面尺寸加缝。砖尺寸 20–6000 mm，缝 0–50 mm，方向 ±360°，起铺点允许在区域外。修改砖尺寸不改变起铺点；视图旋转不改变排版。UI 支持数值录入、0／90°、图上取点及完成面角点吸附、显式复制其它区域的起铺点与方向。复制后独立保存，不建立隐含联动。

二维 SVG 模式和三维 UV 共用该网格；边界取墙面完成面裁切后的区域，凹形和孔洞保持。三维地面和层厚由生产构造器生成，砖缝为平面纹理，未逐砖挖槽。DXF 输出 `FLOOR_TILES` 裁切砖面和标高；每区域候选砖数超过 20000 时明确拒绝该导出，避免假装完成切砖计算。预算沿用原面积估算；铺贴尺寸与已录入采购规格不同会提示，不改采购数量或订单。

## 高度与检查

原家具、柜体、关联台面、叠放设备及绝对安装高度保持；地面编辑通过原 `mutate()`、撤销、自动保存，不触发厨房自动避让或叠放重新归位。层厚修改不会自动抬高家具，也不把地面厚度重复加到宿主与关联设备。

属性及三维选中标注区分毛坯绝对标高与距完成地面的净高；区域显示完成地面至天花净高。空间规则检查家具底部穿入地面、跨标高支承、未知标高、完成地面超过天花，以及真实柜门／抽屉开启范围与地面的相交。毛坯墙和天花绝对位置保留。漫游眼高随已知完成地面变化，地面拾取优先使用实际生产面；外部背景面降至最低地面以下。

门底与门槛的实测绝对标高尚无持久字段，相关门口列为待核对，不将现有示意门扇的 0 标高当作实测门底。未处理坡度、地漏、门槛构造、交错／人字铺、切砖损耗优化及自动贴地操作。家具支承采用占地覆盖的保守核对，不推断每个支脚位置。

## 兼容与失效

- 原项目及命名方案未配置时不补厚度、不降低旧卫生间；新字段验证后原样恢复，重复恢复不累计偏移。
- 项目／工作区外层含任一地面设置写版本 3；读取 1／2／3，旧版程序拒绝新文件。内部有地面设置的缓存升为 v3 并写独立 `huxing-design-v3`，旧 v2 缓存保留；新程序优先读 v3，无 v3 才从 v2 读入。
- IndexedDB 启动、仓库仲裁、恢复副本与本机清除均支持 v3；仓库原子保存仍走原接口。短分享链接对地面设置引导使用完整项目 JSON。
- 复制户型、命名方案、导出导入、历史、撤销重做沿用原链路；纯地面编辑跳过家具归一化。内置户型转自定义时只平移网格起点，绝对砖尺寸、层厚和标高不缩放。XY 标定不缩放这些绝对 mm 值。
- 区域 ID 消失后保留失效设置并报待核对，可移除后在新区域录入，避免跨区域猜测继承。参考区域失效同样待核对；未实现自动拆分／合并地面设置。
- 空间确认只包含实际读取的区域标高、未知状态和房间几何；纯砖尺寸／缝／方向／起点以及采购配色不会清除空间确认。二维和建筑三维缓存包含地面设置。

## 验证

核心回归见 `tests/test-floor-finishes.cjs`，浏览器专项为 `floor-finishes`，同时运行 HTTP 与离线 `file://`，覆盖界面、撤销、刷新、命名／项目往返、三维及 390 px。完整验收结果记录在项目维护日志。1601 演示为独立 ID 和只读服务域，省略仓库保存适配器；假设其它区域 10＋40=50 mm、卫生间目标 45 mm，原文件和既有未提交测试文件用 SHA-256 比对。
