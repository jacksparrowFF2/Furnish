# 地砖铺贴与地面标高（第一阶段，2026-10-16）

输入、持久化及计算使用 mm；三维边界换算为 m。1601 的现有层高、窗台和设备安装高度由用户确认为毛坯地面基准，不随地面设置更改。其它旧项目不自动迁移基准或推测层厚。

## 数据与算法

可选 `work.floorFinishes = {version:1, areas:{[roomId]:settings}}` 独立于材质、预算及采购订单。绑定功能区 ID，支持同一物理空间内不同铺贴设置。没有该字段时保留原显示和高度。仅用户启用新卫生间设置时预填 `mode:reference, drop:5`；参考区域需选择，未知层厚留空。

- `rawZ`：毛坯地面绝对标高，默认录入值 0，可改；不以卫生间高差反推沉箱或毛坯高差。
- `tileThickness`：面层厚度；非瓷砖材料同样可使用地面标高。
- `baseThickness`：粘结＋找平层的合计厚度，避免重复计入。
- `mode:layers`：完成标高 = 毛坯标高＋面层＋粘结找平层。
- `mode:level, targetZ`：目标完成标高减去毛坯和面层，推算找平层。
- `mode:reference, reference, drop`：完成标高 = 参考区域完成标高−降低量。卫生间默认降低 5 mm，可改为 0 或其它数值；参考不存在、循环、未知或推算为负时保留输入并待核对。

目标／参考模式中已填找平层与推算结果冲突时不覆盖实测输入，完成标高待核对；留空才采用推算厚度。毛坯／目标标高范围 ±20000 mm，厚度及降低量 0–1000 mm，是输入防错范围而非施工推荐值。

可选 `layout:{width,height,gap,angle,origin:[x,y]}` 定义实际砖面尺寸、右／下侧砖缝、原图方向及参考整砖左上角。节距为砖面尺寸加缝。砖尺寸 20–6000 mm，缝 0–50 mm，方向 ±360°，起铺点允许在区域外。修改砖尺寸不改变起铺点；视图旋转不改变排版。UI 支持数值录入、0／90°、图上取点及完成面角点吸附、显式复制其它区域的起铺点与方向。复制后独立保存，不建立隐含联动。

二维 SVG 模式和三维 UV 共用该网格；边界取墙面完成面裁切后的区域，凹形和孔洞保持。三维地面和层厚由生产构造器生成，砖缝为平面纹理，未逐砖挖槽。DXF 输出 `FLOOR_TILES` 裁切砖面和标高；每区域候选砖数超过 20000 时明确拒绝该导出，避免假装完成切砖计算。预算沿用原面积估算；铺贴尺寸与已录入采购规格不同会提示，不改采购数量或订单。

## 高度与检查

原家具、柜体、关联台面、叠放设备及绝对安装高度保持；地面编辑通过原 `mutate()`、撤销、自动保存，不触发厨房自动避让或叠放重新归位。层厚修改不会自动抬高家具，也不把地面厚度重复加到宿主与关联设备。

属性及三维选中标注区分毛坯绝对标高与距完成地面的净高；区域显示完成地面至天花净高。空间规则检查家具底部穿入地面、跨标高支承、未知标高、完成地面超过天花，以及真实柜门／抽屉开启范围与地面的相交。毛坯墙和天花绝对位置保留。漫游眼高随已知完成地面变化，地面拾取优先使用实际生产面；外部背景面降至最低地面以下。

门底与门槛的实测绝对标高尚无持久字段，相关门口列为待核对，不将现有示意门扇的 0 标高当作实测门底。未处理坡度、地漏、门槛构造、交错／人字铺、切砖损耗优化及自动贴地操作。家具支承采用占地覆盖的保守核对，不推断每个支脚位置。

## 兼容与失效

- 原项目及命名方案未配置时不补厚度、不降低旧卫生间；新字段验证后原样恢复，重复恢复不累计偏移。
- 项目／工作区外层含任一地面设置写版本 3；读取 1／2／3，旧版程序拒绝新文件。内部有地面设置的缓存升为 v3 并写独立 `huxing-design-v3`，旧 v2 缓存保留；新程序优先读 v3，无 v3 才从 v2 读入。
- IndexedDB 启动、仓库仲裁、恢复副本与本机清除均支持 v3；仓库原子保存仍走原接口。短分享链接对地面设置引导使用完整项目 JSON。
- 复制户型、命名方案、导出导入、历史、撤销重做沿用原链路；纯地面编辑跳过家具归一化。内置户型转自定义时只平移网格起点，绝对砖尺寸、层厚和标高不缩放。XY 标定不缩放这些绝对 mm 值。
- 区域 ID 消失后保留失效设置并报待核对，可移除后在新区域录入，避免跨区域猜测继承。参考区域失效同样待核对；未实现自动拆分／合并地面设置。
- 空间确认只包含实际读取的区域标高、未知状态和房间几何；纯砖尺寸／缝／方向／起点以及采购配色不会清除空间确认。二维和建筑三维缓存包含地面设置。

## 浮动编辑与区域列表（2026-10-16）

选中区域后的浮动栏提供「地砖铺贴」及「区域列表」。画布底部「地砖」也可打开全区域列表，无需先选择房间。浮动编辑分为「铺贴参数」「地面标高」，与属性栏复用同一表单生成器和应用逻辑；两处使用独立控件 ID，不建立另一套保存通道。仅显示当前标高模式需要的字段；图上取起铺点时保留浮动表单，Esc 先取消取点。窄屏复用既有浮条停靠与画布保留区，表单可滚动。

列表展示所有计入面积的功能区，飘窗台不纳入批量操作。勾选即时启用，支持全部启用／全部关闭，每个批量操作作为一次 mutate，可撤销重做。新启用区域使用既有默认值，层厚保持未知；卫生间降低量仍为 5 mm，参考区域须明确选择。非瓷砖区域只启用地面标高，不改材料。

可选 `settings.enabled:false` 表示关闭并保留参数；缺失或 true 沿用既有启用语义。恢复、复制、命名方案和项目文件均保留此字段；关闭项不参与网格、标高和空间计算。若被其它区域引用，引用方待核对，不沿用已关闭区域的旧标高。重新启用恢复原参数；旧项目未主动勾选时不生成设置。较早的严格校验版本会拒绝不认识的 enabled 字段，不会将关闭项当作已启用后保存。

### 图上起铺点吸附

进入「图上选起铺点」后，鼠标移动实时显示十字标记。距区域完成面角点 12 屏幕像素内显示绿色吸附标记，否则为橙色自由选点；表单同步显示坐标和状态。候选角点取墙面完成面派生后的区域边界，含孔洞，不随视图旋转改变原图坐标。只吸附角点，尚不吸附墙边任意点或其它区域的砖缝。

点击仅更新表单草稿，标记保留并注明「待应用」，仍须点击「应用地面设置」保存；Esc 取消当前取点并保留此前草稿，关闭表单清除标记。预览不进入项目、历史或成果导出。核心 `snapOrigin()` 始终按原鼠标位置比较最近角点，避免相邻候选点连锁吸附；阈值随实际屏幕变换换算，缩放后保持 12 像素。

### 全区域统一起铺点

「地砖 → 区域地砖铺贴 → 统一起铺点」打开全屋浮动表单，可输入原图 X／Y 或用同一个角点吸附取点器。应用到所有计入面积、当前材质为瓷砖的区域，含关闭区域；非瓷砖区域及飘窗台不处理。默认只改起点，「同时统一铺贴方向」勾选后才批量改角度。各区域砖长宽、砖缝、层厚、毛坯／完成标高、参考高差及启用状态保持；未设置地面的旧区域创建保留未知层厚的关闭记录，后续显式启用时沿用预设起点。

核心 `setLayoutBasis()` 返回工作副本，完整校验后由一次 mutate 保存，整个批量操作一次撤销／重做。没有新增全局持久字段或跨区域关联，只写原 `areas[id].layout.origin` 及可选 angle；之后各区域可独立修改，需再次统一时重新应用。复制、命名方案、项目往返和自动保存沿用原结构，重复恢复不漂移；二维、三维及 DXF 读取各自原有 layout，空间核对输入不因纯起点／方向变化而失效。

起点为整个原图共用坐标，可位于某一区域外；不同区域若砖尺寸、砖缝或方向不同，共用起点也不能保证所有砖缝连续对齐。此功能不修改材料规格、家具或柜体，也不自动开启已关闭区域。


## 标高输入预览与保存反馈（2026-10-17）

原表单仅显示上次保存的派生结果，应用即使仍待确定也使用统一成功提示。现在输入／切换模式会用同一核心对草稿计算，显示预览标高、所需找平层和具体待定原因；预览不进入历史或自动保存。参考区域选项显示已知完成标高、待确定或未启用状态。未选参考、区域移除／关闭、参考标高未知、参考循环和缺失降低量分别提示；已填找平层冲突仍保留输入，用户可核对后自行清空以启用推算。

应用沿原 mutate 保存，允许保存未知厚度和待定关系；反馈明确区分「参数已保存，完成标高仍待确定」「地面设置已应用，完成标高…」及关闭状态。没有新增持久字段、默认厚度或自动抬高家具行为。


## 批量设置地面标高（2026-10-18）

区域列表「批量设置地面标高」覆盖全部计入面积区域，包括非瓷砖区域；默认全选，可取消或只选部分。统一填写 rawZ／tileThickness／baseThickness，另可勾选卫生间独立粘结找平层（按用途识别，不按名称猜测）。输入共用原有 mm 范围，三项必须明确，0 为有效值；未填写时不把未知厚度当作 0。逐区域草稿预览不保存。

共用核心 `setLayers()` 克隆并原子校验，应用时启用所选区域、使用 layers 模式，清理这些区域原 targetZ／reference／drop，保留 layout 和其它地面记录。UI 一次 mutate，可整批撤销／重做；关闭或返回不保存。非选定区域、失效记录、砖尺寸／缝／方向／起点、家具／建筑及墙砖自定义设置均不改写。无新持久字段和版本；项目／命名方案／复制／恢复沿原记录。

例：毛坯0、面层10、普通粘结找平50、卫生间45，分别完成60／55 mm；墙砖默认从各自完成面起铺。已有绝对起铺设置保留，用户可在墙砖批量入口明确改为完成面以上0。输入值按实际项目填写，不将此示例写为全局默认。核心回归 `tests/test-floor-bulk-levels.cjs`，浏览器专项 `floor-bulk-levels`。


## 门洞补铺、可读砖缝与真实高差（2026-10-18）

旧3D门洞仍绘制毛坯0位置的无纹理示意板，房间地面只到区域边界；2D也用统一底色门槛覆盖网格。现在共用核心从实际 door／slide 矩形和两侧真实区域派生 `floorFinish.doorways`：内部洞口按墙中心线分给两侧，各自沿用网格及完成标高；仅一侧为室内时沿用该室内区域覆盖洞口。扣除已有地面覆盖，不增计区域面积、材料预算或持久字段；不是门槛构造或厂家安装要求。关闭／未知一侧不猜层厚，不把未知标高推成已确认值。

2D、3D、DXF、地面落点／漫游眼高和空间开启／支承核对读取同一派生；上下文签名覆盖实际洞口分区及标高，纯砖尺寸／颜色仍不触发空间确认。生产 `surface()` 构造纹理顶面，`layers()` 保留真实板层侧面与底面并去除未贴图共面顶盖，避免遮住铺贴网格。纹理材质加深砖缝并使用屏幕导数对亚像素缝做适量覆盖增强，轻微区分砖面明暗；保存的2 mm缝宽、实际节距和5 mm高差保持，0缝不绘制假缝。纹理与层体材质随生产建筑重建释放。

两侧已知且不同高时，在洞口中线派生实际高差面及一条合并的标注（60／55显示高差5 mm），不放大高度。顶面、真实层体、台阶与纹理同属生产构造器，三维标注只为识读，不代表现场门槛实测。凹形／孔洞地面使用同一生产构造器验证三角网格，不以源码字符串代替覆盖测试。

回归 `tests/test-tiling-render-alignment.cjs` 以真实Three射线验证门洞两侧60／55表面、5 mm高差实体、窗不补铺、旧项目／未知／推拉门，以及项目恢复。浏览器专项 `tiling-render-alignment` 验证HTTP和断网file://、材质编译、2D补铺、3D高差标注、墙地对缝、保存与390px；实际1601另行目视检查。


## 卫生间3D动态起铺点（2026-10-18）

卫生间区域列表提供「3D动态调整」，原单区域表单也提供「3D动态调整起铺点」。需已启用地砖且完成标高已知，2D入口自动进入主三维场景；编辑器打开后以可用画面俯视本区域，桌面避开右侧面板，窄屏优先露出上方地面。可重新按「俯视选点」，结束选点后拖动旋转观察。

输入原图X／Y（±1000000 mm）、点击可见地面、X／Y各±50 mm微调或按「重新生成预览」，均立即重算本区域地砖、所属门洞半边及已有followFloor墙砖的UV。橙色圆环表示参考砖角；可恢复已保存起点。射线只接受本区域可见地面，墙体、家具和其它区域不作为落点，靠近本区域完成面角点可吸附。选点模式下Esc结束取点并保留草稿，再按Esc关闭取消。入口只调整起点，不启用关闭地面、不改砖规格、缝宽、方向、层厚或其它区域；墙砖不具备关联时继续保持手动排版。

`floor-origin-preview.js`在生产表面上原位更新UV属性，记录第一次预览前的数组；复用`floor-finish-model.uv()`与`wall-tiling-model.uv()`，不另建简化铺贴或每次重建全屋。取消、关闭、切视图、切户型或建筑重建前恢复原UV并释放临时圆环。输入无效时恢复保存图案，不显示上一份有效草稿冒充新输入结果。临时预览不写state、缓存、项目或历史；三维图片导出须先应用或取消，报告截图不包含未保存草稿。

「应用起铺点」共用`setLayoutBasis()`，先清预览，再沿原mutate保存一面区域的origin，可一次撤销重做、刷新和项目往返；没有新增持久字段、外层版本或保存通道。原二维取点保持。墙地砖节距不同时仍只对齐起铺缝；没有坡度、地漏、施工切砖及余料优化。鼠标／触屏使用同一pointer入口，实机触屏另行验收。

核心生产回归为`tests/test-floor-origin-preview.cjs`；浏览器`floor-origin-3d`覆盖HTTP／断网file://、数字与真实鼠标选点、遮挡拒绝、恢复／无效值／取消、草稿隔离、一次撤销重做、刷新及390px。

### 三维圆环连续拖动（2026-10-18）

进入动态调整后，可直接按住橙色圆环拖动，按动画帧合并指针事件，实时更新本区域地面、门洞半边和followFloor墙砖的生产UV；不重建全屋或GPU属性。拖动从当前草稿累计位移，不把保存基准跳到鼠标处。原起点在房间外时，圆环优先显示房间内最近中心的等价网格砖角（含旋转）；无网格砖角的极小区域使用内部平移手柄。该临时位置不保存，砖规格保持800宽×400高等既有配置。

圆环约36px，随相机距离调整大小。父级捕获监听先于OrbitControls，拖动时冻结飞行、旋转和缩放，松手恢复原相机控制；持续落点按本区域完成地面所在平面计算，允许经过家具遮挡。拖出区域保持最后有效位置，松手补齐最后一帧并保留草稿。Esc、pointercancel、捕获丢失或窗口失焦撤回本次手势到拖动前草稿，仍可继续编辑；关闭编辑器清理捕获与监听并恢复保存排版。非主指针不接管当前手势。应用仍为一次mutate，撤销、重做、刷新及其它区域隔离沿原链路。

### 拖动角点吸附与闭合边界（2026-10-18）

修复圆环拖动只检查严格内部、没有调用角点吸附的问题：恰落在右／下边界或浮点射线略越界时，旧版会拒绝该帧，表现为无法贴到墙地角。`floor-origin-preview.contains()`现将外轮廓及孔洞边缘视为合法边界，孔洞内部仍不可落点。拖动先以完成地面投影后的屏幕距离寻找12px内最近的本区域完成面角点，再判断范围；允许从角点外侧的吸附半径内接近，远离区域仍保留最后有效位置。不同缩放及斜视共用像素半径，不把它替换为固定毫米值。

## 家具以完成地面为高度基准（2026-10-18）

本节替代上文“家具保持毛坯高度”的默认新建行为。用户明确要求全部家具以完成地面为基准；当前1601工作槽已设为完成地面，其50件家具的原始尺寸、安装高度、关联和XY均保留。普通区域派生抬高60 mm，卫生间55 mm，来源是当前项目已保存的10＋50／10＋45层厚；不是全局默认施工厚度。历史命名方案不批改，旧文件未设置基准时仍保留原毛坯行为。

可选 `work.furnitureDatum:'finished-floor'|'survey'` 是整个工作方案的家具输入高度基准。新建明确为finished-floor，旧缺失不补写；导入与实际恢复均校验。地砖区域列表可切换，沿mutate一次撤销／重做、自动保存、复制户型、命名方案及项目往返；切换不触发厨房／叠放归一化，也不把偏移写进mountHeight、counterElevation、混水器高度或柜体尺寸。产品核心 `floorBase(plan,f,furniture)` 集中解析，优先关联台面／洗衣柜宿主，位置跨区取中心所在区域，中心在完成面外时按实际占地交叠选择；飘窗区域通过共边邻接的计入面积区域取基准，实测飘窗台与窗台仍保持绝对位置。未知地面返回待核对，三维暂以0偏移展示，不宣称已落地。

生产场景只对家具根组叠加一次偏移，缓存位姿更新重设后再叠加；预览继续以相对地面坐标构造。实体包络、梁／吊顶、家具重叠、柜门抽屉高度区间及上翻扫掠、竖管切孔和运动核对、洗碗机和热水器预留同步使用世界高度。固定插座、建筑门窗、梁底顶与天花仍用毛坯绝对标高，家具变高可能产生需要重新核对的顶部冲突。属性区分距完成面高度与绝对标高。空间确认包含基准，纯砖缝、配色与采购不新增失效。

含finished-floor的项目与工作区使用外层版本10及独立huxing-design-v10缓存，旧1–9可读，旧缓存保留；首次无v10时保留v9时代对旧分支最新时间仲裁。仓库保存、恢复副本、IndexedDB与清除入口支持v10。回归 `test-furniture-finished-datum.cjs` 覆盖旧数据、未知、关联、旋转镜像、梁接触阈值、项目重复恢复及实体层厚；浏览器专项 `furniture-finished-datum` 覆盖真实生产根组、缓存位姿、撤销刷新、下载上传和390px。

支承仍是占地保守核对；未模拟每个支脚、斜坡和家具自动适应不同地面。飘窗垫等历史模型的原包络没有随本次基准变更重新建模。
