# 洗衣区与餐边柜模块设计

2026-11-08。两类组合的“详细设计”、双击及厨房编辑入口进入新的三栏模块界面，保留原专用生产配方、水槽、连续台面与设备关联。取消不改原组合；父草稿统一保存为一次应用历史。旧柜不会因打开编辑器被转换为组件柜。

## 模块与对齐

- 餐边柜保留下柜／连续台面、展示柜／上柜、冰箱位／顶柜这些共享结构，分别编辑总深及前后位置。原横向隔间仍属于共享柜箱，不能把门缝当成独立柜箱；隔间门型、层板及原浅抽屉可在右侧编辑。共享柜体的原板厚语义保持。
- 洗衣区地柜有独立总深和对齐位置，连续台面另保留自己的总深；地柜必须留在该连续台面的深度范围内。模块用途可改为门柜、开放柜、水槽柜或设备空位，设备空位可继续增加。改变原水槽模块用途时关闭原内嵌水槽；水槽开关可在组合设置恢复。
- 原吊柜、开放柜、水槽保留已有结构与位置，可关闭／恢复。新增独立柜箱及开放柜箱使用正式组件柜，在内层搭建器编辑板厚、背厚、层板、隔板、门抽、内部净空、连接及复用组件。每个新柜箱有自己的宽深高、底部相对整组底标高、左右／前后位置；柜箱也可移到主柜侧面，放在异形台面延伸段下方。
- 前面板外沿、背板外沿、柜体中心和自定义位置均可作为前后基准，正偏移朝局部正面。普通组件柜的箱间连接也提供这些选择；尺寸、生产板件、完整开启、测距及组合外包读取同一连接布局。这里的“背板对齐”指背板外沿／箱体后沿，背厚为0时仍有明确的箱体后沿基准。

新增独立柜箱先加入父草稿，内层“保存柜体搭建”返回父界面，最后“保存组合设计”才应用。内层组件库资源也暂存到父草稿，取消父草稿不写入。父草稿保持嵌套编辑前的撤销历史，并继续校验最初组合及关联锁定设备，拒绝覆盖期间的并发修改。原有设备关联沿 `Kitchen.normalize` 更新，不因更改整组宽度在下一次刷新时再次漂移。新增第二个设备空位不自动采购或放入另一台洗烘设备；设备本身继续从家具库放置／对齐。

## 石英石连续异形台面

选择左侧“石英石台面 · 异形轮廓”。可以向左／右扩展一段，输入延伸宽、该段总深及后沿偏移，生成与原台面连成一体的直角台阶或 L 形轮廓。随后可在平面图拖动顶点（10mm网格），或选顶点输入精确 X／Y；相邻直角边一起调整，避免产生开口。可多次延伸、撤销／重做，也可恢复随柜默认台面。

`kitchen.laundry.worktop.outline` 保存相对主柜中心的局部 mm 顶点，Y正向柜体前方，随整组旋转／镜像。原主柜 `w/d` 仍为柜体／主台面布局基准；新增轮廓及侧柜可超出此基准，界面另外显示组合实际外包。已有顶点在主柜尺寸变化时保留局部坐标；需要随新柜体重新生成时用“恢复随柜默认台面”。统一厚度继续读取 `kitchen.thickness`，台面顶=台面底部标高+厚度。

轮廓是一个无孔、无自交的直角多边形，最多32点，单坐标绝对值及平面跨距最多6000mm。原管道缺角、设备孔、水槽孔和障碍切口在生产阶段继续从该轮廓扣除，不将水槽孔直接写入顶点数组。连续延伸拒绝脱离原台面的孤岛。`Kitchen.topGeometry/slabGeometry` 同时供二维、生产石英石网格、GLB、实体碰撞及安装表面使用；外包检查含超出主柜的轮廓与侧柜，不把 L 形缺口填成实体。

这是布局／实体能力。照片只用作组合能力参考，没有据透视估算写入厂家尺寸；石材接缝、圆角／倒角、悬挑支撑、承重、开裂风险及加工安装要求尚未建模。

## 数据与兼容

共用 `product-rules.cabinetBuilder.placement/worktop` 定义选择和范围。新持久输入如下：

| 数据 | 缺失／新建 | 语义 |
|---|---|---|
| `boxes[].attach.align/offset` | 旧缺失仍背沿对齐、偏移0；旧数据不补写 | 相对父箱的前后基准与mm偏移；复用重分配身份时保留 |
| `cabinet.sideboard.placements.{lower,upper,fridge}` | 缺失保留旧背沿 | 各原共享模块的 `{align,offset}`；总深按实际外包派生；首次编辑旧缺失冰箱深度时固定原有效深度 |
| `kitchen.modules[].cabinetPlacement` | 缺失保留旧整深 | 洗衣区实体地柜的 `{depth,align,offset}`；不改变连续台面 |
| `laundry.assembly.cabinetN` | 新增时生成独立组件结构 | 稳定模块键；原分区字段加v2 `cabinet`、独立宽深高、x/y及底标高；最多24个分区（含原有及关闭的分区） |
| `laundry.assembly.*.name` | 缺失使用派生模块名 | 内层柜箱命名；不改变身份与空间确认 |
| `laundry.worktop.outline` | 缺失沿旧台面；恢复默认删除字段 | 上述局部直角多边形 |

显式新字段最低项目／工作区v79，读取v1–v78旧项目、仓库与旧缓存；缓存入口v79仍保留所有历史候选。当前、命名方案、复制、组件复用、仓库保存与项目往返均使用原路径。结构与位置进入原完整配置缓存／核对上下文；模块名称按非空间字段剔除，价格与配色维持原语义。`cabinet-assembly-core.js` 是浏览器／Node共享规则，`cabinet-assembly-editor.js` 只管理草稿，两个经典脚本随既有离线发布目录加载。
