# 厨房地脚、可拆踢脚、通风挡板与内抽

2026-11-12。适用于 v2 标准组件柜及厨房中保存该结构的独立柜箱。参数化柜体继续由生产构造器生成，不新增保存通道或 Blender 家具资产。现有异形 `profile` 部件暂不支持本轮通风孔、内抽和拆卸状态；编辑器不显示这些选项，导入也明确拒绝，不能标成已支持。

## 编辑与持久契约

规则集中于 `FurnishProducts.cabinetService`；所有数值都是布局建模初值／范围，不是已选厂家五金或燃气安装要求。

| 组件 | 新字段及语义 | 缺失时 |
|---|---|---|
| `plinth` | `support:'solid'/'legs'`；`legs` 生成四只地脚、前脚塑料卡扣与独立薄踢脚板；`feet:false` 只保留可拆前板；`removed:true` 拆前板与随板卡扣，保留地脚 | 沿用原实心底座；旧数据不补写 |
| 标准 `board` | `removable` 表示拆卸能力；`removed` 让板件真实消失；`vent={columns,rows,slotWidth,slotHeight,gapX,gapY}` 在板件局部宽×高平面贯通厚度开矩形孔 | 原板件、原身份与原位置 |
| 标准单列 `drawerModule` | `removed` 取下整个抽屉；`innerTray={height,topInset,open,extension}` 在分区顶部增设独立薄托盘，保留原外抽面 | 原抽盒和外抽面 |

内抽限单列且不含 `states` 的标准独立抽屉；`boxTopInset >= 内抽高 + 上退 + 12mm`，避免内抽与外抽盒相交。内抽有自己的运动节点，实际伸出量不超过已打开的外抽面；点击内抽走原 `section:'innerTray'`、`motion` 与 `mutate`。编辑器打开内抽时同步打开外抽；关外抽会约束内抽实际位置，配置仍保留。全部开／关、规格归零与组件复用也处理内抽状态。

地脚的底盘、顶盘保持尺寸，改变高度只改变中间杆段；高度初值沿所选踢脚。新地脚模式下，无底柜侧／背板从地脚顶部开始，旧无底柜仍保留原落地侧板语义。`feet:false` 不证明悬空柜箱承重成立，须另设计与相邻柜箱的连接。

通风孔按实体板条分解，显示、数值板件、碰撞和 GLB 读取同一组孔间实体，孔中心不会被完整包络填死。最多240孔，行列为正整数，孔及间距正值，孔阵列须在板内保留边界。当前仅矩形孔；不模拟气流、孔内倒角、螺钉孔和真实卡扣弹性。可拆状态真实移除对应生产实体，不以透明显示或全柜碰撞豁免代替。

包含新字段的当前／命名／自定义库配置最低格式 v86，仓库与离线恢复缓存同步接收；旧版本继续读取。保存复用会恢复 `removed:false` 和关闭内抽。完整配置进入几何缓存、确认及原项目链；新结构附 `serviceRule`，颜色、价格及采购状态不导致空间确认失效。仅“可拆卸能力”不改变安装实体；实际 `removed` 状态参与核对。不得把缺少板件的柜箱包络当空腔。

灶前隐藏板944×82×18、下沿748、前表面局部Z164；上延抽面顶819，台面底830，前口连续缝11；抽面背面Z182与隐藏板间留18通道。42个45×6矩形孔（14列×3行、间距12／8）为本案示意。灶下隔板底730、顶748，可拆。此通风路径属于设计模型，不能凭开孔面积或22mm的模型机身间隙宣称符合TH36B-T厂家安装要求，接口／气管位置和实际进风参数仍待安装资料及现场核对。

大号拉斯克350×450×770不变，日常停车中心从 `(6853,9811)` 调为 `(6853,9841)`，向柜内30mm避开踢脚板；顶余42、名义宽余20。C不放地脚，以免占滚轮通道；柜箱悬空侧板的承托连接、门铰链实体及踢脚扣件须深化，不伪造为已验收五金。

检修顺序：打开C门到90°，向外拆C踢脚；将车直移至前方，再侧移停在操作区外；将B两只外抽连同内抽从选定滑轨扣件拆出，取下B底板和踢脚，即可接近后方分水器。前通风挡板和灶下隔板可留在原位。收回时反向操作；不要在车占门前时关闭门。按10mm步进检查直移1200、侧移1497的271个姿态，模型实体未相交；装着踢脚板时的反例会阻挡车。脚轮转向、软管变形、具体拆轨动作及整组分水器更换行程未模拟。
